## 第 0 部分　使用说明

### 0.1 这册是什么，怎么用

`S1`—`S6` 是六个世界各自的世界模组 ＋ 长篇战役，**厚，全，适合长期团**。`S8` 是它们的**门口**：为六个世界各写一则**三幕开场战役**，让一个从没玩过 PRISM 的团，挑一个世界就能在 **20 分钟内开跑**，并在 **一场 2—3 小时的会话里跑完一个完整的第一幕**。

三种用法：

| 用法 | 怎么做 |
|---|---|
| **一次性体验** | 只跑某一则的**第一幕**（约 2 小时），跑完即散，不收线 |
| **试跑选世界** | 用第一幕作为"试玩"，全桌投票决定接下来长跑哪个世界 |
| **正式开局** | 跑完整则三幕，再按第 0.6 节接进该世界的正式长篇战役 |

> **不要在第一次跑的时候用满六个世界。** 六则之间是并列的，不是连续的。选一个，跑完，再谈别的。

### 0.2 开场前必须做的对表（`00` 第五节的落地版）

`00-overview-and-quickstart.md` 第五节给了 30 分钟开局流程。本册把它具体化为**开场前的五问一选**，主持人务必在掷第一颗骰子之前完成：

| # | 问题 | 在本册的含义 |
|---|---|---|
| 1 | 玩哪个世界？ | 从本册六则里选一则（见第 0.5 节对照表） |
| 2 | 强度口味？ | 残酷写实／标准／英雄主义。本册默认**标准**：有风险，但不常团灭 |
| 3 | 一场多久？ | 一次性（跑一幕）／每周（跑一则）／长期（接正式战役） |
| 4 | 边界在哪？ | 明确哪些内容不上桌（本册六世界的题材差异很大，见 0.5 节） |
| 5 | 对角色期待？ | 想当主角／配角／搞笑／认真——这决定主持人给谁递多少戏 |

**一选**：从本册相应战役的"三条入场钩子"里选一条（或让玩家各自选不同的钩子，本册支持混钩开场）。

### 0.4 只有 1.5 小时怎么办（逐世界压缩方案）

一场只有 90 分钟时，**保留三幕的骨架，砍掉并行的支线与第二个场景支路**，把三幕压成"一场景一幕"：

| 世界 | 保留 | 砍掉 | 压缩后形状 |
|---|---|---|---|
| 灰冕 | 第一幕"雾中归路" + 领主的第一次接触 | 三幕中的调查幕、全部支线 | 进谷 → 见领主 → 一个二选一收束 |
| 静默劫案 | 第一幕的踩点 + 动手 | 撤离段的多轮、销赃谈判 | 接活 → 进柜 → 拿东西走人 |
| 潮金港 | 第一幕的一个退潮窗口 | 八家字号竞速、第二幕换边 | 落滩 → 挖到东西 → 有人来抢 |
| 静海 | 第一幕的"窗口二选一" + 一次舱外作业 | 延迟通信的多轮往返、检疫站攻防 | 选窗口 → 出舱 → 带回一封信 |
| 沉层 | 第一幕"下一层" | 第二、三幕的深层、留守经营 | 下第一层 → 遇到同行 → 决定上不上来 |
| 断线 | 第一幕的"一次命令" | 第二幕后方政治、第三幕大推进 | 接令 → 执行 → 命令作废 |

> **压缩原则**：宁可**少跑一个场景，也不要跳过一次判定**。判定是本系统的体验核心，砍判定等于砍玩法。

### 0.6 一则跑完后，怎么接进正式长篇战役

每则开场战役的末尾都会给出**两到三个收束**，每个收束都标注它**指向该世界正式战役的哪个位置**。接法有三种：

1. **顺接**：把开场战役的账本（flag、NPC 态度、资源）直接抄进该世界长篇战役的初始账本，从正式战役的第一幕开始，开场战役视为"前传"。
2. **跳接**：跳过正式战役的前置铺垫，把玩家直接放到正式战役的第二幕，用开场战役里最强的那个 NPC 关系当作他们在城里的"既有人脉"。
3. **并接**：把开场战役当作正式战役的一条**支线**，让它与主线并行；玩家跑完开场后，正式战役的主线 NPC 会主动找上门。

> 本册每则结尾都写明了它**保留哪些 flag 名**，就是为了让"顺接"在技术上可行。

### 0.7 玩家完全不接钩子时的三条补救路径

新团最常见的事故：主持人念完开场白，玩家说"我不去"。不要慌，按顺序用这三条：

1. **换钩子**：本册每则给了三条入场钩子（赚钱／真相／被卷入）。若玩家对"赚钱"无感，改用"被卷入"——让事件**发生在他们身上**，而不是请他们来。
2. **加压力**：给一个**限时**。钟要响了、潮要涨了、窗口要关了、命令要执行了。时限是把"不去"变成"没得选"的最快工具。
3. **上人要账**：让一个 NPC **欠过他们，或他们欠过一个 NPC**。水钱、旧债、一句"你答应过我的"。让玩家的驱动（第 0.3 节写的那句话）被点名。

> 三条都用完还不接，就让第一幕以"他们什么也没做"收场——然后**演出后果**：别人替他们做了决定，而那个决定对他们不利。这是最好的老师。

## 第一则　灰冕：钟响十三次之前

**世界**：`s1-ashen-crown-cursed-domain.md`　｜　**题材**：哥特恐怖 · 封闭箱庭
**推荐引擎**：战术引擎（`02A`）　｜　**假设配置**：4 人，1 级　｜　**预计时长**：第一幕 2 小时；全则 2—3 场会话

**Logline**：一片会遗忘来客的山谷已经把加冕礼办了十二年。你们随一支失踪的商队走了进去。领主要你们帮她找一件"能证明循环存在"的东西——而第十三声钟响，只剩三天。

**世界速览（主持人念给玩家听的 90 秒版）**：缄钟谷是一条被活雾封锁的谷地。十二年前一场失败的加冕礼之后，死者不再离去，边界升起会呼吸的白灰色浓雾；越过雾墙的人会从原处走回。这里真正的货币不是银，是"一个人还记得多少自己"——亡者的记忆会凝成叫**忆晶**的矿物，可以被读取、伪造、烧掉。谷地的统治者是**伊蕾芙·烬冕**，一顶以万人临终记忆熔成的**灰冕**把她固定在"领主"这个身份上，她不能真正死去。

**三条入场钩子（选一条，或各选不同）**

| 类型 | 钩子 | 适合的角色 |
|---|---|---|
| 想赚钱的 | 你们替一支商队押运一批忆晶进谷，商队在雾里消失，货在你们手上，货主在谷里等着——而你们发现"货主"三年前就下葬了 | 逐利的、欠债的 |
| 想知道真相的 | 你们中的一人，昨晚在讣告墙上看见了自己的名字，死因一栏空白，日期是三天后；告示背面的忆晶里有人在说"别让她戴冠" | 好奇的、有执念的 |
| 被卷入的 | 一辆没有车夫的黑马车停在你们面前，车门内侧钉着写有你们姓名的请柬："请来见证我最后一次失败" | 被动的、有秘密的 |

### 第一幕 · 雾中归路（目标：进入谷地，见到领主的第一次接触）

- **目标**：让玩家在活雾里走完第一段路，理解"路会被弯回原处"，并第一次接触伊蕾芙（她主动接触玩家）。
- **这一幕结束时应当发生什么**：玩家确认"谷地在循环，而领主知道这件事，并且她想找人帮她结束它"。

**开场白（可直接朗读，约 110 字）**
> 第三次看见那棵被雷劈成两半的山毛榉时，车夫终于不再催马。车轮印从你们身后延伸到前方，又在乳白色的雾里合成一个圆。路旁坐着个穿丧服的小女孩，鞋尖没有沾泥。她抬头问："你们也是来参加明天那场、已经办过十二年的加冕礼吗？"远处，一口极大的钟响了第一声。

## 第五则　沉层：再下一层就得丢东西

**世界**：`s5-foundered-strata-ruins-and-caverns.md`　｜　**题材**：遗迹探索 · 配给与深度
**推荐引擎**：两者皆可（本则用战术引擎跑战斗与穿越，负重与层压用构建引擎记账）　｜　**假设配置**：4 人，1 级　｜　**预计时长**：第一幕 1.5—2 小时；全则 2—3 场会话

**Logline**：坼口盆地每隔几百年就把自己往下砸一次，把一整座城埋进地里，九次之后就有了"沉层"。你们受雇下去取一件东西。回来的人都说过同一句话：**再下一层，就得丢东西。**

**世界速览（主持人念给玩家听的 90 秒版）**：坼口镇建在一个碗沿上，碗底就是**口**，口以下九个可辨识的人工层叫**沉层**。越深越富，也越难把财富带上来。往下是自由的，往上要付钱：垂直运力被**缒行**垄断，**背工价**按"重 × 起运层深"计价。往下的路是"难走的"，不是"锁着的"——阻碍来自时间、配给、通行情和有没有人愿意替你拉绳。你们背着的每一公斤都要被搬过每一层边界，超载会让穿越时间翻倍，而时间就是命。越深，常识越不可靠——那叫**层压**。

**三条入场钩子**

| 类型 | 钩子 | 适合的角色 |
|---|---|---|
| 想赚钱的 | 灰秤行放出消息：第九层的东西"即将可被估值"，出价翻了三倍。你们接了第一单——下到第三层取一样东西，订金已经到手 | 逐利的、敢冒险的 |
| 想知道真相的 | 你们手里有半张**方梯**的层图——唯一到过第九层还活着回来的人留下的，图上有一行别人看不懂的注 | 好奇的、较真的 |
| 被卷入的 | 你们被**七炉**的份子钱逼到了墙角，只有下一趟深活才还得清；而一个自称"只是来买货"的外地人，已经在口上的茶馆等了你们三天 | 欠债的、被追的 |

| 1 | 潮金港 | 你们在落滩挖到一块刻着陌生文字的船板，涨潮时它开始发烫 | `tracks.party`、`rep.oyster` |
| 2 | 静默劫案 | 一块船板的背面，是高塔金库同款的刻痕；珠宝商认出它 | `silence.current`、`reputation.baihang` |
| 3 | 灰冕 | 你们追着刻痕走进一片起雾的谷地，钟声从雾里传来 | `flag.volunteer_crown`、`clock.bell` |
| 4 | 静海 | 谷地尽头是一座"哑铃"状的旧站，通讯比你们的心跳晚六小时 | `dv_current`、`flag.lingering_signal` |
| 5 | 沉层 | 站在站底往下看，那里不是深渊，是一摞被埋掉的城的顶 | `depth.max_depth_this_run`、`clock.supply` |
| 6 | 断线 | 最深的裂缝尽头透出一线天光，天光里有铁路，铁路上有掩体 | `morale_discipline.morale`、`rep.command` |

**跨界的三条守则**：
1. **一次只跨一道缝。** 把"为什么"留给玩家去猜，别解释。S7 §10 生成的裂隙天然是"说不清"的——这正是它的价值。
2. **保留驱动，重置关系。** NPC 不会跟着走；但玩家身上的债、欠的人情、藏的秘密可以。这保证人物连续，世界翻新。
3. **每站只跑一则。** 把 S8 的一则跑完（2—3 场会话）再跨，而不是每站跑一幕。否则六站变流水账。

### 附录 C　常见开局事故与处理

| 症状 | 成因 | 处理 |
|---|---|---|
| 玩家磨蹭半小时还没建卡 | 首次接触，规则没消化 | 直接用 §0.3 的**预生成角色**，把选择压缩成"挑一个"；背景标签口头补 |
| 玩家对钩子不动心 | 钩子与角色驱动不匹配 | 回到 §0.7 的三条补救路径：加价、加急、加牵连 |
| 玩家想跳过开场白 | 觉得"念文本"很尬 | 让玩家自己念，或让他们补一个细节（"你闻到的第一件事是什么"） |
| 玩家把 NPC 全杀了 | 习惯了"见敌即战" | 每个 NPC 都有"若被杀死／背叛"字段——翻到那一栏，把后果写进世界账本，而不是阻止玩家 |
| 队伍内讧、拆团 | 驱动互相冲突 | 用 §0.2 的对表提前暴露冲突；内讧本身可以是剧情，但要保证"分开也行"的两条线 |
| 一次判定失败后卡住 | 把失败当"门锁" | 全程用**失败向前**：失败不关门，只加代价（多花时间、多欠人情、多留痕迹） |
| TPK 风险 | 战斗预算没算 | 用各册遭遇预算公式核对；宁可让首领"破韧即可谈判"，也不要灭团 |
| 骰运差、连续挫败 | 单点判定太重 | 记住五档结果：**险成**与**挫败**都推进故事，只有**灾难**才添乱 |
| 玩家跳过关键线索 | 线索放在单一路径上 | 回到**三线索法则**：给调查、社交、环境三条独立入口，任得其一即可 |
| 玩家想"全都要" | 没有资源约束 | 用该世界的**资源账**逼取舍：Δv、配给、水钱、沉默轨、负重——这些不是装饰，是引擎 |
| 节奏太慢、会话快结束还没进展 | 场景铺太多 | 用 §0.4 的 1.5 小时压缩方案，把三幕砍成一条主线加一次高潮 |
| 一个玩家一直沉默 | 角色没有"必须开口"的时刻 | 用他的**驱动**点名："这件事只有你会想做——你说。" |
| 玩家问"我现在能做什么" | 世界没给足可选项 | 每个场景表都写了**三条可选路径**，照着念即可 |
| 主持人忘了上次发生了什么 | 没记世界账本 | 用每则"幕末世界账本变化"的字段做一份 JSON（结构见各册第十节），开局先念差距 |
| 玩家想立刻进正式长篇战役 | 起手就尝到了甜头 | 见 §0.6：把开场战役当成"第 0 章"，正式战役当成"第 1 章"，账本直接接力 |
| 玩家坚持做超纲的事 | 想测试边界 | 世界特则就是边界；用"这在你们的世界里要付什么代价"回应，而不是"不行" |
| 全桌都累、想收尾 | 会话超时 | 用该则的"收束"列表里最容易达成的一个，做一次降温结算，把悬念留到下次 |
| 玩家抱怨"太难" | 忽略了防护/韧性/连携 | 提醒他们使用**助势骰**、**连携**与**场地要素**；一次好的准备可省一场硬仗 |
