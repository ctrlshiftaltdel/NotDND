## 一、判定公式

```
判定结果 = d20
         + 属性修正          （见 CORE 第 1 节量表，−2 至 +3）
         + 熟练加值          （若该技能熟练：+2／+3／+4）
         + 专精加值          （若该技能专精：额外 +1）
         + 助势骰总和        （见第 2 节）
         + 情境修正          （态势、装备、高地、掩体等）
```

**对抗 DF：**

- 结果 > DF → 达成。
- 结果 = DF → 达成（**平手归属于行动方**）。
- 结果 < DF → 未达成。

> **导引者的即兴 DF**：当出现规则没写的判定时，从下表的"常规 12"起步，依据三个问题微调：这事本来就该很难吗（+2～+6）？角色有很好的准备吗（−2～−4）？失败会很有趣吗（如果是，降低 DF，让剧情跑起来）？

### 什么时候不掷骰

战术引擎明确要求导引者在下列情况下**跳过掷骰**：

1. **没有有意义的失败方式**。角色要推开一扇没锁的门，那就开了。
2. **角色有压倒性的优势且无时间压力**。开锁大师在没有敌军追击的情况下撬一道普通锁，直接成功（但消耗时间）。
3. **失败不会导致剧情推进**。如果掷骰失败的结果只能是"什么都没发生"，那这次掷骰是在浪费所有人的时间。
4. **玩家主动选择了代价**。玩家说"我愿意花一整晚来查"，那就给结果，扣时间。

> 掷骰只用于：**结果不确定**、**两边都有趣**、**此刻有压力**。

## 二、助势骰：随机性的现代处理

传统规则用"掷两次取高"来表达优势。棱镜改用**助势骰（Edge Dice）**：

> **每获得一层优势，你额外掷一枚 d6，把结果加到你的判定上。**

### 为什么这样改

1. **可堆叠**：三层优势真的比一层强，玩家能感到自己积累的努力。
2. **可预测性适中**：一枚 d6 的期望是 3.5，玩家能对局面做出理性判断（不像重掷那样只能祈祷）。
3. **对 AI 友好**：加法比"比较两个骰"更容易让模型稳定表达与解释。
4. **视觉上直观**：手里一堆骰子滚出去的感觉就是比一个骰子好。

### 助势骰的量化

| 层 | 掷骰 | 期望 |
|---|---|---|
| 微弱优势 | +1d6 | +3.5 |
| 明显优势 | +2d6 | +7 |
| 压倒优势 | +3d6 | +10.5 |
| 超出 3 层 | 每多一层改為 +2 固定加值 | — |

### 劣势

**每层劣势，掷一枚 d6 并从结果中减去。** 劣势同样最多 3 层。

> 注意：当一个判定同时有优势和劣势时，它们互相抵消（而不是各自计算），这是为了桌上的速度。

### 优势来源表

**【可替换】** 每个阵营的小队可以自定义这张表，这是自定义团队风味的最佳入口。

| 来源 | 层 |
|---|---|
| 使用了高地的射手 | +1 |
| 目标未察觉你的存在（偷袭）| +1 |
| 队友刚刚用【协助】动作支援你 | +1 |
| 你使用了与自身战斗风格高度契合的环境要素 | +1 |
| 目标处于【失衡】或【恐惧】 | +1 |
| 你调用的【背景标签】与当前局面高度相关 | +1 |
| 你刚花费 1 AP 瞄准（近战则为蓄势待发） | +2 |
| 敌方处于【破韧】状态 | +2 |
| 你在此前已经失败过一次并调整了方案 | +1（每次会话每人限一次） |

### 劣势来源表

| 来源 | 层 |
|---|---|
| 目标处于中度或重度掩体后 | −1 / −2 |
| 你在移动中攻击且未做好 | −1 |
| 照明完全不足且你无夜视 | −1 |
| 你正在同时处理另一件事（分心）| −1 |
| 目标正在专注躲避（其上一个动作为闪避）| −1 |
| 你处于【失衡】【中毒】【恐惧】等状态 | −1（每个状态，最多 −3） |
| 你攻击的目标正处于守势态势 | −1 |

> **同来源不叠加**：例如三个队友各给你一次协助，在同一回合也只算 +1。这条规则防止无限叠加把游戏变成算术题。

## 三、五档结果梯度

战术引擎不用简单的"成功／失败"，而是**五档**。这个设计来自电子游戏与现代叙事游戏的交叉：让每一次掷骰都有意义，且总是推进。

设 **R = 判定结果 − DF**

| R | 档位 | 含义 | 后果 |
|---|---|---|---|
| ≥ +6 | **凯旋** Triumph | 不只是做到，还做到了出色 | 目标达成 **＋额外收益**。额外收益可以是：额外信息、额外效果、为下一次行动铺路、或让一个队友也受益 |
| 0 ~ +5 | **成功** Success | 干净利落 | 目标达成，按描述结算 |
| −1 ~ −2 | **险成** Narrow | 做到了，但付出了代价 | 目标达成，**＋一个代价**。代价可以是：损失资源、引入麻烦、留下痕迹、暴露自己 |
| −3 ~ −9 | **挫败** Failure | 没做到，而且情况变差 | 目标未达成，**＋情况恶化**。恶化可以是：被发现、失去机会、盟友受损、敌人抢占先手 |
| ≤ −10 或自然 1 | **灾难** Catastrophe | 不只是失败，还赔了 | 目标未达成 **＋显著麻烦**。麻烦可以包括：自己陷入危险、设备损坏、第三方介入、不可逆的后果 |

### 为什么必须有"险成"和"灾难"

- **险成**让"差一点失败"的紧张感变成一次真实的决策：玩家要选择接受什么代价，这比"再来一次"有意思得多。
- **灾难**让"运气很差"成为叙事机会而非单纯的惩罚。优秀的导引者会让灾难成为最令人难忘的场景。
- 这两档都要求导引者**主动创造价值**，这正是 AI 主持人应当被训练去做的事。

### 灾难后果表（d20）

当导引者一时想不出灾难应该怎么写时，掷一次：

| d20 | 后果 |
|---|---|
| 1 | 你的武器／工具损坏或脱手，落入难以取回的位置 |
| 2 | 你发出巨响，引来了不必要的注意 |
| 3 | 你伤到了自己（1d6 伤害）或伤到了同伴 |
| 4 | 你触发了场景中的一个负面场地要素 |
| 5 | 关键情报被误导了：你得出一个错误的结论（导引者诚实说明这是错的） |
| 6 | 你失去了高地／位置优势，被压制在不利地形 |
| 7 | 你损坏了一个重要的第三方物件（需赔偿或解释） |
| 8 | 你被卷入下一个危险空间（掉进下一层、被拖进裂缝、或落入包围圈） |
| 9 | 你暴露了身份／意图，对方开始针对你采取措施 |
| 10 | 你累计 1 点负担 |
| 11 | 你错过了时机，机会窗口关闭（可能需要另想办法） |
| 12 | 你的盟友／雇主对你的能力产生怀疑，声望 −1 |
| 13 | 敌人获得了你身上的一个重要物品 |
| 14 | 你被困、被压或被卡住，需要一次行动才能脱身 |
| 15 | 一个无关者被卷入并受伤，道德成本产生 |
| 16 | 环境被永久改变，从此这条路线不可用 |
| 17 | 你触发了某个伏笔（导引者把计划中的麻烦提前） |
| 18 | 你让一个敌人获得了针对你的针对性增益（下次针对你 +1 枚助势骰） |
| 19 | 你的行动反而帮助了对手（导引者说明为何） |
| 20 | 双重灾难：再掷一次本表，两个后果同时发生 |

## 四、难度值参考与设定向导

### 标准 DF 阶梯

| DF | 名称 | 对应的人群比喻 |
|---|---|---|
| 6 | 童稚 | 受过训练的人几乎不会失手 |
| 8 | 平凡 | 普通人有时能做好的事 |
| 10 | 简易 | 需要一点注意 |
| 12 | 常规 | 专业人士的日常水准 |
| 14 | 有挑战 | 需要专注与准备 |
| 16 | 困难 | 需要技巧或一点运气 |
| 18 | 严峻 | 领域的顶尖人士才有把握 |
| 20 | 极限 | 需要多重优势叠加 |
| 24 | 传说 | 需要整个团队铺路才能触及 |
| 28+ | 神话 | 应当被改写为一个多阶段任务，而不是一次掷骰 |

### 按角色等级设定 DF

**给导引者的快速参考**：为 1 级小队设定 DF 时，主力属性 + 熟练的典型加值为 **+3**（属性 +1、熟练 +2）。因此：

| 队伍等级 | 典型主力加值 | 想要"一半概率成功"的 DF |
|---|---|---|
| 1–3 | +3 ~ +5 | 13 ~ 15 |
| 4–7 | +5 ~ +8 | 15 ~ 18 |
| 8–12 | +8 ~ +11 | 18 ~ 21 |

> **五五开是关键数字。** 一个需要"紧张但应该成"的检定，设在这个 DF；一个"一定要付出一两次铺垫才有戏"的检定，设在 +5 的位置。

### 把大目标拆开

**任何 DF ≥ 22 的单次检定都应当被拆成一个多阶段任务。** 例如"说服国王出兵"不该是一次 DF 25 的交涉，而应当是一系列活动：找到能见到他的人（DF 14）→ 掌握他真正在意的筹码（调查 DF 16）→ 打击他的反对者（战斗或交涉）→ 最终摊牌时 DF 降至 16。

这条规则是让 AI 主持人不要把剧情压缩成一次掷骰的关键教导。

## 五、攻击判定详解

### 攻击流程

```
1. 选择目标与武器／能力
2. 支付 AP
3. 掷 d20 + [相关属性] + [武器／能力熟练] + 助势骰 vs 目标的防护 Guard
4. 依据下表判定命中等级
5. 命中则掷伤害骰 + [属性修正的一半，向下取整] + [武器／能力加值]
6. 应用抗性／弱点
7. 扣活力，并按 CORE 第 8 节扣韧性
```

### 攻击结果等级

| 判定结果 vs Guard | 等级 | 效果 |
|---|---|---|
| 高出 10 点以上 | **暴击** Critical | 掷两次伤害骰，取较高的一次，再加上正常伤害；必定造成横向的额外状态（1 层【失衡】或【流血】） |
| 高出 6–9 点 | **重击** Solid | 正常伤害 + 2 |
| 高出 0–5 点 | **命中** Hit | 正常伤害 |
| 低 1–2 点 | **擦过** Graze | 一半伤害（向下取整），不触发任何附加效果 |
| 低 3 点以上 | **落空** Miss | 无伤害；目标可借此获得一次反手打击的反应机会 |

### 严重失手（自然 1）

仅战术引擎适用。当攻击掷出自然 1 时：

- 不造成伤害；
- 立即获得 1 层【失衡】；
- 导引者从下表掷一次（或自行选择更贴合场面的）：

| d6 | 失手后果 |
|---|---|
| 1 | 武器脱手，落在距离你 1d4 米的位置，需 1 AP 捡回 |
| 2 | 你的攻击破坏了掩体，自己失去了它 |
| 3 | 你跌进了敌人的控制区，对方获得一次免费的攻击机会 |
| 4 | 武器卡住／卡壳，需要 1 AP 修理后才能再次使用 |
| 5 | 你误伤了相邻的一个队友（造成一半伤害） |
| 6 | 你暴露了自己的意图和位置，敌人获得针对你的 +1 骰（持续一回合） |

> **推荐给新手团**：把自然 1 简化为"仅失去这回合剩下的 AP"，然后在玩家熟悉后再启用完整表。

### 伤害骰

各武器有各自的伤害骰（见世界模组装备表）。近战武器的伤害加值取决于武器性质：

- **精细武器**（匕首、细剑）：属性修正全额。
- **力量武器**（战斧、重锤）：力道修正。
- **均衡武器**（长枪、警棍）：取力道与灵巧较高者的一半（向下取整）。
- **远程武器**：+ 洞察修正的一半（向下取整），弩与小口径枪械不加修正。

### 掩体

| 掩体等级 | 防护加成 | 额外限制 |
|---|---|---|
| **轻度**（齐腰矮墙、垃圾桶）| +2 | 可就地获得，移动不受影响 |
| **中度**（车引擎盖、窗户后）| +4 | 必须移动到该位置；离开时失去 |
| **重度**（承重墙角、沙袋掩体）| +6 | 无法在此移动，且只有探出身体时才能攻击 |
| **完全**（厚墙后）| — | 无法被攻击，你也无法攻击 |

掩体会随攻击而损坏：当攻击落空但与防护的差距 ≤ 3 时，导引者可判定掩体受损（中度掩体受损后降级为轻度）。

## 六、先攻、顺序与敌人分组行动

### 先攻

```
先攻掷骰 = d20 + 洞察修正 + 灵巧修正的一半（向下取整）
```

- 玩家小队**可以把自己内部顺序任意调换**（鼓励配合），但不能插到敌人中间。
- 敌人按其类型**分组**：同一类型的敌人在同一时间点一起行动，由导引者一次性描述。这显著减少等待时间，也让 AI 的表达更整齐。
- **偷袭轮**：如果敌人在开始时未察觉小队，则小队获得一整轮免费行动。这是埋伏的巨大回报。

### 敌人分组行动建议

导引者按以下原则组织敌人：

1. 把敌人分成 2–4 组（近战组、远程组、施法组、首领组）。
2. 每组在同一时间点行动，一次性描述该组所有单位的动作。
3. 每组应当有一个明确的"当前目标偏好"（见 `04` 战术人格），让玩家能预判威胁。

## 七、战术机动库

**机动（Maneuver）**是可以在战斗中施行的特殊技巧，是战斗多样性的直接来源。所有角色都可以学习机动——它们不限于某个流派（流派只不过是让某些机动变得更强）。

### 学习机动

- 角色起始（1 级）掌握 **3 个通用机动 + 2 个流派机动**。
- 每次升级可以选择一个新机动（作为成长选择的选项 E 的一个分支）。
- 机动可以被临时教授：一名已有该机动的角色，花费一次**训练场景**即可教会队友。这让长期战役里的角色互相塑造。

标记为 ★ 的机动在编译时经过数值校准，推荐新手优先选它们。

## 八、六大战术流派与能力树

**流派（Discipline）**是战术引擎的角色纵向构建路线。角色在 1 级选择 1 个流派，每 2 级可以跨流派分支一次（可选择第二个流派的低级能力）。

每个流派有 **5 层**，每层 **2 项能力**。你可以在该流派中投资成长选择解锁更高层能力；要达到第 N 层，需要已拥有至少 (N−1) 项本流派能力。

### 流派总览

| 流派 | 战术角色 | 核心手感 |
|---|---|---|
| **锋刃** Edge | 近战爆发／追打 | 越打越强，惩罚任何犹豫 |
| **铁壁** Bulwark | 保护／抗打击 | 站在原地变成了一种战术选择 |
| **游猎** Stalker | 远程／机动／预设 | 让敌人进入你安排好的地方 |
| **秘法** Adept | 控场／能力运用 | 用一个法术改写整个回合的结构 |
| **诡道** Rogue | 隐匿／欺诈／暴击 | 从不正面对抗，永远在你意料之外 |
| **统帅** Marshal | 增益／连携／指挥 | 队友变强就是你自己变强 |

## 九、敌人快速生成模板

这一节是给**需要临时造敌人的导引者**用的（对人类主持人和 AI 都适用）。它让你在 30 秒内产出一个数值合理、有辨识度的敌人，而不必翻阅图鉴。

### 四档基础模板

| 指标 | 杂兵 Minion | 标准 Standard | 精锐 Elite | 首领 Boss |
|---|---|---|---|---|
| **活力** | 12 | 26 | 48 | 110 |
| **防护 Guard** | 12 | 14 | 16 | 18 |
| **韧性 Poise** | 8 | 14 | 24 | 40 + 3 层护盾 |
| **攻击加值** | +3 | +5 | +7 | +9 |
| **伤害** | 1d6+1 | 1d8+2 | 2d8+3 | 3d8+4 |
| **AP** | 3 | 3 | 3 | 4 |
| **DF（用于其能力）** | 10 | 12 | 14 | 17 |
| **遭遇预算** | 1 | 3 | 7 | 20 |

### 按队伍等级缩放

这套模板是**为 1 级小队**设计的。当队伍等级提升时，把下表累加到模板上：

| 队伍等级 | 活力修正 | 防护修正 | 攻击加值修正 | 伤害修正 |
|---|---|---|---|---|
| 1 | +0 | +0 | +0 | +0 |
| 2–3 | +6 | +0 | +1 | +1 |
| 4–5 | +14 | +1 | +2 | +2 |
| 6–7 | +24 | +2 | +3 | +4 |
| 8–9 | +38 | +3 | +5 | +6 |
| 10–12 | +55 | +4 | +7 | +9 |

> **给 AI 的提示**：不要给敌人叠加太多数值修正。**更好的做法是改变敌人的行为与组成**，而不是让它变得血厚而笨。一个 8 级遭遇应当由"不同种类的敌人相互配合"构成挑战，而不是由"三个数值翻倍的杂兵"构成。

| **分身** | 生命值降到一半时分裂为两个半血个体 | +2 |

> 预算：7 + 3 + 2 + 2 = **14 点**

## 十、遭遇预算系统

**遭遇预算**让导引者可以快速组建一场强度可控的战斗，而不必逐个计算。

### 计算方式

```
遭遇预算上限 = 队伍人数 × (队伍平均等级 + 2)
```

| 队伍 | 1 级 | 3 级 | 5 级 | 7 级 | 9 级 | 12 级 |
|---|---|---|---|---|---|---|
| 2 人 | 6 | 10 | 14 | 18 | 22 | 28 |
| 3 人 | 9 | 15 | 21 | 27 | 33 | 42 |
| 4 人 | 12 | 20 | 28 | 36 | 44 | 56 |
| 5 人 | 15 | 25 | 35 | 45 | 55 | 70 |
| 6 人 | 18 | 30 | 42 | 54 | 66 | 84 |

### 遭遇强度

| 强度 | 预算占比 | 预期体验 | 建议使用时机 |
|---|---|---|---|
| **纠缠** | 40% | 应该很轻松，但会消耗一点资源 | 日常摩擦、建立自信 |
| **标准** | 70% | 需要认真对待，会消耗约 1/3 资源 | 常规遭遇，大多数场景 |
| **严酷** | 100% | 有可能出现濒危，会消耗大量资源 | 每 2–3 场一次的高潮 |
| **致命** | 140%+ | 团灭是真实可能的结果 | 战略性失误的后果，或终局决战 |

### 组成限制

为了防止"一大堆东西淹没人"或"一个看不见的敌人藏在角落"这类糟糕体验：

1. **同类敌人的数量不得超过 队伍人数 × 1.5**（向下取整，最低 2）。
2. 单个**首领**的预算消耗不得超过本场总预算的 60%。
3. 每场遭遇**至少要有两类不同的敌人**（或至少一个带词缀的个体），以保证战术多样性。
4. **杂兵数量建议控制在 6 个以内**，超过则使用下文的"群战处理"。

### 群战处理

当杂兵数量超过 4 个时，使用下列简化，这是让战斗保持流畅的关键：

- **杂兵共享活力池**：每 2–3 个杂兵共用一份活力，打空这份活力即可清理整组。这让"清理杂兵"有爽快感，而不是消耗战。
- **一组杂兵只掷一次骰**：一组杂兵的攻击合并为一次群体攻击，对同一目标造成叠加伤害，而非逐个掷骰。
- **过杀转移**：对杂兵造成的超出伤害可以转移到同组的其他杂兵身上。

## 十一、可选规则

以下规则默认**关闭**。它们是为特定口味的团准备的调味料。

### 1. 伤口表（严肃写实口味）

当角色受到暴击或单次损失超过 1/3 活力时，掷 d12：

| d12 | 伤口 |
|---|---|
| 1 | 失去一只眼睛：依赖视力的判定 −1 骰，永久 |
| 2 | 手臂骨折：该手臂不能使用精细动作，直到治疗 |
| 3 | 严重脑震荡：所有心智类判定 −1 骰，直到长歇 |
| 4 | 内脏损伤：移动 −2 米，直到长歇 |
| 5 | 留下永久性疤痕：交涉时获得 +1 骰，察觉时 −1 骰 |
| 6 | 大腿中箭：移动减半 |
| 7 | 失去手指：射击与巧手 −1 骰 |
| 8 | 耳鸣：洞察类判定 −1 骰，一天 |
| 9 | 慢性疼痛：每晚需通过耐受检定才能长歇 |
| 10 | 失去一个重要随身物品（剑、通讯器、药物） |
| 11 | 脑震荡引起失忆：忘记最近 24 小时的一件事 |
| 12 | 濒死体验：获得永久 +1 负担，但赢得 1 点决意上限 |

### 2. 弹药与消耗管理

- 每次远程攻击消耗 1 单位弹药；每次速射消耗对应倍数。
- 弹药耗尽后需要 2 AP 装填，或在间幕补充。
- **简化版**：只在遭遇结束后检查一次弹药是否足够补充；若不够，需要在下一个场景想办法。

### 3. 士气检定

当遭遇中出现以下任一情况时，敌方单位需要进行士气检定（`d20 vs DF 12 + 队伍规模 − 目睹的己方伤亡数`）：

- 该组敌人损失超过一半；
- 敌方首领被击败；
- 敌人受到一次暴击并且该次伤害超过其剩余活力的一半。

失败则该个体**溃逃**或**投降**（由导引者选择更符合叙事的一个）。这让战斗提前收束，而不是把最后一滴血打完。

### 4. 追击与逃脱

当一方想要脱离时，不进入普通战斗，而进入**追逃条约**：

- 双方各选择一种策略（速度、欺骗、地利、干扰）。
- 每一轮双方各掷一次对应的技能判定，率先累计三次成功者达成目标。
- 每一轮对抗，导引者都应当演出一段环境变化（转入巷弄、跳上车顶、穿过人群）。

### 5. 玩家掷所有骰

敌方的命中由玩家的**闪避判定**（`d20 + 灵巧 + 态势 vs 敌人的攻击加值 + 10`）取代；玩家的优势骰成为主动防御的资源。这显著提高玩家的参与感与安全感。适合偏叙事的团。

### 6. 战术地图 vs 心象剧场

- **心象剧场**（默认）：不使用地图，位置以"近／中／远"与"相邻／脱离"描述。速度更快，但要求导引者在口头上清晰地维护空间一致性。
- **战术地图**（可选）：使用区域（zone）而非方格。每个区域描述其一固有的特征。适合重视走位的团队，强烈推荐配合地图使用本系统，因为本系统的位置机制价值很高。

### 7. 一次会话一个敌方骰

为简化 AI 的运算，可以让所有敌人的攻击都使用同一个 d20 结果（每次各类型掷一次）。这让 AI 表达更整齐，但减少了随机性。适合入门团。
