## 一、如何使用本册

### 三幕结构

每则战役都按以下结构组织：

```
第一幕 · 钩住
  一个具体的、发生在玩家身边的事件。目标：让玩家在乎。
  通常 1–2 次会话。

第二幕 · 恶化
  真相的第一层被揭开，但它比想象中大。目标：让玩家选择立场。
  通常 2–3 次会话。

第三幕 · 摊牌
  一个必须付出代价的对峙。目标：让世界因玩家而改变。
  通常 1–2 次会话。
```

### 每幕的四要素

| 要素 | 内容 |
|---|---|
| **目标** | 玩家在这一幕要达成什么（必须可被明确说出） |
| **场景** | 建议的 2–4 个场景，每个都有明确的位置与张力值 |
| **分支** | 至少三条玩家可能走的路（使用 `04` 的三条分支法） |
| **收束** | 本幕结束时的判定条件 |

### 线索网的使用

每个战役都给出**核心结论**与**至少三条获取途径**。这是三线索法则的具体落实。

> **导引者的第一责任**：如果玩家没有找到任何一条途径，把其中一条送到他们面前。**卡住永远不是玩家的错。**

### 分支的处理

每幕给出三条分支路线，标注使用的**故事引擎**（见 `04` 第 6 节）。未被选中的路线不消失：

- 50% 概率在后续以变形回响的形式出现；
- 其余存入未使用钩子池，供第二幕或第三幕使用。

## 二、战役一：《雨夜七号线》（阈界都市）

> **推荐引擎**：战术引擎　｜**推荐语气**：冷硬　｜**建议等级**：1–3
> **一句话**：七个人在同一节车厢里看见了对面站台上的一个人。三天后，其中六个收到了同一条短信。而第七个人，就是发短信的人。

### 核心秘密

**三年前，一个叫沈砚的年轻人在七号线青龙寺站（已停用十四年）的站台上，看见了对面站台的自己。他走过去，然后就没有回来。**

现在，他仍在那个站台。他一直在等有人看见他——因为根据这个世界的规律，**被足够多的人看见，就能回去**。他需要七个。他已经有了六个。

### 关键 NPC

```
【沈砚】三年前失踪的人，仍在青龙寺站
  Drive : 回家。他不知道自己已经死了
  Lever : 他的妹妹（如果玩家能找到她，并让她说话）
  Mask  : 平静、有礼、像一个刚下班的人
  Tell  : 他从不眨眼，也从不踩到水——因为他没有倒影也没有重量
  Threshold : 如果被告知真相，他会试图把一个活人换进站台

【沈砚的妹妹 · 沈砚青】三十岁，仍在找哥哥
  Drive : 知道哥哥到底怎么了，无论结果是什么
  Lever : 她已经花了三年，愿意付出任何代价
  Mask  : 干练、理性、不谈私事
  Tell  : 讲到第三年时会改用过去时，然后自己纠正

【陶铮】办公厅行动组的负责人
  Drive : 在三天内完成一次"敷面"，以保住自己的职位
  Lever : 他其实也想弄清楚青龙寺站到底发生了什么
  Mask  : 公事公办，且总是很累
  Tell  : 提到"1984 年第三隧道"时会停顿

【老孟】七号线的老员工，三人组中最后一位
  Drive : 让有人继承他知道的东西
  Lever : 他没有继承人，只有听众
  Mask  : 啰嗦、爱讲旧事、看起来不太可靠
  Tell  : 每次讲到最后一段都会岔开话题
```

### 第一幕：钩住

**目标**：弄清楚"你们为什么都收到了那条短信"。

- **场景 1（张力 3）**：一场普通的夜雨。角色各自在七号线的同一节车厢里，看见对面站台站着一个人。**不要解释，只描述。**
- **场景 2（张力 4）**：三天后，六个人收到短信"你们看见我了"。有人开始调查其他人是谁。
- **场景 3（张力 6）**：第一次集体行动——回到那节车厢的位置。青龙寺站已停用十四年，但门开着。

**三条分支**

- **A｜代价**：走进站台，与沈砚第一次对话。他非常友好，并请你们"下周三晚上再来，还差一个"。
  *短期*：你们知道了他的需求。*长期*：你们必须决定要不要凑齐第七个人。
- **B｜牵连**：办公厅注意到你们在调查。陶铮出现，要求你们立刻停止，并且**他把青龙寺站重新封了**。
  *短期*：正面遭遇官方。*长期*：你们必须想办法绕过封锁，或者与陶铮交易。
- **C｜回响**：找到老孟，他讲出了 1984 年第三隧道事件的一部分，并提到"车不会停在没人叫的站"。
  *短期*：获得了历史参照。*长期*：你们知道**必须主动叫站，它才会停**。

**收束条件**：玩家确认"那个人是真实存在的、且他在等人的到来"。

### 第二幕：恶化

**目标**：决定要不要给沈砚他想要的第七个人。

- **场景 1（张力 5）**：沈砚的妹妹出现。她已经找了三年。
- **场景 2（张力 7）**：陶铮提出交易：他帮你们进入站台，条件是**你们带一个人出来**（他要的是证据，不是救人）。
- **场景 3（张力 8）**：第一次尝试让七号线在青龙寺站停靠。这需要：在某节车厢里，让七个活人**同时**看见他。

**核心结论**：沈砚已经死了，站台上的东西不是他。**三条途径**：
1. 老孟会说出"三年里七号线停过两次青龙寺，那两次都有人消失"；
2. 站台上的他没有倒影，且从不踩到积水；
3. 办公厅 1984 年的档案里有完全一样的记录。

**三条分支**

- **A｜抉择**：凑齐七个活人——这意味着**把一个无辜者带进危险里**。
- **B｜揭露**：告诉妹妹真相。她会崩溃，但也会提出另一个办法：让她自己成为第七个。
- **C｜升级**：陶铮不等了，他封锁了整条线路并强行进入站台。**站台开始吞噬活人。**

**收束条件**：玩家选定一种做法，并为此付出第一个真实代价。

### 第三幕：摊牌

**目标**：在青龙寺站做一个决定。

**高潮三要素**

1. **代价的可能性**：如果处理失败，会有角色被留在站台上；
2. **知情的选择**：玩家此时清楚知道所有选项与后果；
3. **无法回头**：无论结果如何，七号线此后永远多停一站。

**三种结局**

| 结局 | 条件 | 后果 |
|---|---|---|
| **换回** | 有人自愿进入站台，把沈砚换出来 | 沈砚以某种不完整的状态回来；那位自愿者成为新的"站台上的东西"，且他会继续等七个 |
| **了结** | 让妹妹与他告别，站台失去"被等待"的意义 | 沈砚消散。妹妹得到答案。青龙寺站永久停用，且从此地图上不再有它 |
| **沉默** | 什么都不做，让办公厅接管 | 陶铮完成敷面。事件被掩盖。三人组中的老孟此后不再说话。**这是最沉重也最真实的结局** |

### 后续钩子

- 老孟抽屉里还有 1984 年那次的完整记录；
- 陶铮在敷面报告里写下了你们所有人的名字；
- 第七个人（如果你们没凑齐）其实一直都在——他是列车员。

## 三、战役二：《井温》（余烬纪元）

> **推荐引擎**：战术引擎 或 构建引擎　｜**推荐语气**：抒情 或 悲剧英雄　｜**建议等级**：1–3
> **一句话**：公社的井开始发烫。三天后，守烬人会来检查；而你们在第二天夜里发现，井底的不是水。

### 核心秘密

**井底连着一段野生的根系，而那段根系里有一个尚未散尽的意识。**

它是第六纪患者的集体残余——一百年前死于燃症的三分之一人口，有一部分并没有真的散掉，而是沉进了根系。现在它正在试图**醒来**，而井里上升的温度就是它苏醒的迹象。

它要的不是复仇。它想要的是**被记住**。

### 关键 NPC

```
【老谷】公社最年长的人，八十一岁
  Drive : 在他死之前，把这件事交代清楚
  Lever : 他知道，但他一直没说
  Mask  : 慈祥、爱讲旧事、有点耳背
  Tell  : 每次讲到第六纪都会"忘了"，而且是真的忘了

【守烬巡查 · 柯弥】三十四岁，例行公事
  Drive : 完成这次检查，回到城里
  Lever : 她的姐姐死于燃症，而官方数字是零
  Mask  : 专业、礼貌、不带情绪
  Tell  : 说到"零"这个数字时会看别处

【井里的东西】第六纪的集体残余
  Drive : 被记住
  Lever : 名字。说出任何一个死者的名字，它就会安静一阵
  Mask  : 它不说话，只让人做梦
  Tell  : 靠近井的人会反复梦见同一个不认识的人

【邻村的家主 · 郝平】
  Drive : 把这片地拿下，井不重要
  Lever : 他的女儿也做了那个梦
  Mask  : 热情、豪爽、好客
  Tell  : 从不碰井里的水
```

### 第一幕：钩住

**目标**：搞清楚井为什么会发烫。

- **场景 1（张力 3）**：日常。公社的一天，井水开始温热，孩子说水是甜的。
- **场景 2（张力 5）**：夜里，井底有光。有人梦见了不认识的人。
- **场景 3（张力 6）**：守烬巡查柯弥到达前的一天，公社内部开始分裂：有人想上报，有人想隐瞒。

**三条分支**

- **A｜牵连**：邻村家主郝平突然造访，提出要买下这片地，出价高得不合理。
- **B｜回响**：老谷讲出第六纪的一件事，讲到一半又忘了——但他留下一句话：**"井是后来才挖的，那天我们挖到了根。"**
- **C｜代价**：柯弥提前一天到了。她要求立刻封井，而封井意味着**公社将失去唯一的水源**。

**收束条件**：玩家确认"井底的东西与第六纪有关"。

### 第二幕：恶化

**目标**：决定要不要让井里的东西醒来。

- **场景 1（张力 6）**：更多人开始做同一个梦。梦里的那个人在做一件事——**她在数名字**。
- **场景 2（张力 7）**：柯弥查出真相的一半，她的选择会改变立场：她可能转为帮助你们，也可能是更严格的封锁。
- **场景 3（张力 8）**：进入根系（通过井）。这是本战役的"地下城"段落。

**核心结论**：井里的东西是第六纪的集体残余，它要的是名字。**三条途径**：
1. 老谷留下的那半句话 + 公社的地契（井确实是后来挖的）；
2. 柯弥的官方档案中，第六纪的死亡名单在某一页被撕掉了；
3. 在井底的根系中，可以直接听见它在数名字。

**三条分支**

- **A｜抉择**：收集名字并念给井听。每一位念出名字的角色都会失去一段自己的记忆（对等的交换）。
- **B｜启示**：发现郝平的女儿也在做那个梦。如果让她来念第一个名字，代价会由所有人分摊。
- **C｜升级**：根系开始扩张。井水沸腾，且附近三十公里内的野炉全部开启。

**收束条件**：玩家带回了至少一个死者的真名。

### 第三幕：摊牌

**目标**：在三天期限到达前完成仪式，或者阻止它。

**高潮三要素**

1. **代价的可能性**：念出名字的人一定会失去一段记忆；
2. **知情的选择**：玩家此时知道代价、知道后果、也知道不做的后果；
3. **无法回头**：仪式一旦开始，井将永远不再是水井。

**三种结局**

| 结局 | 条件 | 后果 |
|---|---|---|
| **记住** | 完成仪式，念出足够多的名字 | 集体残余得到安息。井变成一口温热的、不再出水的井，而它此后会在每年同一天发出光。念名者失去的记忆从此属于所有人 |
| **封存** | 让柯弥按官方程序封井 | 事件被记录为"地质活动"。公社失去水源，必须迁走。老谷在迁走那晚去世，而他没有留下任何话 |
| **记忆交换** | 让郝平的女儿念第一个名字 | 代价由全公社分摊，每个人忘掉一件小事。第六纪的患者们被记住了，而代价是**公社从此记不清那天到底发生了什么** |

### 后续钩子

- 柯弥手里的第六纪名单缺失的那一页，后来出现在白骨荒野；
- 那个"在数名字的人"的身份，可以在静林的档案里查到；
- 根系里还有别的野炉，而它们都通向同一个地方。

## 四、战役三：《第 41 次备份》（熵网）

> **推荐引擎**：构建引擎　｜**推荐语气**：冷硬 或 荒诞讽刺　｜**建议等级**：1–3
> **一句话**：一个备份技师把同一个人的意识备份了四十次，都失败了。第四十一次成功了——但醒过来的不是那个人。

### 核心秘密

**第四十一次备份里装的，不是原主叶槐的意识，而是三十一年前坍缩那天没能退出的一个人——备份技师裴晚的妹妹，裴芜。**

熵网的坍缩吞掉了成千上万个正在线上的人。绝大多数被判定为"无法恢复"。
但裴晚发现：如果用一个**足够空**的意识作容器，反复备份、反复清洗，理论上可以把网里残留的东西一点点"捞"到容器里。
叶槐是她找到的容器——一个把自己卖给了财团、意识几近空白的人。

四十次，容器都被撑破了。第四十一次，容器稳住了。**因为这一次，裴芜也学会了配合。**

而财团（云枢）盯上第四十一次备份，原因与裴晚完全不同：一个**能被反复备份而不同步崩解的意识**，是三十一年来最贵的技术样本。

### 关键 NPC

```
【裴晚】备份技师，三十六岁
  Drive : 把妹妹带回来——无论要清洗多少次自己
  Lever : 每做一次备份，她都要删掉自己的一段记忆来腾出带宽
  Mask  : 冷静、程序化、把一切说成技术问题
  Tell  : 说到"第 41 次"时，手会在键盘上停一拍
  Threshold : 如果被告知妹妹其实不想回来，她会先沉默，然后继续做

【叶槐】编号 E-2047，容器
  Drive : 想知道自己到底还是不是自己
  Lever : 他记得一些不属于自己的童年——一条河、一个叫"芜"的名字
  Mask  : 顺从、配合、几乎不反抗
  Tell  : 偶尔会用别人的口气说话，然后自己愣住

【邵诤】云枢财团执行人
  Drive : 把样本完整地、可复制地交给公司
  Lever : 他的合同还剩两年，而他需要一份足以升职的成果
  Mask  : 客气、专业、永远在谈流程
  Tell  : 提到"同步率上限"时会露出一点得意——他知道别人不知道的事

【阿箬】网潜者，二十三岁，引路人
  Drive : 挣够钱，把父亲从无名区找回来（他也在熵网里）
  Lever : 她下过很多次网，从没遇到过像"第 41 次"这样的东西
  Mask  : 吊儿郎当、嘴上不饶人
  Tell  : 说法说到一半会突然停下来"听"——她真的听见了

【裴芜】熵网里的意识（三十一年前失踪时十七岁）
  Drive : 出去；或者，至少被记住
  Lever : 她只记得姐姐叫过一次她的名字，而那一次姐姐在哭
  Mask  : 她通过叶槐说话，语气很轻，像怕吵到谁
  Tell  : 她会用裴晚的口气讲裴晚做过的梦
```

### 第一幕：钩住

**目标**：弄清楚为什么"第 41 次备份"会在网里自己动。

- **场景 1（张力 3）**：一次普通的例行备份。玩家（受雇于云枢，或是裴晚找来的外援）在档案层的一个隔间里，看见一台老式备份舱里躺着叶槐。**他只说了一句话："你们终于来了。"**
- **场景 2（张力 5）**：备份数据里出现了一段不该存在的日志——它记录的是一段三十一年前的、网潜退出的失败尝试。时间戳早于叶槐出生。
- **场景 3（张力 6）**：裴晚失踪了。她的工位被清空，只剩一张纸条和一个坐标——指向**无名区**的一处旧中继。

**三条分支**

- **A｜代价**：按坐标去无名区找裴晚。她会承认自己做的事，并请你们"再下一次网，把第 41 次带走"。*短期*：你们知道了真相的方向。*长期*：你们成了她的共犯。
- **B｜牵连**：邵诤出现，提出正式收购：样本、数据、容器全归云枢，你们拿一份厚重的报酬。*短期*：缓和；*长期*：你们必须在"卖掉一个人"和"拒绝财团"之间选。
- **C｜回响**：留在原地，从备份舱的残留数据里，一点一点把三十一年前的日志复原出来。*短期*：慢，但没有欠任何人情；*长期*：你们掌握了一条裴晚也不完全知道的线索——**裴芜不是唯一一个被留在里面的人。**

**收束条件**：玩家确认"第 41 次备份里有两个意识，而且其中一个不属于这个世界"。

### 第二幕：恶化

**目标**：决定要不要把第 41 次备份带出熵网。

- **场景 1（张力 5）**：玩家第一次真正下网。第四十一次备份在网里有一个"影子"——它会在玩家靠近时**用叶槐无法知道的细节**描述玩家（例如玩家刚刚在现实里做了什么）。
- **场景 2（张力 7）**：裴晚的清洗次数被揭示：她已经删掉了自己近二十年的记忆。她记不清母亲的脸了。**而她不记得自己记不清。**
- **场景 3（张力 8）**：邵诤不再等交易了。云枢启动"回收程序"，加密整个隔间，开始把备份上传到云端——**一旦上传完成，裴芜会被拆成训练数据。**

**核心结论**：第 41 次备份里是裴芜，而"叶槐"正在被两个意识共同占据。**三条途径**：
1. 备份日志里那段三十一年前的时间戳；
2. 叶槐说出只有裴芜知道的事（一条河、一个名字）；
3. 阿箬在无名区见过同样"不该存在"的中继——坍缩那天，有不止一个人没出来。

**三条分支**

- **A｜抉择**：帮裴晚把第 41 次带出来——这意味着叶槐醒来后可能不再"是叶槐"。
- **B｜揭露**：把真相告诉叶槐，让他自己决定。他会做出一个出乎所有人意料的决定。
- **C｜升级**：阻止上传。云枢的回收程序会把整个档案层拉进"高同步区"，**在里面待太久的人会开始分不清自己是本体还是备份。**

**收束条件**：玩家选定一种做法，并为此付出第一个真实代价——**删掉自己的一段记忆，或失去一个身份。**

### 第三幕：摊牌

**目标**：在上传完成前，对容器做最后一个决定。

**高潮三要素**

1. **代价的可能性**：无论选什么，都会有人失去一段自己——裴晚、叶槐、或玩家之一；
2. **知情的选择**：玩家此时知道裴芜的意愿、叶槐的意愿、裴晚的执念，以及云枢的价格；
3. **无法回头**：第 41 次备份一旦被写入或清除，这个"她"就再也不会以同样的方式存在第二次。

**三种结局**

| 结局 | 条件 | 后果 |
|---|---|---|
| **带出** | 完成转移，把裴芜写进叶槐的容器 | 一具身体里有两个人。叶槐同意共用，代价是他从此再也不能确定哪段记忆是自己的。裴晚终于认得出妹妹的脸——然后发现自己认不出母亲的 |
| **清除** | 让云枢完成回收，或由玩家亲手清除 | 裴芜永久消散。叶槐恢复"干净"，但失去了一整段情感记忆。裴晚崩溃——**而且她连自己被删掉的部分都记不得了，所以她的崩溃看起来很平静** |
| **留下** | 让第 41 次留在熵网里，成为一个稳定的锚点 | 裴芜不出去，但也不再消散；她成了网里一个能被人找到的坐标。此后任何下网的人都可以"路过"她。云枢失手，叶槐恢复原状，裴晚把剩下的日子用来做一件事：**每个月下一次网，去看她一次** |

### 后续钩子

- 阿箬父亲的名字，出现在三十一年前那段日志的下一行；
- 无名区里那个"不该存在"的中继，编号是 41；
- 裴晚删掉的那二十年里，有一段是关于**她母亲**的——而她的母亲，当年也在线上。
- 云枢的回收清单上，第 42 行到第 47 行，都不是空的。
