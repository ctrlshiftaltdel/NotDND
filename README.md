# NotDND

一个**完全原创、可商用**的 AI 跑团网页应用。规则系统为「**棱镜 PRISM**」
（MIT，PRISM Authors），AI 担任**导引者**（Conductor），纯文本交互，无图片资源；
面向单机 / 局域网「多人轮流共用一台设备」的桌边场景。

> ⚠️ **仅限本机 / 局域网使用。** 后端默认无账号系统、可监听 `0.0.0.0`，
> **请勿暴露到公网。**
