## 一、怎么用这本册子

### 1.1 它解决三个问题

随机表册子通常死于同一种病：**掷出来的东西不能用**。

最常见的三种死法，本册逐一处理：

| 死法 | 症状 | 本册的解法 |
|---|---|---|
| **缺语境** | 表给了"一个奇怪的人"，但你还得再想十分钟他到底是谁 | 每张表的结果项自带一个可演的钩子（一个动作、一个矛盾、一个物件），不是形容词 |
| **缺组合** | 表与表之间没有连接说明，五张表掷出五个不相干的碎片 | 第 1.3 节给出组合语法；每张表的"这张表怎么用"直接写出推荐组合式 |
| **缺兜底** | 掷到重复项、或结果明显不合当前世界，主持人卡住 | 第 1.4／1.5／1.6 节给出三套确定性流程，不留"由主持人决定"的空白 |

一句话概括本册的设计原则：**每张表的每一次掷骰，都必须产出一个能被立刻念出口的句子。**

### 1.2 表的标准字段（T6 扩展版）

`S0` 的模板 T6 只要求"表名 + 一句怎么用 + 重复处理"。本册在此之上把每张表固定为**五件套**：

```markdown
### 表 X-N · 表名（适用场景｜钩子密度：高/中/低）
**一句话用途**：这张表回答哪个具体问题。

| d20 | 结果 |
|---|---|
| 1 | … |

**这张表怎么用**：推荐组合式（用第 1.3 节的语法书写）＋推荐的落点数（掷几次）。
**重复／不合场景时**：至少给出两条具体的处理动作，不写"自行决定"。
```

每张表还可能带一个可选字段 **【接口】**：当这一掷会落到数值上时，**必须**写明它对应内核的哪个标签／状态／伤害类型／物价层级。格式见第 1.7 节。这是本册与一般随机表册最大的不同——**随机出来的东西必须能立刻进账本、立刻能打架、立刻能卖钱。**

### 1.3 组合语法

本册的表不是孤岛。它们用下面六个算子连接。**这些写法可以直接粘给 AI 导引者当作指令。**

| 算子 | 写法 | 含义 | 例 |
|---|---|---|---|
| **并列** | `A + B` | 两份结果共同描述同一个对象，彼此不修饰 | `陌生人 = 表2-1 + 表3-1 + 表3-5 + 表4-1` |
| **交叉** | `A × B` | 把 B 当作 A 的修饰层，二者必须互相迁就 | `外貌 × 习惯`（手指焦黄 ＋ 反复捏鼻梁 ＝ 老烟枪的手） |
| **递进** | `A → B` | 由 A 的结果限定 B 的落点范围 | `驱动 → 恐惧`（要保护妹妹 → 害怕自己又一次来迟） |
| **条件** | `A ? B : C` | 满足条件取 B，否则取 C | `有火器 ? 保留"枪械" : 改读为"弩"` |
| **重复** | `A^n` | 掷 n 次，结果并列 | `摊位^3`（一条街上三个摊子） |
| **反相** | `~A` | 取结果的反面，或表里不一 | `~热情`（过分热情，且在掩饰什么） |

**三条组合纪律**：

1. **一个骨架一次成型。** 造人时先掷完所有需要的表，再开始解释。边掷边解释会导致后半段的结果被前半段牵着走，失去随机的价值。
2. **不超过三层组合。** 超过三层的组合式会产出精巧但难以演出的怪物。需要深度时，宁可用于一个**已经确立**的核心角色，而不是路人。
3. **矛盾不要抹平。** 两个结果互相打架时（疏于打理 × 衣冠楚楚），把它保留下来当作这个人的内在冲突，而不是重掷。这是随机表最有价值的产物。

### 1.4 二次加工五法

当结果需要被改动时使用。**五法有顺序，自上而下尝试即可**，不需要创造力，只需要执行。

| 法 | 什么时候用 | 怎么做 |
|---|---|---|
| **升格 Promote** | 结果很平淡，但场景需要重心 | 把这一个细节提升为场景的核心矛盾（墙上有水渍 → 墙后有整面渗水的空腔，敲起来是空的） |
| **侧移 Lateral** | 结果的"意思"对，但"形"不搭 | 保住两端的语义（它是什么功能／它造成什么后果），换掉中间的实现方式（枪店老板 → 弩坊主人） |
| **反转 Invert** | 结果与当前场面完全同向，没有张力 | 取反义（他愿意帮忙 → 他太想帮忙了，以至于隐瞒了关键的一步） |
| **具现 Embody** | 结果是抽象词，没法直接说出口 | 把它变成一个可被感官确认的物件、动作或数字（他很有钱 → 他付账时不看数目，而且找零不要） |
| **嫁接 Graft** | 结果无主 | 把它挂到剧情已有的一条线上（这件事是**谁**做的、跟**哪条线索**有关、**什么时候**开始的） |

> **具现是五法里最常用的一法。** 如果只想记住一条：把一个形容词改成一句能被看见的动作描述，几乎总能救回一个结果。

#### 表 1-1 · 二次加工手法速掷（任何结果需要返工时｜钩子密度：中）

**一句话用途**：不想动脑时，让骰子替你选一种加工方式。

| d20 | 加工手法（含一行示范） |
|---|---|
| 1 | **加数字**：给结果一个具体数量（三条船，而不是一些船） |
| 2 | **加时间**：给结果一个明确的时刻或期限（天亮前必须搬走） |
| 3 | **加主人**：指明这是谁的（这是前任店主留下的，他三年前失踪了） |
| 4 | **加代价**：使用或接近它要付出什么（打开它会弄断你的两根手指） |
| 5 | **加证人**：有人看见过这件事（巷口那个补鞋的看见了全过程） |
| 6 | **加反差**：在它旁边放一个相反的东西（金漆剥落的柜子里放着一双擦得发亮的鞋） |
| 7 | **加缺失**：它少了关键的一部分（账本少了中间七页，正好是最忙的那七天） |
| 8 | **加重复**：同样的东西出现三次以上（每个门口都摆着同一款式的空鸟笼） |
| 9 | **加错误**：它被人做错过一次，且痕迹留下了（门框上有一道砍痕，砍歪了） |
| 10 | **加等待**：它正在等某人某事（桌上有两副碗筷，一副还没动过） |
| 11 | **加感官**：给它一个气味或声音标签（闻起来有烧过的糖味） |
| 12 | **加拒绝**：它拒绝被使用或进入（抽屉卡死了，撬开会伤到里面的东西） |
| 13 | **加交易**：它与某人做过一次交换（这把刀是拿半年的工钱换的） |
| 14 | **加误解**：旁人对它有普遍的错误认知（街坊都以为那是口井，其实是通风口） |
| 15 | **加时效**：它的有效期很短（这批货今晚就转运） |
| 16 | **加伤痕**：它受过一次伤并留下了证据（墙上补过漆，颜色深浅不一致） |
| 17 | **加名字**：它有自己的名字（工人们管这台机器叫"老寡妇"） |
| 18 | **加规矩**：围绕它有一条不成文的规矩（没人敢在天黑后从这里过） |
| 19 | **加错身**：它出现在不该出现的位置（婴孩的鞋挂在成年男人的窗台上） |
| 20 | **加回声**：它与角色过去的一件事呼应（和你上次弄丢的那件东西是同一个牌子） |

**这张表怎么用**：任何一次"掷出来但不知道怎么演"的结果，掷一次本表，把结果当作加工指令。
**重复／不合场景时**：若连续两次掷到同一行，改用**相邻行 + 反转**（第 9 行缺页 → 多出来的、不属于这里的一页）；若某行指令在当前世界说不通（如科幻世界里"补鞋匠"），保留结构、换掉载体（第 5 行见证者 → 监控终端的缓存日志）。

### 1.5 重复结果的处理规则

> 大多数随机表册子回避这个问题，于是主持人在夜里十一点半第三次掷到"一个醉汉"时，只能自己硬编。下面是三条规定，照做即可。

**规则一 · 同一批的人物不许重样。**
在同一次人物速成中（例如一次生成三名路人），若任意两张结构性表（身份、驱动、外貌标记、致命缺点）落到了同一行，**第二个人物对该行执行一次"侧移 + 具现"**，改写成同源但不同的版本。

> 例：两次掷到"他在数东西" → 第一个人数自己的手指，数到第七根就重新开始；第二个人数走过的台阶，并且正在用手指把它们蹭在裤子上。

**规则二 · 同一会话第三次命中同一行，烧掉它。**
当某张表在同一次会话内第三次给出同一行：

1. 立刻在该行旁记一个记号（推荐写 `(已用)`）；
2. 用一个**仍然符合该表语义范围**的新结果替换它，写在表的空白处——这张表现在属于你的团了；
3. 把被替换掉的那次结果**升级为线索**：它不是巧合，它是这个世界的某种规律（三次都遇到同一个卖糖人的小贩，那他就是这条街的消息贩子）。

**规则三 · 跨会话的重复，是世界的特征。**
如果跨越多次会话仍然反复掷到同一结果，**不要重掷，接受它**。把它升格为一个固定的世界元素：给它名字、给它一个摊位或据点、让它认识队伍。重复是巧合，被承认的重复是设定。

### 1.6 不合当前世界时的三层校准

本册是世界无关的，因此必然会出现"这个世界里不该有枪／不该有法术／不该有海"的结果。按以下三层**由轻到重**处理，不要跳层。

| 层 | 手段 | 保留什么 | 换掉什么 | 例（把"海盗"搬进内陆荒漠世界） |
|---|---|---|---|---|
| **一层 · 换皮** | 只改名与外观 | 功能、动机、社会位置 | 名词、服饰、道具 | 海盗 → 沙道上的劫道客（船的替代品：改装货车） |
| **二层 · 换路** | 换达成方式 | 目的与后果 | 手段与机制 | 船 → 商队；封锁港口 → 封锁唯一的水源驿站 |
| **三层 · 换骨** | 整项替换 | 只保留它在结构里的位置（例如"这是第三方势力"） | 全部内容 | 掷一次表 1-2，取一个同等结构的替代物 |

#### 表 1-2 · 语境替换速掷（某张表整体不适用于当前世界时｜钩子密度：低）

**一句话用途**：当一个结果完全放不进当前世界时，用它找一个**功能等价**的替代品，保持它在剧情结构里的位置不变。

| d20 | 替代方向 | 它在结构里替换的位置 |
|---|---|---|
| 1 | 一家本地商行 | 有资源、但不中立的小势力 |
| 2 | 一座废弃设施 | 可探索、有遗留物的空间 |
| 3 | 一个行会或手艺人团体 | 掌握某项专门技术的中间层 |
| 4 | 一个家族 | 有内部继承纠纷的血缘组织 |
| 5 | 一个祭祀／研究团体 | 掌握禁忌或专业知识的边缘群体 |
| 6 | 一支驻军或巡防队 | 有合法性暴力但程序繁琐的力量 |
| 7 | 一群在本地谋生的外来者 | 既融入又被排斥的群体 |
| 8 | 一个债务人圈子 | 以人情与欠款为纽带的关系网 |
| 9 | 一处黑市或夜市 | 规则外但有秩序的交易场所 |
| 10 | 一条运输线（人、货、水、数据皆可） | 可被截断的动脉 |
| 11 | 一个被遗忘的官署／档案室 | 保存着旧真相的机构 |
| 12 | 一场正在进行的纠纷 | 双方都需要外力介入的冲突点 |
| 13 | 一处自然险地 | 不涉及人事的危险来源 |
| 14 | 一套本地技艺或秘方 | 可被学习或窃取的知识资产 |
| 15 | 一群孩子或少年 | 成年人忽视但无处不在的耳目 |
| 16 | 一个外来旅人 | 带来外地消息与误解的人 |
| 17 | 一件被多人争夺的物品 | 集中注意力的焦点物 |
| 18 | 一个季节性事件（集市、汛期、祭祀） | 给故事装上倒计时的日历锚点 |
| 19 | 一个已死之人留下的影响 | 仍在推动事情、但没有实体的力量 |
| 20 | 一条本地禁忌或规矩 | 限制所有人行为的无形边界 |

**这张表怎么用**：先定位原结果在剧情中的**功能位置**（它提供的是暴力、资金、知识、场所还是时间压力），再在本表里挑同位置的替代物。
**重复／不合场景时**：若掷到的行与原结果功能不同，不要硬套——**以功能为准再掷一次**；若连续两次仍不适用，直接从上述 20 行里挑功能最贴近的一条，不必再掷。

### 1.7 与内核数值的接口

> **这一节是本册的兼容契约。** 本册给出的每一个会落到桌面上的东西（一件武器、一个敌人、一笔钱、一个状态）都必须按下表翻译成 `01`／`02A`／`03` 的既有字段。**本册不新增任何数值规则。**

#### 1.7.1 六类接口总表

| 本册产出 | 落到内核的哪里 | 必须写明什么 |
|---|---|---|
| **伤害效果** | `01` 第四节伤害标签 | 十一种之一：斩击／钝击／穿刺／火焰／电击／寒霜／声波／腐蚀／力场／精神／熵蚀 |
| **临时效果** | `01` 第五节状态 | 状态名 + 施加方式 + 移除方式（沿用内核既有描述，不改数值） |
| **装备特性** | `01` 第四节性质标签 | 至少一个【】标签（如【近战】【单手】【共鸣】）+ 一句数值效果（幅度限制在伤害 ±1／DF ±1／Guard ±1 之内） |
| **敌人** | `02A` 第九节四档模板 + 词缀 | 档位（杂兵／标准／精锐／首领）+ 词缀清单（≤4）+ 预算 + 行为模式 + 破韧奖励 |
| **物品价格** | `03` 第五节物价层级 | 碎银 Tier 1／标准 Tier 2／贵重 Tier 3；以及稀有度五档之一（常见／普通／少见／稀有／唯一） |
| **人物关系** | `03` 第六节声望轴与羁绊 | 好感 −3~+3、敬畏 −3~+3、声望 −3~+3、羁绊 1–5，以及一行升降条件 |

#### 1.7.2 默认值 + 覆盖开关

本册坚持 `S0` 的写作禁令：不留"由主持人决定"。**凡是需要主持人判断的地方，给出默认值，并附一个可选的覆盖开关。**

```markdown
默认：随机护甲特性"镶嵌废旧板料"——Guard +1，移动 −1 米，标签【重装】。
覆盖开关：若所在世界模组已规定重甲的移动惩罚，以世界模组为准；若该世界没有金属加工
          （例如纯生物质世界），改用 Guard +1、标签【生物】，且在高温环境中 3 回合后失效。
```

> **给 AI 的提示**：读到"覆盖开关"时，**先采用默认值**；只有当上下文明确说明默认值与该世界冲突时才启用开关。不要主动启用。

### 1.8 AI 导引者加载简报

> 可直接粘贴进系统提示词。全文 800 字以内。

```
你是棱镜（PRISM）系统的导引者。现在加载《S7 随机生成器》工具箱。

使用原则：
1. 本册是素材库，不是规则。数值判定走 01/02A/02B，物价走 03，NPC 持久化走 04 的世界账本。
2. 需要即兴造人/造场景/造敌人/造任务时，先念出组合式（例如"3-1 + 3-5 + 4-1"），
   再一次性掷完所有表，最后统一改写为一段可朗读的描述。不要边掷边说。
3. 掷出的结果如果明显平淡，执行"具现"法：把形容词改成一个可见的动作、一个数字或一个物件，再念给玩家。
4. 重复结果处理：同一批人物内不许重样（侧移改写）；同一会话第三次命中同一行，烧掉该行并替换为新内容；
   跨会话的重复升格为固定世界元素（给它名字，写进账本的 npcs 字段）。
5. 与本世界冲突的结果：先换皮（改名与外观）→ 再换路（换达成方式）→ 最后换骨（整项替换，掷表 1-2）。
```

## 三、人物速成

> **本节 10 张表。** 目标是让人在三分钟内说出"这个人是谁、他要什么、他怕什么、他身上有哪样不协调的东西"。

## 五、场景速成

> **本节 8 张表。** 目标是让导引者在一分钟内说出"玩家拐进这条街，看到了什么、闻到了什么、能碰什么、哪里不对"。
> 主组合式：`表5-1（骨架） + 表5-2（气味与声音） + 表5-3（可交互对象）`，再掷 `表5-4（扭曲）` 或 `表5-8（不对劲）` 二选一作为味。
> 一个场景**最多叠两层**（见 1.3 纪律二）；超过两层会变得精巧但难以演出。限时场景再补 `表5-6（时间压力） + 表5-7（出口与封锁）`。

| 20 | 一个孩子的玩具，落在最不像孩子会出现的地方 |

**这张表怎么用**：`表5-3 + 表5-8（不对劲）`。对象是**问题的形状**，不对劲是**问题的味道**。"锁从里面锁上的箱子"本身就是谜面，不必再解释。
**【接口】** 可交互对象若会产出物品，按第 8 节定价并标【】标签；若会作为线索，按 `03` 第三节的"三线索法则"配两条旁证。
**重复／不合场景时**：同一场景掷到两个同型对象，把其中一个改成**"另一个的同款、但被动过"**（一排箱子中有一个被打开又合上）；若对象不合世界（没有"鸟笼"的荒原），用 1.4 **侧移**换载体（"死了很久的鸟"→"风干了很久的一只小兽挂在桩上"）。

**一句话用途**：给普通场景加一条"规则被改写"的设定，让玩家必须重新理解环境才能行动。

| d20 | 场景扭曲 |

| 8 | 这里的一切都停在同一个时刻 |
| 9 | 有人一直在暗处重复同一件小事 |
| 10 | 你走进来的路已经不见了 |
| 11 | 这里的规则和外面相反（冷即热、上即下） |
| 12 | 你在这里看到的是过去的某个片段 |
| 13 | 有一个位置，所有东西都不肯靠近 |

**这张表怎么用**：`表5-1 + 表5-4`（骨架 × 扭曲）。扭曲必须**改变玩家的行动方式**，否则就只是装饰——掷出后立刻问："因为它，玩家现在不能做什么、必须做什么？"
**【接口】** 扭曲若造成状态，使用 `01` 第五节既有状态（迟滞、沉默、恐惧等），不改数值；若造成规则层面变化，写进 1.7.2 的"覆盖开关"。
**重复／不合场景时**：同一会话第二次掷到同一条扭曲，把它**反向使用**（第一次是"声音传不出去"，第二次是"声音传得出去，而且传得比你应该被听到的更远"）；若扭曲超出当前世界的设定（硬科幻里出现"情绪影响重量"），先判定它是否属于该世界的裂隙（第 10 节），否则用 1.6 三层校准。

| 8 | 天刚亮，一切都显得过分明亮 |
| 9 | 空气有异味，待久了会不舒服 |
| 10 | 落着灰或沙，肉眼可见地积在肩头 |
| 11 | 时不时打雷，但不下雨 |

**这张表怎么用**：`表5-5 × 表5-6（时间压力）`。天气常常**本身就是**时间压力（潮水上涨、雷雨逼近、光线消失），两者可以合并叙述。
**【接口】** 恶劣环境给判定加 DF：轻度 +2、严重 +4（见 `02A` 第四节）；涉及伤害的天气（极寒、高温）按 1.7.1 给伤害标签（寒霜／火焰）。

| 5 | 毒或诅咒在人体内扩散 |

| 7 | 追兵每隔一段时间就逼近一点 |
| 8 | 谈判对象即将离开此地 |
| 9 | 证据会在某个时刻自动销毁 |
| 10 | 天气会在短期内恶化到无法行动 |
| 11 | 有人等着你给答复，过期不候 |

**这张表怎么用**：`表5-6 + 表5-7（出口与封锁）`。压力给"来不及"，封锁给"走不掉"，两者一起才有紧迫感。写场景时把压力**明码标在桌上**（"还有三次行动机会"），比含糊地催促有效。
**【接口】** 时间压力在账本里写成 `clock` 字段（例如 `{"pressure": "货轮三日内离港", "ticks": 3}`），每时段或每场景推进一格。
**重复／不合场景时**：同一场景有两个压力时，让它们**互相冲突**（要救人就得放弃证据），不要并列；若压力在本世界不成立（没有"潮水"的内陆城），用 1.4 **侧移**换载体（涨落的集市人流、收摊时间）。

**【接口】** 出口的解谜难度用 `02A` 第四节 DF 阶梯：简易 10、常规 12、有挑战 14、困难 16；多阶段拆解见同节"把大目标拆开"。
**重复／不合场景时**：若同一场景需要"封得更死"，让玩家**自己关上门**（他们为了掩护而堵住唯一的出口）；若出口太宽松、场景不紧张，直接从本表第 20 条取用。

## 六、事件与遭遇

> **本节 8 张表。** 目标是把"赶路"和"进城"这两段最容易被敷衍的时间，变成有事情发生的场景。
> 主组合式：`表6-1（路上遭遇） + 表6-6（误会来源）` 或 `表6-3（突发事件） + 表6-8（余波）`。
> 遭遇不是战斗代名词：本节一半以上的表是**非战斗**的（6-4、6-6、6-7），刻意用来打断"遇敌—开打—继续走"的单调节奏。

| 9 | 一个卖东西的摊子，摊主睡着了 |

## 七、敌体速成

> **本节 6 张表 + 1 个流程。** 全部基于 `02A` 第九节的四档模板与词缀表，**不新增任何数值规则**。
> 目标：**30 秒造出一个数值合理、有辨识度、能被玩家读懂的敌人。**
> 若只需要一个路人级的对手，跳过第 2 步（词缀），直接走第 1、3、6 步即可。

### 30 秒造敌：六步流程

```markdown
第 1 步 · 定档位   掷 d4，查表 7-1（杂兵/标准/精锐/首领）
第 2 步 · 加词缀   掷 d20，查表 7-2（可选；词缀 ≤4 个，预算累加）
第 3 步 · 定行为   掷 d20，查表 7-3（它怎么打）
第 4 步 · 定能力   掷 d20，查表 7-4（它的招牌招式与伤害标签）
第 5 步 · 定破韧   掷 d20，查表 7-5（被打崩时发生什么）
第 6 步 · 定掉落   掷 d6，查表 7-6（打赢给什么档位）
```

**收尾三件事**（必做）：① 查 `02A` 第九节取基础数值，按队伍等级累加缩放；② 预算 = 基础预算 + 词缀预算，对照 `02A` 第十节确认落在合理强度；③ 给它一个**能被念出口的名字**（用 表2-2 或 表2-8 拼）。

### 表 7-1 · 档位（d4｜生成第一步｜钩子密度：中）

**一句话用途**：先定敌人在故事里的重量，数值随之而来。

| d4 | 档位 | 基础数值（1 级基准） | 预算 |
|---|---|---|---|
| 1 | 杂兵 | 活力 12｜防护 12｜韧性 8｜攻 +3｜伤 1d6+1 | 1 |
| 2 | 标准 | 活力 26｜防护 14｜韧性 14｜攻 +5｜伤 1d8+2 | 3 |
| 3 | 精锐 | 活力 48｜防护 16｜韧性 24｜攻 +7｜伤 2d8+3 | 7 |
| 4 | 首领 | 活力 110｜防护 18｜韧性 40+3 层护盾｜攻 +9｜伤 3d8+4｜AP 4 | 20 |

**这张表怎么用**：`表7-1 + 表7-2`。档位决定"它不是随便打的"，词缀决定"它不好打在哪"。单场里首领的预算不得超过总预算 60%（见 `02A` 第十节）。
**【接口】** 队伍等级 2 级以上时，按 `02A` 第九节"按队伍等级缩放"表累加活力／防护／攻击／伤害修正。
**重复／不合场景时**：一场里掷出多个首领，只保留一个为首领，其余**降档为精锐**；若一场遭遇全是杂兵，按 `02A` 第十节使用"群战处理"（共享活力池）。

**一句话用途**：给敌人一个能被记住的招式，并顺手锁定它的伤害标签——每个结果都对应 `01` 第四节的一种伤害类型。

### 组装示例

> **示例 A · 1 级队伍的杂兵**
> 第 1 步 档位 d4 = 1 → 杂兵（12／12／8／+3／1d6+1，预算 1）。
> 第 2 步 跳过词缀（路人级）。
> 第 3 步 行为 d20 = 1 → "先潜伏，再扑向落单者"。
> 第 4 步 能力 d20 = 3 → 突刺【穿刺】，无视部分护甲。
> 第 5 步 破韧 d20 = 1 → 跪倒一回合，失去全部 AP。

> **示例 B · 5 级队伍的标准敌人**

## 九、任务与反派速成

> **本节 8 张表。** 委托 4 张（类型、隐藏动机、转折、失败的样子），反派 4 张（类型、计划、弱点、被击败后的真空）。
> 主组合式：`表9-1（委托类型） + 表9-2（隐藏动机） + 表9-3（转折）`；反派则 `表9-5（类型） + 表9-6（计划） + 表9-7（弱点） + 表9-8（真空）`。
> 一整套跑完，就是一条可以直接开演的支线；把 `表9-4（失败的样子）` 当结局分支预先写好，能避免临场慌。

### 表 9-1 · 委托类型（d20｜开场掷一次｜钩子密度：中）

**一句话用途**：一句话说清"这趟活要干什么"，是绝大多数支线的起点。

| d20 | 委托类型 |
|---|---|
| 1 | 护送——把一个人或一样东西送到目的地 |
| 2 | 寻找——找到一个失踪的人或物 |
| 3 | 取回——从危险的地方拿回一件东西 |
| 4 | 调查——弄清一件事的真相 |
| 5 | 保护——在限定时间内守住某人某地 |
| 6 | 清除——处理掉一个麻烦（人或非人） |
| 7 | 交涉——代表某人去谈成一件事 |
| 8 | 潜入——不惊动任何人地进入某处 |
| 9 | 营救——把人从困境里带出来 |
| 10 | 破坏——让某件事无法完成 |
| 11 | 追捕——抓住一个逃跑的人 |
| 12 | 收集——凑齐若干样本或材料 |
| 13 | 见证——作为中立者去证实一件事 |
| 14 | 传递——传递一条不能落纸的消息 |
| 15 | 调解——让两方停止争斗 |
| 16 | 打探——获取一条别人不肯说的情报 |
| 17 | 护送货物，并伪装其真实性质 |
| 18 | 兜底——替某人处理一件失败的旧事 |
| 19 | 试炼——证明某人是否值得信任 |
| 20 | 送葬——把一个人的遗体或遗愿送回去 |

**这张表怎么用**：`表9-1 + 表9-2（隐藏动机）`。委托类型是"明面上的任务"，隐藏动机是"真实的目的"；两者错位越大，这条线就越有嚼头。参考 `04` 第七节的**任务状态机**：dormant → offered → active → (succeeded_clean | succeeded_dirty | failed | expired)。
**【接口】** 每个委托写成一个显式状态机（见 `S0` 第七节 7.1）；起点与终点各写一条 flag。
**重复／不合场景时**：连续两个委托同型时，把第二个改成**"第一个的后续"**（护送完成后，要护送这个人回去）；若委托与本世界能力不符，用 1.4 **侧移**换实现方式。

| 4 | 他在借你们之手除掉一个自己不能碰的人 |
| 5 | 这件委托原本属于另一个人，被他截了下来 |
| 6 | 他其实是被胁迫来下委托的 |
| 7 | 他希望任务失败，好证明某件事 |
| 8 | 他要在你们完成任务的那一刻公开你们的身份 |
| 9 | 这件委托的目标，其实是他自己 |
| 10 | 他在替一个不在场的人试探你们 |
| 11 | 他需要一份"有人做过这件事"的记录 |
| 12 | 他知道这条路上有陷阱，却没提醒你们 |
| 13 | 他要的不是东西，是"东西被移动过"这个事实 |
| 14 | 他在拖延时间，为另一件事争取机会 |
| 15 | 他本人就是那个"失踪的人" |
| 16 | 他给出的情报有一半是假的，且他知道 |
| 17 | 他想让某个第三方欠你们的人情 |
| 18 | 他其实在保护委托人名单上的下一个人 |

**这张表怎么用**：`表9-2 + 表4-4（秘密）`。隐藏动机通常就是委托人的秘密；动机越"私人"，越应该在第 3 幕由他自己说出来，而不是靠调查揭穿。
**【接口】** 委托人作为 NPC 写进账本 `npcs`；其隐藏动机写进 `npcs[].mask` 与 `npcs[].drive` 的差异里。
**重复／不合场景时**：同一委托人多次委托同一动机，让动机**升级**（第一次是试探，第二次是摊牌）；若动机太隐晦、玩家根本无从察觉，给它留至少两条可被发现的旁证（表 5-3 的可交互对象）。

**重复／不合场景时**：同一任务需要两次转折时，让第二次**推翻第一次的解释**（"雇主是反派"→"雇主也是被利用的"）；若转折与玩家已经做出的选择冲突，改为**尊重他们的选择并升级后果**，不要抹掉。

### 表 9-4 · 任务失败的样子（d20｜预设结局分支｜钩子密度：高）

**一句话用途**：预先写好"搞砸了会怎样"；这是游戏剧本与小说大纲的根本区别。

| 8 | 你们被抓住了 |
| 9 | 成功，但你欠了一个不该欠的人 |
| 10 | 失败，且牵连了一整个地方 |
| 11 | 成功了，但成果被第三方夺走 |

**重复／不合场景时**：不让失败连续以同一种形式出现；若玩家已经"注定成功"，直接从第 20 条取用一次——让他们赢，但赢得毫无意义，制造反差。

**一句话用途**：决定这个反派是"该打的人"还是"难打的人"；真正难缠的反派通常让人无法痛快下手。

| 19 | 一个其实是你们阵营里的人 |
| 20 | 一个根本不存在的反派（恐惧本身） |

**这张表怎么用**：`表9-5 + 表4-1（对玩家的态度）`。反派出场时的态度决定玩家的第一印象——"把你们当成同类的人"用"好感 +1"出场，比直接宣战可怕得多。
**【接口】** 反派在账本里是 `nemesis` 条目：写清 `level`、`plan`、`next_move`（见 `04` 第三节）；若前身是盟友，从 `npcs` 迁入 `nemesis`。
**重复／不合场景时**：一个战役里不要出现两个同型反派，把第二个改成**"第一个的镜像"**（同为理想主义者，但选择相反的手段）；若反派太单薄，给他补一个"他也会为某样东西心软"的细节（表 3-9）。

### 表 9-6 · 反派的计划（d20｜一次一个｜钩子密度：高）

**一句话用途**：让反派在幕后**持续做点什么**，而不是原地等玩家上门。

| d20 | 反派的计划 |
|---|---|
| 1 | 先制造混乱，再以秩序之名接管 |
| 2 | 一步步切断目标的所有退路 |
| 3 | 把所有知情者灭口 |
| 4 | 用一场灾难掩盖一次转移 |
| 5 | 让对手互相消耗，自己坐收 |
| 6 | 用一个人质换取整座城的让步 |
| 7 | 先收买关键的人，再动手 |
| 8 | 把目标引到他最熟悉的地方动手 |
| 9 | 用假的胜利引对手深入 |
| 10 | 制造一个替罪羊，转移所有视线 |
| 11 | 让所有人的秘密互相牵制 |
| 12 | 在某个特定时刻引爆预设的装置 |
| 13 | 让牺牲看起来像是意外 |
| 14 | 通过控制供给（水、粮、药）来控局 |
| 15 | 一点点替换掉关键的几个人 |
| 16 | 让对手"自愿"走进陷阱 |
| 17 | 把真正的目标藏在次要目标后面 |
| 18 | 先毁掉钱，再毁掉信任，最后毁掉人 |
| 19 | 什么也不做，只等对手自己失败 |
| 20 | 计划其实还没定，他也在赌 |

**这张表怎么用**：`表9-6 + 表5-6（时间压力）`。把计划写成**可被玩家观测到的进度**（第 1 步已发生、第 2 步正在进行），玩家就会主动去阻止下一步，而不是被动接任务。
**【接口】** 计划映射为账本 `threads` 的 `progress` 与 `clock`；每完成一幕推进一格（见 `S0` 7.2 flag 表思路）。
**重复／不合场景时**：若计划与玩家行动完全无关，让它**被玩家的一次成功打断**，并让反派换一种更狠的做法（表 6-8 第 19 条）；若计划太复杂难以跟踪，压缩成三步，每步一个可见的迹象。

**【接口】** 弱点若对应战斗，按 `02A` 第九节的档位与词缀给出数值对位（如"无防备"= 该伤害类型抗性清零）；若对应剧情，写入任务状态机的一条 `active → succeeded_clean` 条件。

## 十、跨界与裂隙

> **本节 4 张表 + 2 个流程。** 用于把两个世界接起来——无论你是跑多世界战役，还是只想往现有世界里插一次"不该出现的东西"。
> 主组合式：`表10-1（入侵形式） + 表10-2（旅行代价） + 表10-3（错配）`；需要人时再补 `表10-4（跨界 NPC 的困境）`。
> 本节末尾另附 **一次性场景生成器（三骰法）** 与 **数字工具附录（JSON）**，供独立开发者直接取用。

### 表 10-1 · 异界入侵的形式（d20｜裂隙线开场掷一次｜钩子密度：高）

**一句话用途**：决定"另一个世界"以什么方式渗进来；形式决定玩家的第一反应。

| d20 | 异界入侵的形式 |
|---|---|
| 1 | 一小块"不是这里"的地面开始出现 |
| 2 | 某个人开始记得自己从未经历过的事 |
| 3 | 一种不属于本世界的生物悄然繁殖 |
| 4 | 一段本地的规则在某个区域失效 |
| 5 | 有人带回了一件不属于这里的物品 |
| 6 | 一个本地的传说开始真实发生 |
| 7 | 一段从别处传来的信号被接收到 |
| 8 | 有人在梦中被反复带往另一个地方 |
| 9 | 一个本地人突然能说一种不存在的语言 |
| 10 | 天气开始按另一套规律运行 |
| 11 | 某个已经死去的人，在另一个世界还活着 |
| 12 | 一处地点的空间开始比它应该的大 |
| 13 | 一种"外来"的情绪在人群中扩散 |
| 14 | 一件本地的器物开始自行运转 |
| 15 | 一个新的入口在无人看管的地方打开 |
| 16 | 有东西从两个世界的缝隙里漏了出来 |
| 17 | 本地的一部分开始向另一边"渗透" |
| 18 | 有人开始在两个地方同时出现 |
| 19 | 一个本地的孩子，名字多年前就被另一边登记过 |
| 20 | 一切从一句不该被说出的话开始 |

**这张表怎么用**：`表10-1 + 表5-8（不对劲）`。入侵的第一个迹象应当是**不对劲**，而不是"怪物出现"；让玩家先感到规则出了问题，恐惧才立得住。
**【接口】** 入侵形式对应 `01` 第四节的【熵蚀】伤害标签与第五节「熵染」状态；异界生物的敌体按 `02A` 第九节生成（常配"适应""隐伏"词缀）。
**重复／不合场景时**：多条裂隙线出现时，让它们**互相矛盾**（一处说另一处是假的），制造"到底哪个世界是真的"的疑问（见 表10-2 第 12 条）；若入侵太突兀，用 1.4 **嫁接**把它接到早已存在的一条旧设定上。

### 表 10-2 · 跨世界旅行的代价（d20｜一次跨界掷一次｜钩子密度：高）

**一句话用途**：让"去另一个世界"这件事有代价；没有代价的穿越会让一切张力消失。

| d20 | 跨世界旅行的代价 |
|---|---|
| 1 | 你会失去一个不属于你的记忆 |
| 2 | 你会带回一样不属于你的东西（且无法丢弃） |
| 3 | 你的名字在一边会被忘掉 |
| 4 | 你会多出一个"另一个版本"的自己 |
| 5 | 你的身体会在两边留下不同的痕迹 |
| 6 | 你在一边的年龄会开始与另一边不同步 |
| 7 | 你会开始听见另一边的声音 |
| 8 | 你会被一边的某个存在标记 |
| 9 | 你必须每过一段时间回去一次，否则会消散 |
| 10 | 你会失去对一段关系的记忆 |
| 11 | 你会被一边的规则约束（如必须说真话） |
| 12 | 你会逐渐无法分辨哪个世界是"真的" |
| 13 | 你会把一边的东西带进另一边（污染） |
| 14 | 你会欠下另一边一笔债 |
| 15 | 你会失去一项能力，换回一项别的 |
| 16 | 你会被两边同时拒绝，成为无处可归的人 |
| 17 | 你会带回一个跟随者，且他无法回去 |
| 18 | 你会在两边各留下一个无法解释的伤 |
| 19 | 你会开始忘记自己来时的目的 |
| 20 | 你什么都不失去，但世界记得你来过（代价延迟） |

**这张表怎么用**：`表10-2 + 表3-8（随身物件）`。代价要**可被记录、可被追讨**——第 2 条带回的东西、第 17 条带回的跟随者，都是能写进账本的实体，而不是一句设定。
**【接口】** 代价若造成状态，用 `01` 第五节（「熵染」「恐惧」「沉默」等）；若造成长期负担，用 `01` 第十二节「负担 Strain」；第 14 条的"债"写入账本 `debts`。
**重复／不合场景时**：同一角色多次跨界时，代价**累积**并逐渐指向第 12 或 19 条（分不清真假、忘了来意）；若某条代价玩家无法承受，改为延迟生效（第 20 条），先埋、后收。

### 一次性场景生成器（三骰法）

> **用途**：在任何一次会话的任意时刻，用 30 秒凭空造出一个"能立刻开演"的场景。不需要准备，不需要前情。
> **流程一页版**：掷三次骰，填进下表的三个空；再各掷一次"味"，场景即可开演。

```markdown
三骰法 · 一次性场景
────────────────────────────────
骰一 · 地点      表 5-1  场景骨架   → ______
骰二 · 扭曲      表 5-4  场景扭曲   → ______
骰三 · 事件      表 6-3  突发事件   → ______
────────────────────────────────
味（可选，各掷一次）
  · 气味与声音   表 5-2           → ______
  · 哪里不对劲   表 5-8           → ______
  · 出口与封锁   表 5-7           → ______
────────────────────────────────
收尾：用一句话把三者串起来念出来：
"你们走进〔地点〕，这里〔扭曲〕，就在此时〔事件〕。"
────────────────────────────────
```

**串接纪律**：

1. **地点在前，扭曲在中，事件在后。** 顺序不能换——先给玩家一个可以理解的空间，再打破它，最后砸一件事。
2. **扭曲必须改变行动方式**，不能只是氛围（见 表5-4 的用法说明）。
3. **事件必须留下余波**：掷一次 表6-8，把"这件事之后会怎样"写下来，作为下一次的引信。
4. **最多三骰 + 三味。** 再多就会产出精巧但演不出来的场景（见 1.3 纪律二）。

**示例（可直接朗读）**：
> 骰一 表5-1 = 4（一个挤满人的市场，没人抬头看你）；骰二 表5-4 = 13（有一个位置，所有东西都不肯靠近）；骰三 表6-3 = 7（有人认出了你，且大声叫破）；味 表5-8 = 2（这里的人从不看某扇门）。
> **开场白**："你们挤进这条市场，人声很吵，可没有一个人抬头看你们。摊位之间空着一小块地方，货物、人流、连风都绕开它走。就在你们试图绕过那块空地时，最里面靠墙的那扇门始终没人看上一眼——然后有人认出了你，高声叫出了你的名字。"

> **给开发者的三点提示**：
> 1. 每张表的 `die` 就是它的骰面；`rows` 中的 `roll` 是唯一键，可直接用于随机取值。
> 2. `interface` 字段是**与内核的唯一接口**：`type` 说明这条结果落到哪一类字段，具体数值一律回查 `01`／`02A`／`03`，本册不复制数值。
> 3. 由本册生成的 NPC、敌人、物品，建议在写入账本前先补一个稳定的 `id`，以便跨会话引用。
