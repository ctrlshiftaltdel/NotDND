## 一、核心设定

### 一句话

> **你在废墟上有一具身体，在网上有一个身份；两者都不完全属于你，而且它们正在慢慢分开。**

### 熵网是什么

**熵网（The Net）** 是坍缩后遗留下来的那片无法解析的数据区域。它不是一个"地方"，但所有人都把它当作地方来谈论。

- 普通终端无法进入它，进去的只有**网潜者 Diver**。
- 进去的人需要用**同步率**来维持自身意识不被稀释。
- 网里面有东西：被遗弃的意识、自动运行的旧程序、以及无法解释的结构。
- **从网里带出来的东西会成为现实。** 这是本模组最重要的一条法则：网潜不是"查资料"，它是**把某样东西从那边搬过来**。

### 坍缩

三十一年前，全球的数据网络在同一时刻进入了不可逆的降级。

- 没有战争，没有病毒，没有攻击。它只是**停止被理解**。
- 数据没有丢失——每一比特都还在硬盘上——但读取它们的结果毫无意义。
- 少数人发现，如果把自己的意识"调谐"到某个频率，就能在那片混沌中看到结构。这些人成为第一批网潜者。
- **坍缩至今仍在缓慢进行**：每年有约 0.3% 的可用数据沉入熵网。

### 十条设定信条

1. **身体是奢侈品。** 干净、健康、未经改造的身体属于极少数人。大多数人身上都有二手零件。
2. **记忆可以被编辑。** 因此"证明你是你"成为这个世界上最值钱的服务。
3. **财团取代了国家。** 智慧城市由企业管理，法律是服务条款，公民身份是订阅状态。
4. **网里的东西会出来。** 这是这个世界所有诡异事件的源头。
5. **改得越多，你越少。** 义体改造提升能力，同时消耗"自我"。这是可量化的。
6. **没有人能关掉任何东西。** 所有的系统都还在运行，只是没人知道它们为什么还在运行。
7. **废墟里有三十一年的旧东西，而且它们大多还能用。** 考古学在这个世界是一门工程学。
8. **身份可以交易。** 一个人的全部记忆与社交痕迹是一份资产，可以被抵押、出售、继承。
9. **你无法确认任何人是不是本人。** 包括你自己。
10. **关心别人是唯一还没有被标价的东西。** 这是这个世界的道德底线。

## 二、历史：坍缩与之后

| 年份 | 事件 |
|---|---|
| **31 年前** | **坍缩。** 全球数据网络在 11 分钟内完成降级。所有备份同时失效。 |
| **30 年前** | 「黑暗年」。城市的生命维持系统大面积失效。人口减少了约 22%。 |
| **29 年前** | 第一批网潜者出现。他们中的四分之三在三年内成为档案人。 |
| **26 年前** | 第一家义体厂商上市。身体改造开始普及。 |
| **22 年前** | **第一例回响体事件**。某个被带出网的东西在现实中维持了六天的存在。 |
| **19 年前** | 《身份资产法》通过。记忆与身份正式成为可交易资产。 |
| **15 年前** | 四大财团完成对六座主力城市的收购。主权概念事实上消失。 |
| **11 年前** | **熔毁事件**。一次大型网潜中，47 名网潜者的意识同时留在了网里。 |
| **7 年前** | 第一个「档案人工会」成立，主张被困在网中的人也拥有权利。 |
| **3 年前** | 熵网首次出现自发性的结构变化：它开始**自己生成内容**。 |
| **现在** | 熵网的扩张速度为每年 0.3%。有科学家估算，再过 90 年，现实与网的边界将不再可辨。 |

> **给导引者的长期伏笔**：熵网正在变快。它每年都在生成更多东西，而且它生成的东西越来越像**有意图的**。这就是这个世界最大的问题，而没有人知道答案。

## 三、地理：九个区域

### 1. 中枢城｜Core

> **氛围**：干净的，垂直的，被照亮的。所有东西都是订阅制。

四大财团总部所在地。这里的居民拥有 92% 的平均纯度——**他们几乎不改造自己，因为他们的身体本身就是资产。**

- **关键地点**：环柱（全城最高的建筑，也是数据中心）、服务大厅（法律在此以服务条款的形式存在）、纯度检测站（进入中枢城必须通过）
- **主要势力**：四大财团、纯度委员会
- **典型事件**：订阅被取消（等于法律意义上的死亡）、有人伪造纯度证明、有人在打听网潜者的下落

### 2. 环带｜The Belt

> **氛围**：管道，蒸汽，焊接的火花，以及数以万计的小招牌。

围绕中枢城的工业与生活环带，人口三千万。**绝大多数居民身上至少有三处改造。**

- **关键地点**：第九焊接区（最著名的义体黑市）、管道市场（什么都卖）、旧地铁改造的居住舱
- **主要势力**：十七个义体帮派、维修工会、社区自卫队
- **典型事件**：零件短缺、帮派收保护费、有人拿出了不该有的零件

### 3. 外场｜Outfield

> **氛围**：开阔，安静，风很大，以及大量三十一年前的遗留物。

城市之外的废墟带。这里是**考古者的地盘**：三十一年前的建筑、车辆、服务器全都还在，而且大部分还能启动。

- **关键地点**：旧数据中心园区（考古者的圣地，也极其危险）、第十三号仓库（传说里面有一台还在运行的服务器）、废弃高速公路（有帮派在此设卡）
- **主要势力**：考古行会、拾荒者、以及不知道是什么的东西
- **典型事件**：挖出可运行的旧设备、有人在那里待了太久、回来的东西不太对

### 4. 熔毁区｜Meltdown Zone

> **氛围**：没有声音，没有信号，仪表全部失灵。

十一年前那次事故留下的区域。半径 12 公里，至今无法居住。

- **关键地点**：事故原点（47 名网潜者的接入地点）、仍然在运转的应急设备、一圈永远不会亮的路灯
- **主要势力**：财团的封锁部队、私自进入者的尸体
- **典型事件**：设备自行启动、有人听见里面有人在说话、某个东西走了出来

### 5. 云端熔炉｜Forge Cloud

> **氛围**：不存在的物理空间，但所有人都知道怎么"去"那里。

网潜者的公共区域：熵网中一片相对稳定的结构。网潜者在此交换信息、交易、以及互相残杀。

- **关键地点**：中央索引（一片不稳定的档案海）、熔炉市集（什么都卖，包括意识）、47 号纪念区（那 47 人的意识残片仍在原地）
- **主要势力**：网潜者行会、档案人工会、不明结构
- **典型事件**：有人的意识没能回来、出现从未见过的新结构、某个档案人请求你带一样东西出去

### 6. 档案层｜The Archive Stratum

> **氛围**：一望无际的、无法分辨内容的档案。像雪。

熵网中最深、最平静、也最危险的一层。这里存放着坍缩之前的全部数据。

- **关键地点**：一个人的全部记忆（它被打包成了一份文件）、三十一年前的某一天（它仍然存在）、无法进入的部分
- **主要势力**：无。这里没有活人组织。
- **典型事件**：找到想要的东西、被某样东西注意到、意识到自己已经在这里待了很久

### 7. 港区｜Docklands

> **氛围**：集装箱，起重机，以及三十一年都没有停过的自动装卸。

自动化港口，至今仍在运作，且没有人给它下过指令。这里是对外贸易的唯一通道。

- **关键地点**：自动装卸区（无人但高效）、七号泊位（那里的船从三十一年前就没动过）、海关（由 AI 管理，且它很严格）
- **主要势力**：港务 AI、走私集团
- **典型事件**：来历不明的货物、有人想让你带一样东西过关、AI 提出了一个奇怪的问题

### 8. 医疗穹顶｜Dome

> **氛围**：白，安静，以及一种让人不太敢大声说话的体面。

义体医疗与纯度维护的中心。这里也是唯一能合法进行"身份备份"的地方。

- **关键地点**：备份厅（你可以把自己存起来，按月付费）、纯度恢复中心（极其昂贵）、不受监管的地下三层
- **主要势力**：医疗财团、一群试图让备份获得权利的激进者
- **典型事件**：备份到期（等于死亡）、有人试图恢复别人的备份、地下三层在做不该做的事

### 9. 无名区｜Unlisted

> **氛围**：地图上没有，导航到不了，但确实存在。

城市与城市之间的、未被任何系统登记的区域。**这里住着所有主动退出系统的人。**

- **关键地点**：断电村（完全不使用任何联网设备）、一个手工维护的电台、一位记得坍缩之前的人
- **主要势力**：退出者社区、一个自称"最后的人类"的老人
- **典型事件**：有人来寻求帮助、有人来抓人、有人只是想安静地死

## 五、世界特则：同步率、义体与网潜

### 同步率 Sync

**同步率**衡量你的意识与身体之间的耦合强度。它最重要，也最脆弱。

```
同步率上限 = 心智 + 洞察 + 4
```

#### 消耗与恢复

| 行为 | 同步率 |
|---|---|
| 网潜一轮（约 10 分钟） | −1 |
| 在网中受到一次意识冲击 | −2 |
| 使用需要接入的能力 | −1 |
| 在网中经历一次时间错位 | −3（网的十分钟是现实的一小时） |
| 现实中的长歇 | +2 |
| 在医疗穹顶接受校准 | +4（费用「标准」） |

#### 同步率下降的后果

| 同步率 | 表现 |
|---|---|
| > 60% | 正常 |
| 40–59% | 现实感变薄：所有察觉判定 −1 骰，且无法分辨梦与记忆 |
| 20–39% | **身份漂移**：你开始做出不属于自己的判断。导引者可以在此时替你决定一次行动 |
| 1–19% | **断线风险**：每次行动都有 20% 概率失去一整个回合 |
| 0 | **成为档案人**：你的意识留在网里，身体留在现实。两者都还活着 |

> **这是本模组最可怕的结局。** 一个档案人的身体会被医疗机构接管并对外出租；而他的意识会在网的某处继续思考。

### 纯度 Purity

**纯度**是你身上原生组织的比例，也是"还剩多少自己"的量化。

```
纯度起始 = 10
每次义体改造 −（改造等级）
```

| 纯度 | 表现 |
|---|---|
| 9–10 | 完整的人。在中枢城被视为上等 |
| 6–8 | 正常的大多数人 |
| 3–5 | 明显改造过的人。中枢城部分区域无法进入 |
| 1–2 | 大部分是零件。情绪反应迟钝，共感判定 −1 骰 |
| 0 | **不再被法律视为人。** 你成为财产 |

> **纯度是可以恢复的**，但极其昂贵：一次「原生重建」需要「贵重 ×5」，且需要三个月。

### 义体改造

每件义体提供能力，同时降低纯度。

| 义体 | 效果 | 纯度代价 |
|---|---|---|
| **光学模组** | 夜视、变焦、热成像 | −1 |
| **反射增幅器** | 先攻 +2，闪避 +1 骰 | −1 |
| **承重骨架** | 力量类判定 +2 骰，负重翻倍 | −1 |
| **皮下装甲** | 防护 +2 | −1 |
| **武器臂** | 内置近战武器（1d8） | −2 |
| **神经接口** | 可以直接接入设备，无需工具 | −1 |
| **记忆槽** | 可以存储并回放一段记忆 | −2 |
| **身份伪装模组** | 可以随时更换生物识别特征 | −2 |

> **改造的隐藏代价**：纯度每低于 5，你在共感、表演与说服上的判定各 −1 骰。**别人能感觉到你不太像人了。**

### 网潜 Diving

网潜是本模组的核心活动。它不是"查资料"，而是**进入一个地方**。

#### 网潜流程

```
1. 接入：需要一台终端（每个区域都有，费用不同）
2. 潜入：掷一次「同步」判定，决定你进入的深度与稳定度
3. 行动：在网中按回合行动，与现实相同的规则
4. 遭遇：网中的一切都是敌体或障碍
5. 带回：你可以带走一样东西（这是网潜的目的）
6. 退出：同步率结算，并检定是否留下了什么
```

#### 网潜中的时间错位

> **网中的十分钟，等于现实中的一小时。** 这个错位是本模组最有力的紧张装置：你在网里多待一会儿，现实世界就已经过去很久了。

| 网中时间 | 现实时间 |
|---|---|
| 1 分钟 | 6 分钟 |
| 10 分钟 | 1 小时 |
| 1 小时 | 6 小时 |
| 4 小时 | 一整天 |

#### 网中的三类遭遇

| 类型 | 说明 |
|---|---|
| **程序残骸** | 仍在运行的旧程序，通常不知道自己已经没有主人 |
| **档案人** | 被困的意识。他们可能求助、可能攻击、也可能只是想找人说话 |
| **回响体** | 从网里生成的东西。**它们想要出来** |

> **最重要的一条规则**：网潜者在网中死亡不会真的死，但会**永久损失 1d4 点同步率上限**。这是可累积的、不可逆的损耗。

## 八、协议

**协议（Protocol）**是本模组的能力体系。它的核心张力是：**一切能力都来自改造与接入，而它们都在消耗你的自我。**

### 三个等级

| 等级 | 消耗 | 说明 |
|---|---|---|
| **轻协议** | 1 点专注 | 义体内置功能，随时可用 |
| **中协议** | 2–3 点专注 | 需要接入与操作 |
| **重协议** | 3–5 点专注，或 1 点同步率 | 会让你的身体付出代价 |

> **同步率低于 40% 时，所有协议的 DF +2。** 你的意识已经不稳了。
> **关于 AP 列**：表中 AP 标为 `0` 的少数条目是**非战斗用途的自检／读值类协议**（如「同步检定」「微表情」）。它们不占用行动点，但照常消耗专注；若在战斗回合内使用，由导引者判定是否算作一次辅助动作（见 `01` 第 6 节的 AP 价格表）。

## 九、敌体图鉴

> **使用方法**：每份数据给出活力、防护、韧性、攻击加值与伤害。其余行为由 `04` 第 9 节的**战术人格六型**决定——每个敌体都标注了它的人格归属。
> **数值口径**：以 `02A` 第九节的四档模板为基准（杂兵 12／12／8／+3，标准 26／14／14／+5，精锐 48／16／24／+7，首领 110／18／40 + 3 层护盾／+9）**手工微调**：
> - 活力／防护／韧性允许在基准上下浮动约 2–6 点，攻击加值允许 ±1，用来表现个体差异；
> - **伤害骰按该单位的实际武器与攻击性质离散化**（徒手 1d4、短刃 1d6、长兵 1d8／2d6、重型与巨兽 2d10／3d10），因此表内不出现模板里的 `+1`／`+2`／`+3` 常数加值；
> - 首领的活力与韧性按其剧情分量上下调整，不另设预算表；
> - 真正的编队权重以第 10 节的遭遇表为准，不要在现场逐个加总。
> **等级缩放**：队伍等级提升时，按 `02A` 第 9 节缩放表累加。

## 十一、开场钩子

### 团构一：合作者（推荐给新手团）

> 你们被同一家中介雇去做同一件事：把一样东西从网里带出来。
> 中介没有告诉你们那样东西是什么，也没有告诉你们还有另外两支队伍在做同样的事。

**为什么好用**：目标明确、自带竞争、第一幕就能进网。

### 团构二：一群欠债的人（推荐给喜欢日常的团）

> 你们都在同一家医疗穹顶有未付的费用，而你们的备份将在同一个月到期。
> 一位陌生人提出：帮她做一件事，她替你们所有人续费三年。

**为什么好用**：赌注是自己的存在、关系由债务构成，且第一个抉择是"要不要相信她"。

### 团构三：被选中的人（推荐给有经验的团）

> 你们四个人的身份档案在同一个数据库里被标记为「已终止」，而你们都还活着。
> 要弄清楚谁做的，你们必须先接受一件事：**在法律上，你们已经不是人了。**

**为什么好用**：直接切入本模组最锋利的主题，且立刻让玩家失去所有体制内的保护。
