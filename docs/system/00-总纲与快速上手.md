## 一、这套规则想解决什么问题

传统桌上角色扮演规则诞生于 1970 年代的纸质媒介环境，它们做出了三个假设，而这三个假设在今天都不成立：

**假设一：桌边有一个人来即兴裁决。**
于是规则书可以大量留白，用"由主持人决定"来填空。当主持人是 AI 时，"由主持人决定"是一种负担而非自由——模型缺少稳定执行的默认路径，容易在不同会话间给出不一致的裁决。棱镜把留白填上进退有据的默认答案，同时保留覆盖开关。

**假设二： randomness 意味着掷一次骰，然后接受结果。**
现代数字游戏证明了"玩家可以主动干预随机性"更有趣：资源投入、 reroll 换取代价、把失败转化为另一种收益。棱镜让骰子成为可协商的对象，而不是判决书。

**假设三：战斗是一串"我攻击它，它攻击我"的循环。**
棱镜把一场战斗设计成一个**可拆解的谜题**：敌体有可被打开的破口、场地有可被利用的要素、队友之间有可触发的连锁、行动点有限因而每次选择都要付代价。这让第 50 场战斗和第 1 场一样需要动脑。

这套规则因此有三条主线：**可被机器稳定执行**、**玩家对随机性有能动性**、**战斗是可解谜题**。

## 二、十项核心信念

这十条是规则的宪法。遇到规则没写清楚的地方，回到这十条来判断。

**1. 失败必须推进。**
任何一次检定失败都不允许填答为"什么都没发生"。失败要么造成新的麻烦，要么以更高代价达成目标，要么揭示原本隐藏的信息。导引者若掷不出第三种方案，就从前两种里选。

**2. 玩家拥有主动权，主持人拥有反应权。**
玩家决定角色做什么、为什么做、以及承担什么代价。主持人决定世界如何回应，但不得替玩家决定角色的意图、情绪与私人事项。

**3. 数值是叙事的翻译层，不是叙事的主人。**
当一个 +3 修正和一个精彩的叙事理由冲突时，叙事理由优先获得解释权，修正其次。规则从不命令角色"你不可能做到"，只回答"你需要付出多大代价"。

**4. 每个数字都应当被理解为某种虚构事物的量化。**
活力点数下降不一定意味着流血，它可以是决心、体力、运气、清醒度的流失。主持人应当在叙事上给出当时的解释，玩家需要知道自己的角色"看起来怎么样了"。

**5. 玩家应当能看见系统的内部状态。**
敌人剩余韧性、当前气势、可能触发的能力——凡是玩家角色在虚构世界中"有理由感觉到"的信息，都应当明示。隐藏信息只限于"虚构上确实不可知"的部分。

**6. 一次会话应当有完整形状。**
有开场张力、中段恶化、高潮对峙、余韵收束。主持人对会话节奏负责，即使故事未完，每场都应有属于自己的起伏。

**7. 规则应当可被部分采用。**
本系统每一章都标注了"最小可行版本"。一个小组只需要最小值就能玩，多出来的部分是给想要深度的人的准备。

**8. 系统应当奖励多样性而非最优解。**
任何"一个明显最强的选择"都是设计缺陷。连携机制、场地要素、任务目标的多样性都是为了让不同角色类型在不同场合发光。

**9. 主持人有权也有义务调整难度。**
数值服务于体验。当一组玩家明显吃力或明显无聊时，主持人应当先调整敌人行为、场景要素与目标条件，最后才调整数值本身。

**10. 桌上的每个人都应当对规则有共同预期。**
在开始之前，主持人与玩家应当公开确认：这是一局什么样的游戏（口味、强度、边界、时长预期）。这一条比任何其他规则都重要。

## 三、一句话讲清规则怎么运转

> **玩家描述角色想做什么 → 导引者决定是否需要掷骰以及用哪项技能 → 掷骰并对照难度得出五档结果之一 → 结果的叙事后果被立即演出，并且状态写入世界账本 → 下一拍。**

其余所有内容都是这句话的展开。

## 四、术语速查

下面是全系统反复出现的词。它们对所有人通用，不因世界观改变。

### 角色与判定

| 术语 | 英文 | 含义 |
|---|---|---|
| **角色** | Actor | 由某位玩家操控的人物 |
| **敌体** | Adversary | 由导引者操控的对立方单位（含人形敌人、怪物、无人机等） |
| **导引者** | Conductor | 主持人。本系统假定由 AI 担任，人类亦可 |
| **属性** | Attribute | 六维基础能力，值为 1–10 |
| **技能** | Skill | 具体的应用领域，29 项，每项关联两个属性，取较高者使用 |
| **熟练** | Proficiency | 在某技能上受过专门训练，提供额外加值 |
| **判定** | Check | 掷骰来解决不确定性的一次结算 |
| **难度值** | Difficulty / DF | 判定需要达到的目标数，通常 6–24 |
| **对抗判定** | Contest | 双方各掷一次比较的直接较量 |
| **结果梯度** | Outcome Tier | 五档：灾难 / 挫败 / 险成 / 成功 / 凯旋 |

### 战斗与时空

| 术语 | 英文 | 含义 |
|---|---|---|
| **节拍** | Beat | 时间的最小单位，一次行动、一次转移或一次反应 |
| **回合** | Round | 所有参战者各完成一次自己的回合 |
| **行动点** | AP | 每个角色每回合 3 点，用于支付动作 |
| **过载** | Overload | 透支下回合的行动点，用于打出超过常规的一波输出 |
| **韧性** | Poise | 敌体承受"压制"能力的缓冲值，归零破防 |
| **破韧** | Break | 韧性归零后的状态，敌体失去行动能力并承受连携打击 |
| **连携** | Chain | 队友触发特定条件后插入的追加行动，可叠加层数提供团队增益 |
| **场地要素** | Site Element | 场景自带的可互动物或危险区，战斗开始前由导引者生成 2–4 个 |
| **掩护** | Cover | 地形提供的防护加成，三级：轻 / 中 / 重 |
| **态势** | Stance | 角色当前采取的攻防姿态，影响攻防取舍 |

### 资源与风险

| 术语 | 英文 | 含义 |
|---|---|---|
| **活力** | Vitality | 生命值，归零即陷入"濒危"状态 |
| **专注** | Focus | 施放能力与触发特殊机动的资源池 |
| **气势** | Tempo | 队伍共享的节奏资源，用于改写一次性不利结果 |
| **负担** | Strain | 长期累积的消耗，过高时会削减所有能力 |
| **决意** | Resolve | 可供花费以改写命运的有限点数，通常一次会话恢复一点 |

### 状态与词缀

| 术语 | 英文 | 含义 |
|---|---|---|
| **标签** | Tag | 附着于角色的性质描述，如【装甲】【奥术】【易挥发】，用于触发互动规则 |
| **状态** | Condition | 临时施加的负面或正面效果，如【灼烧】【失衡】【加速】 |
| **免疫 / 抗性 / 弱点** | — | 对某类标签伤害的完全抵抗 / 减半 / 加倍与额外效果 |

### 世界观模组专有词

三个模组对"能力"与"职途"各自使用不同词汇，以贴合调性：

| 模组 | 能力总称 | 入门职业称谓 |
|---|---|---|
| 阈界都市 | 共鸣式（Resonance） | 职途 |
| 余烬纪元 | 秘仪（Arcana） | 职途 |
| 熵网 | 协议（Protocol） | 职途 |

三者共用同一套机械语法，仅名称不同。

## 五、30 分钟开局流程

这一段给第一次接触本系统的人。按顺序做，30 分钟内可以开始跑第一幕。

### 第 0 步：确认预期（5 分钟）

导引者向全桌问五个问题，公开回答并记录：

1. **我们要玩什么世界观？**（阈界都市 / 余烬纪元 / 熵网）
2. **强度口味如何？**（残酷写实：死亡常见且不可逆；标准：有风险但不常团灭；英雄主义：角色很强，重在帅气）
3. **会话时长？**（一场 2–3 小时的一次性团 / 每周一次的长期战役）
4. **边界在哪？**（哪些内容不出现在桌上，例如 torture、特定恐惧话题、未成年人相关情节）
5. **你对角色的期待是什么？**（想当主角、想当配角、想搞笑、想认真）

> 这一步不能跳。大量跑团事故源于开场没对表。

### 第 1 步：做一张角色卡（10 分钟）

见 `01-内核CORE.md` 第 2 节。最快路径：

1. 六维属性用**点数分配法**：在 `2, 3, 3, 4, 4, 5` 这组默认数组上自由分配到六项。
2. 选一项**职途**（见所选世界模组）。职途给予起始活力、两项熟练、一个标志性能力。
3. 选 **2 个背景标签**，例如【前警员】【债务缠身】。标签会在叙事中提供助势骰。
4. 写一句**驱动**：“我的角色一定要 ______。”这是 AI 主持人最重要的输入。

### 第 2 步：导引者准备开场（10 分钟）

AI 导引者执行以下动作（这也是 `04` 中"会话初始化"的精简版）：

1. 建立世界账本 JSON 的空框架。
2. 抽取 1 个**开场钩子**（各世界模组第 10 节提供 d20 表）。
3. 抽取 2–4 个**场地要素**用于可能的首个场景。
4. 抽取 3 个**场景扭曲**（见 `08`）。
5. 用不超过 150 字设置第一幕：**谁在场、在哪、有什么不对劲**。

### 第 3 步：开跑（立刻）

> 不要等"准备好了"才开始。第一个场景可以粗糙，故事会在跑的过程中自己长出细节。

## 六、一场完整的示范回合

下面是使用**战术引擎**的一次战斗回合，展示所有核心部件如何咬合。这是理解本系统最快的方式。

**场景**：阈界都市，地铁隧道。四人小组正在对抗一只「噪涌体」（详见 `05`）——一只由城市噪音凝聚而成的共鸣生物。

```
【回合开始前】导引者已宣布场地要素：
  · 高压电轨（触碰造成 1d8 电击并【麻痹】）
  · 断裂的天花板（可被击中使其坍塌，大范围内【压制】）
  · 涌动的回声（任何大声造成的影响获得 +1 助势骰）

【回合 1】全员各掷先攻。

► 林岫（迅捷刀使 · AP 3）
   她宣言：“我冲上去，横切它的发声核心。”
   消耗 1 AP 位移（6 米），消耗 2 AP 执行【破军斩】。
   · 攻击判定：d20(14) + 灵巧(+2) + 熟练(+2) + 助势骰 d6(4) = 22
   · 敌体防护 DF 16 → 命中，且高出 6 点，触发【要害】
   · 伤害：1d10+2 = 9，噪涌体韧性从 8 降至 2
   · 导引者演出：“刀锋切开声浪的瞬间，隧道里所有声音熄灭了半秒。”

► 陈昭（扩音工程师 · AP 3）
   他抓住机会：“我把共鸣器接在整个隧道广播上，制造反向音爆！”
   · 这是【连携】机会：林岫刚造成【要害】，符合条件
   · 判定：技术 d20(9) + 心智(+3) + 熟练(+2) + 场景要素“回声”(+1d6=5) = 19
   · DF 15 → 成功。噪音共鸣被倒转
   · 效果：噪涌体承受 2 层【失衡】，韧性 2 → 0 → 破韧！
   · 连携层数 +1，全队下次攻击获得 +1 助势骰

► 噪涌体（已破韧）
   破韧状态下它无法行动，只能【挣脱】（DF 12）。掷出 11 → 失败。
   它还额外承受到【连携追击】：任何人在它破韧期间的攻击自动获得要害加成。

► 苏铭（重装调查员）
   “趁它摊成一团，我把那天花板给它砸下来。”
   · 攻击场地要素“断裂天花板”：DF 14，掷出 18 → 成功
   · 坍塌判定：大范围内 8 点钝击伤害 + 【压制】
   · 噪涌体已在破韧状态，自动失败相关豁免 → 受到全额伤害
   · 导引者：“混凝土砸下的巨响比刚才的噪音更像哭声。它散了。”

【结算】
   · 战斗在第 1 回合就结束——因为小队先合力把谜题拆开了
   · 这正确地奖励了协同：如果他们各自平A，噪涌体会多活三回合
```

注意这个示范中的关键设计：

- **场地要素不是装饰**，它是可以被主动攻击的对象。
- **连携**要求玩家彼此关注，而非排队行动。
- **韧性**给了"压制型"角色存在的意义：不是所有人都要堆伤害。
- **导引者每一次宣布成功都在附带叙事**，数字从不孤立出现。

## 七、给主持人：桌前五分钟 checklist

每次开跑前，把这五项过一遍：

- [ ] 世界账本里**当前场景**字段已填写（时间、地点、在场 NPC、可能的出口）
- [ ] 本场景**有至少一个明确的可交互对象**（可以是一扇窗、一个开关、一个情绪激动的路人）
- [ ] 本场景**有一条可被发现的线索**，且至少安排了三条独立路径通向它（三线索法则，见 `04`）
- [ ] 若可能有战斗，**已准备好 2–4 个场地要素**，且其中至少一个可以被玩家反过来利用
- [ ] 角色的**驱动**都记得。这一场里，至少给其中一位角色的驱动一个钩子

## 八、常见问题

**Q：AI 记不住长程剧情怎么办？**
答：这是 `04` 里"世界账本"要解决的问题。要求 AI 在每场结束时输出一段固定结构的 JSON（在场事实、已改变的状态、待兑现的伏笔），下一场开始时把它贴回上下文。棱镜把它写成硬性格式而非建议。

**Q：两套引擎能不能混着用？**
答：可以，但每位玩家在同一局里应固定使用一种。不同引擎的差别相当于两种不同游戏的数值表达方式。若转换，见 `02B` 附录的对照表。

**Q：能不能不用 AI，人类主持？**
答：完全可以。`04` 中除"上下文管理"一节外的所有内容（NPC 驱动轴、三线索法则、敌人战术人格、张力曲线）本来就是从好的真人主持技法提炼出来的。

**Q：世界模组之间能不能穿越？**
答：能。三套世界在 `08` 中提供了"裂隙互侵"随机表，专门为跨模组战役准备。但这需要主持人有较强把控力，建议跑过至少两个完整故事线之后再用。

**Q：数值平衡可靠吗？**
答：本系统的 DF、伤害与角色强度经过内部推定，但没有经历大规模实测。任何团体发现明显失衡，请依据第十项信念——先改行为，后改数值——并欢迎在衍生版本中调整。MIT 许可允许你这么做。
