# 03 · 互动层（Interaction Layer）

**探索 · 交涉 · 调查 · 工艺 · 经济 · 关系 · 据点 · 休整**

> 战斗很容易做得热闹，难的是让"不打的时候"也有同等密度。
> 本册把八个非战斗子系统做成有规则、有资源、有取舍的**可玩内容**，而不是过场。
> 导引者（尤其是 AI）应当主动把玩家推向这些系统——它们才是长线故事真正发生的地方。

## 一、探索与移动

### 时段结构

虚构时间以**时段（Watch）**为最小单位：

| 时段 | 大致時刻 | 特征 |
|---|---|---|
| **晨** | 05–09 | 警戒低，NPC 疲惫，光线变化大 |
| **昼** | 09–17 | 活动高峰，人多眼杂，交易便利 |
| **昏** | 17–21 | 交接班，边界模糊，社交良机 |
| **夜** | 21–05 | 危险高峰，隐蔽最佳，多数资源不可用 |

**每个时段**每个角色可以完成**一件大事**（大约需要 1–3 小时精力的事）或**若干件小事**（每件约 10 分钟）。

> 导引者应当主动询问并推进时段，而不是等待玩家申报。一个典型的会话应当消耗 3–6 个时段。

### 行程与移动裁定

| 行程 | 耗时 | 需要的判定 |
|---|---|---|
| **短程**（同城一个区到另一个区） | 1 时段 | 无，或特殊情况下的人脉／熟悉度判定 |
| **中程**（跨城、郊外深入） | 半天（2 时段） | 导航 DF 12 或载具操作 |
| **远程**（荒野、穿越被封锁的区域） | 全天 + | 生存 DF 14，且每段行程都做风险判定 |
| **危险穿越**（敌区、阈界裂隙、雷区） | 视情况 | 潜行／生存 DF 16，每 1 时段一次风险判定 |

### 风险池机制

> 这是个给导引者的工具：**让"路上不太平"变成可预期的紧张感，而不是随机骚扰。**

每当队伍进入移动状态，创建一个**风险池**：

```
1. 每次移动一个单元（约 1 时段），向池中放入 1 枚标记
2. 移动结束时，导引者掷 d6：
     掷出 6（或 5–6，取决于区域危险度）→ 触发一次遭遇或事件
3. 无论是否触发，触发后清空标记
```

**骰面调整**：安全区域用 d8（只有 8 触发）；危险区域用 d4（4 触发）。这让不同区域的紧张感可量化。

> **不发生事件的移动不能没有收获。** 若掷不出事件，导引者应当描述一个**有价值的见闻**——一支运输队、一处可以再利用的地形、一条传闻。移动应当推进故事，哪怕没有冲突。

### 迷路

迷路不应当是"惩罚"，而应当是"岔路"。

- 导航失败时，**不要**让队伍原地打转；而是让他们到达一个**意料之外但有趣的地方**。
- 迷路消耗 1 个时段，并给风险池增加 1 枚标记。
- 拥有【本土人物】类背景标签的角色，在其熟悉区域自动免除导航判定。

### 追踪

追与被追使用同样的规则：

| 线索新鲜度 | 追踪 DF |
|---|---|
| 刚刚离开（数分钟内），留有清晰痕迹 | 10 |
| 一小时前，痕迹被轻微破坏 | 13 |
| 一天前，痕迹混杂 | 16 |
| 数天前，仅有间接证据 | 19 |
| 只有传闻与二手信息化 | 22（应当改为调查而非追踪） |

成功的追踪会缩短距离；失败的追踪会让对方增加一个时段的领先。

### 扎营与安全

如果队伍需要在非据点的地方长歇，选择营地：

| 营地选择 | 效果 |
|---|---|
| **露天** | 无保护；夜袭风险池 +2 骰；恢复效果减半 |
| **有遮蔽** | 夜袭风险池 +0；正常恢复 |
| **有哨戒安排**（至少一人守夜） | 夜袭风险池 −2 骰，但该守夜者黎明前获得 1 层【疲惫】 |
| **有陷阱与警戒圈** | 夜袭者在接近时须通过潜行 DF 15，失败则全队获得预警 |

## 二、交涉论战（核心社交系统）

> 传统规则把说服做成一次掷骰：DF 15，掷过了就说服了。这让社交沦为最无聊的部分。
> 棱镜把重要的交涉做成一场**与战斗同等结构的交锋**——有立场、有防御、有资源消耗、有取舍。

### 什么时候使用论战

**只在重要的交涉上使用**。随意的寒暄、买东西、问路都不需要论战——那些用一次简单判定或直接叙事即可。

使用论战的三个条件，满足任意两条即可启用：

1. 这次交涉的结果会影响剧情走向；
2. 对方有理由拒绝你；
3. 你有超过一种说服路径可以选择。

### 论战的结构

```
对方立场 = 10 + (对方的心智或气场) + 场景修正
你的说服点 Persuasion Points = 3（起始）
```

**你的回合**可以做以下之一：

| 行动 | 消耗 | 效果 |
|---|---|---|
| **论证** | 1 点 | 进行一次说服／统率／分析判定。成功则削减对方立场 1d6 + 你的气场修正 |
| **施压** | 1 点 | 进行威胁判定。成功则削减 1d8，但对方好感 −1 |
| **共感** | 1 点 | 进行共感判定。成功则不削减立场，但**发现对方的一个 Lever（软肋论点）**，使下一次论证对该论点获得 +2 骰 |
| **伪装** | 1 点 | 进行欺骗判定。成功则你的下一次行动获得 +2 骰；失败则对方立场 +2 且你的说服力永久受损 |
| **让步** | 0 点 | 提出一个具体的利益交换。对方立场削减 1d10，但你欠对方一个明确的人情或资源（写入账本） |
| **收手** | — | 终止交涉，维持当前关系等级 |

**对方的回合**（在你的每次行动之后立即发生）会做以下之一：

| 对方应对 | 触发条件 | 效果 |
|---|---|---|
| **反驳** | 常规 | 对方掷一次对抗；若赢过你，你的说服点 −1 |
| **坚守** | 立场低于一半 | 对方立场 +1d6（相当于恢复） |
| **反问** | 你使用了伪装 | 你必须立即回应一次欺骗或分析，失败则交涉立即破裂 |
| **让步** | 立场低于 1/4 | 对方提出一项让步；你可以接受并终止，或拒绝并继续（此时对方立场 +0，且你获得 1 点额外说服点） |
| **破裂** | 你好感低于 −2 | 对方终止交涉，且此次相遇的所有后续判定 +3 难度 |

### 立场归零

立场降到 0 时，对方**接受你的核心诉求**。但要注意：

- 接受不等于喜欢。你可以得到他的协助，同时让他敬畏 −2；
- 导引者应当演出对方"不得不答应"时的具体反应——这是最有戏的部分；
- 若对方的敬畏低于 −2，他可能会事后报复，或者在下个场景中反悔。

### 好感与敬畏

除了立场，每个 NPC 对每位角色有两项持续值：

| 值 | 范围 | 含义 |
|---|---|---|
| **好感 Affinity** | −3 ~ +3 | 他喜欢你吗 |
| **敬畏 Awe** | −3 ~ +3 | 他怕你／敬你吗 |

这两项独立于任何单次论战，长期保持。它们决定：

- 好感高，对方会主动提供额外帮助与信息；
- 敬畏高，对方不会轻易反对你，但也不会真心帮你；
- 两者皆低，对方会敷衍甚至暗中使坏；
- 两者皆高，这是最稳固也最珍贵的关系。

### 论证素材：四条路径

要成功论证，你必须提出**具体的理由**。系统提供四种论证类型，对方的抗性与弱点取决于其人格：

| 论证类型 | 使用技能 | 对什么人有效 | 对什么人无效 |
|---|---|---|---|
| **利益** | 说服 / 分析 | 商人、官僚、务实者 | 理想主义者、狂热者 |
| **道义** | 说服 / 统率 | 有信念者、守卫、英雄型 | 犬儒者、绝望者 |
| **恐惧** | 威胁 / 统率 | 胆怯者、有弱点被抓住者 | 无所畏惧者、已有退路者 |
| **情感** | 共感 / 表演 | 有软肋者、孤独者 | 冷漠者、高度纪律者 |

> **导引者的职责**：在 NPC 描述中明确写出"哪种论证对他有效 / 无效"。这让玩家的"侦探出他的软肋"变成一个可获益的策略步骤，而不是猜谜。

### 简化的轻量版

如果你们不想在社交上花太多时间，使用**轻量版**：

```
进行一次说服判定：
  R ≥ +6  → 对方接受 + 主动提供额外帮助
  R ≥ 0   → 对方接受
  R = -1  → 对方接受但你欠一个人情
  R ≤ -3  → 对方拒绝且情况恶化
```

> 推荐：**轻量版用于日常 NPC；完整论战用于重要 NPC 与剧情关键时刻。** 同一个会话里通常只进行 1–2 场完整论战。

## 三、调查与线索

### 三线索法则

> **每一条玩家需要知道的结论，都应当至少有 3 条独立的途径可以获得它。**

这条法则是 AI 主持人最重要的安全网：它防止"玩家没找到那个唯一的线索导致整个故事卡死"。

导引者应当在准备阶段就把关键结论列出来，并为每条列出三条途径：

```
结论：「货柜 B7 里装的是活体，不是机械」
  途径 1：贿赂码头调度员查看清单
  途径 2：夜袭货柜，直接看到
  途径 3：追踪那辆运输车的行驶路线，终点是生物处理厂
```

### 线索呈现不需要判定

**关键线索永远不藏在判定后面。** 玩家可以主动说"我搜查这里"，那么只要线索确实在这里，他就应该找到，只是需要付出时间。判定只决定**额外收益**（找到得多快、有没有顺手拿到别的东西、有没有留下痕迹）。

### 调查的四种动作

| 动作 | 技能 | 获取 |
|---|---|---|
| **勘察现场** | 察觉 | 物理痕迹、遗留物、异常之处 |
| **访谈知情人** | 说服 / 人脉 / 共感 | 口述信息、传闻、动机 |
| **调阅记录** | 数据 / 分析 / 历史 | 文档、时序、矛盾点 |
| **复现与实验** | 科学 / 技术 / 分析 | 验证假设，排除不可能 |

> 一个有价值的调查场景应当至少包含**两种**动作路径，让不同技能类型的角色都能发光。

### 推理板

给玩家一个可见的"案件板"（实体便签或共享文档）：

1. 每条获得的线索都写上去；
2. 玩家可以自由提交**假设**；
3. 导引者收到假设后必须回应以下三者之一：
   - **成立**：这确实就是答案（或非常接近）；
   - **需要更多证据**：指出还需要哪一种线索；
   - **不成立**：诚实指出它不成立，并说明为何（给出反证的线索）。

> **永远不要用"你自己猜吧"来回应。** AI 主持人最常见的失误就是把推理环节变成让玩家自言自语。

### 错误的线索与被误导

投射以上并非所有信息都可靠：

- 导引者可以给出**误导性线索**，但必须留下可被发现的矛盾；
- 玩家用「分析」或「直觉」判定可以发现矛盾（DF 14）；
- 被误导应当带来**有趣的岔路**，而不是纯粹的损失。

### 调查的时间压力

给每个调查一个**倒计时**（见下方的时间压力表），让"多花时间查清楚"与"赶紧行动"成为真正的取舍。

| 压力类型 | 机制 |
|---|---|
| **追捕者** | 每 2 个时段，追捕者向你们逼近一步 |
| **截止期限** | N 个时段后机会消失 |
| **恶化** | 受害者状况每时段恶化，影响结局质量 |
| **竞争** | 另一组人也在查同一件事，进度并行推进 |

## 四、工艺与制造

让"我造东西"成为一条可行的角色路线，而不只是一句设定。

### 制作的三要素

每件物品需要三样东西：**蓝图 · 材料 · 工时**。

**蓝图**：可以从势力、导师、废墟、数据库中获得；稀有度分为 普通 / 进阶 / 稀有 / 唯一。

**材料**：从场景中获取，或从市场购买。材料有自己的品质等级（-1 / +0 / +1）。

**工时**：以"工作时段"为单位，每个等级的物品需要不同工时。

| 物品等级 | 工时 | 工艺 DF | 需求 |
|---|---|---|---|
| 简易（绳子、陷阱、简易药品） | 1 时段 | 10 | 无 |
| 标准（常规武器、通信设备、护符） | 3 时段 | 13 | 工作台 |
| 精良（改造武器、专业设备、共鸣增幅器） | 1 天（3 时段） | 16 | 专业工坊 |
| 杰作（独一无二的作品） | 3 天 | 19 | 稀有材料 + 专业工坊 + 一次灵感场景 |

### 品质等级

判定结果决定成品品质，**品质直接影响物品的数值**：

| 结果 | 品质 | 效果 |
|---|---|---|
| 凯旋 | **杰作品质** | 伤害／效果 +2，或一枚额外插槽（构建引擎） |
| 成功 | **精良品质** | 伤害／效果 +1 |
| 险成 | **标准品质** | 按蓝图数值 |
| 挫败 | **粗糙品质** | 数值 −1，且每次使用场景故障时 d20 掷 1–2 触发故障 |
| 灾难 | **失败品** | 材料损失一半，且可能在使用时反噬 |

### 改造现有装备

玩家可以改造已有物品，为其增加或改变**标签**：

| 改造 | DF | 效果 |
|---|---|---|
| 加装瞄准／校准 | 13 | 远程武器 +1 骰或 −1 DF |
| 加装护片 | 12 | 护甲 Guard +1，移动 −1 米 |
| 元素镀层 | 15 | 攻击获得某个伤害标签（火焰／电击／腐蚀等） |
| 减轻结构 | 14 | 移除【重装】标签或减负载 |
| 模块插槽（构建引擎） | 17 | 为该物品增加 1 个符纹插槽 |

> 每个物品**最多 3 次改造**，之后结构不稳定。这条限制防止一件武器成长为吞食所有资源的黑洞。

### 三个世界各自的工艺风味

| 世界 | 工艺名称 | 特性 |
|---|---|---|
| 阈界都市 | 共鸣调谐 | 制作过程可能引入不稳定的【共鸣】副作用 |
| 余烬纪元 | 符文锻造 | 与沉默的神祇残余共鸣，成功率受月相影响 |
| 熵网 | 义体改装 | 每次改装都涉及身体的取舍（牺牲某个属性换取功能） |

## 五、经济与物价

棱镜不使用"精确银币"式的繁琐记账，而是采用**三层货币 + 稀有度**的抽象模型。这既能表达贫富差距，又不会让桌面陷入算术。

### 货币层级

| 层级 | 相对价值 | 举例（阈界都市） |
|---|---|---|
| **碎银** Tier 1 | 1 | 一顿饭、一趟地铁、一次性消耗品 |
| **标准** Tier 2 | 10 | 一件普通武器、一周的住宿、一次小额贿赂 |
| **贵重** Tier 3 | 100 | 专业设备、稀有材料、一个月的安全屋租金 |

> 角色卡的"持有资金"用一个等级表示：**赤贫 / 拮据 / 普通 / 宽裕 / 富有**。每次大额消费后可能降级。这避免了精确记账。

### 物价参考

**【可替换】** 各世界模组提供自己的物价清单；以下是通用底稿。

| 物品 | 层级 |
|---|---|
| 一顿饭、一瓶药剂、普通衣物 | 碎银 |
| 常规近战武器、通讯器、标准护甲 | 标准 |
| 弹药一箱（20 单位）、一晚的安全住宿 | 标准 |
| 精良武器、专业工具套装、稀有材料一份 | 贵重 |
| 杰作品、改造义体模块、共鸣增幅器 | 贵重 ×2–5 |
| 一栋小型安全屋 | 贵重 ×10 |
| 一辆载具 | 贵重 ×3 |

### 讨价还价

价格不是固定的。一次简单的**说服／人脉**判定（DF 12）可以：

| 结果 | 折扣／加价 |
|---|---|
| 凯旋 | 对方给 −30%，并且附赠一件小东西 |
| 成功 | −15% |
| 险成 | −10%，但你欠对方一个人情 |
| 挫败 | 原价，且对方印象转差 |
| 灾难 | +20%，且对方可能记住你并向第三方透露 |

> 只有在**独立商人、黑市、个人对手**处可以讨价还价。连锁店、机构与自动贩卖系统不支持判定。

### 稀有度与获取

物品按可获得性分五档：

| 稀有度 | 获取方式 |
|---|---|
| 常见 | 任何地方，随买随有 |
| 普通 | 需要找对商店，偶尔缺货 |
| 少见 | 需要人脉判定（DF 14）或特定区域 |
| 稀有 | 需要人脉 DF 17 + 一个引荐，或完成一项委托 |
| 唯一 | 必须是某个任务的奖励，或某个特定人物的持有物 |

### 债务

债务是一个很好的故事引擎。规则如下：

- 借债可以立刻获得资金，但每经过一个**章节**，债务增加未偿还额的 20%；
- 债主会在剧情中自然出现——他们是最好的"免费反派"；
- 未偿还债务导致该债主对你的敬畏 +1、好感 −1（每次催收）；
- 偿还债务应当成为一次叙事事件，而不是转账。

### 收入来源

角色可以通过下列方式获得收入：

| 方式 | 收入 |
|---|---|
| 完成委托的酬劳 | 视任务而定，通常碎银 ×d6 到标准 ×d6 |
| 出售战利品（敌人装备、材料） | 按稀有度定价 |
| 间幕副业 | 每次间幕掷一次，结果受相关技能影响 |
| 据点经营收益 | 见第 7 节 |

## 六、声望与关系网

### 声望轴

玩家角色对每个重要势力都有一个**声望值**，范围 −3 到 +3：

| 值 | 含义 | 表现 |
|---|---|---|
| +3 | 崇敬 | 该势力会主动提供支援、透露内部信息、为你背书 |
| +2 | 友好 | 提供折扣、情报、通行便利 |
| +1 | 认可 | 不会被为难，可以求助 |
| 0 | 中立 | 按规则办事 |
| −1 | 警惕 | 额外审查、更高的价钱、更长的等待 |
| −2 | 敌视 | 拒绝服务、可能刁难、会记录你的行踪 |
| −3 | 仇寇 | 主动阻挠、悬赏、派遣人员处理你 |

> 声望变化应当被**明确宣布**。导引者说"你对港务局的声望降到 −2"，这比悄悄记账更能让玩家感受到后果。

### 人脉关系 Bond

与个人的关系不同于对势力的声望，用**羁绊等级 1–5** 表示：

| 等级 | 称呼 | 你可以向对方要求的 |
|---|---|---|
| 1 | 点头之交 | 回答一个简单问题 |
| 2 | 熟人 | 帮忙跑腿、提供一个消息 |
| 3 | 朋友 | 借用资源、冒一点风险帮你 |
| 4 | 挚交 | 为你撒谎、动用自己的关系网、提供藏身处 |
| 5 | 生死之交 | 为你违抗自己的组织、替你顶罪、替你挡刀 |

每次使用关系时，玩家可以提出请求。导引者按以下原则裁定：

- 请求在等级范围内 → **默认答应**，但可能需要付出时间；
- 请求略微超出等级 → 需要一次说服判定，且成功会让羁绊等级可能下降；
- 请求严重超出等级 → **默认拒绝**，但如果剧情上有必要，可以让对方提出一个交换条件。

### 关系的维持

关系如果不被使用，会随时间衰减：

- 每个**章节**结束时，未被联络的关系进行一次判定（或简化：每三个章节 −1）；
- 关系的破裂通常源于：被利用、被忽视、被牵连、价值观冲突。这些应当成为**具体的场景**，而不是悄悄改数字。

### 敌对者 Nemesis

当某个 NPC 对你的好感降到 −2 以下，他成为**敌对者**。敌对者应当：

1. 有自己的目标与进度（不只是等待玩家）；
2. 在幕后推进自己的计划，偶尔以间接方式出现在剧情中；
3. 最终与玩家正面遭遇。

> **给 AI 的提醒**：敌对者是最好的长期结构。每完成一个重要章节，考虑提升某个既有敌对者的级别，而不是再造一个新反派。

## 七、据点经营

当队伍积累资源后，据点会成为他们的第二角色。

### 取得据点

据点可以是：一间仓库、一栋旧公寓、一艘船、一座废墟中的塔、一个被遗忘的地铁站控制室。

取得通常需要：一次性的资金／人情支出 ＋ 一次清除或谈判的场景。

### 设施类型

每个据点可以建设最多 5 个设施（受空间限制）。

| 设施 | 建造成本 | 效果 |
|---|---|---|
| **安全居所** | 贵重 ×2 | 长歇效果提升；负担恢复 +1 |
| **工坊** | 贵重 ×3 | 精良及以下物品可在此制作；修理装备 |
| **情报站** | 贵重 ×4 | 每次会话可免费获得一条传闻；数据的判定 +1 骰 |
| **医疗室** | 贵重 ×3 | 短歇恢复提升；可以移除一层创伤（每次会话一次） |
| **仓储** | 标准 ×5 | 存储物资；隐藏违禁品的能力提升 |
| **训练场** | 贵重 ×3 | 间幕训练效果翻倍；可以更快地学习机动 |
| **伪装门面** | 贵重 ×2 | 据点被发现的概率降低；提供合法收入 |
| **动力／供应系统** | 贵重 ×5 | 其他设施的效能 +1 档（最多 +1） |

### 维护成本

每个据点每个章节需要支付**维护费**（通常贵重 ×1，视规模）。未支付时：

- 第一次：设施随机停用 1 个；
- 第二次：据点声望下降，可能出现入侵者；
- 第三次：据点被查封或被他人占据。

> 维护费是一个优秀的故事引擎：它逼迫队伍在"安定的后方"与"冒险赚钱"之间来回。

### 据点事件表（d20）

每个章节开始时掷一次：

| d20 | 事件 |
|---|---|
| 1 | 房东／债主找上门，要求补缴 |
| 2 | 有人趁夜潜入，但未造成损失（留下线索） |
| 3 | 一位旧识前来投靠，请求庇护 |
| 4 | 设施中的一个发生故障，需要修理（消耗材料） |
| 5 | 邻居开始对你们的活动产生怀疑 |
| 6 | 一封匿名信件送到，内含一条重要情报 |
| 7 | 某个势力提出收购据点，价格优厚 |
| 8 | 发现了据点前任主人留下的隐藏隔间 |
| 9 | 一次小规模冲突就在门口发生（你们被动卷入） |
| 10 | 有人在据点附近长期监视（可察觉 DF 15） |
| 11 | 资源价格上涨，维护费临时翻倍 |
| 12 | 一名受伤的陌生人倒在门口 |
| 13 | 某个派系主动示好，赠送礼物 |
| 14 | 内部成员之间发生争执，需要调解 |
| 15 | 据点被发现隐藏着违禁物（可能是栽赃） |
| 16 | 一个孩子／少年试图偷窃据点的东西 |
| 17 | 政府／机构例行检查，需要应付 |
| 18 | 一位专家愿意用服务换取在此工作的权利 |
| 19 | 据点的某个设施意外升级（前任主人的遗留） |
| 20 | 一次意外的好运：发现了一大笔被遗忘的物资 |

## 八、休整与间幕

### 间幕的时机

在下列节点插入间幕：

- 每次会话结束时；
- 每个章节结束时（大修整）；
- 剧情中出现超过一周的时间跳跃时。

### 间幕行动

每位角色在间幕中可以选择**一项行动**（大修整可以选择两项）：

| 行动 | 效果 |
|---|---|
| **训练** | 学习一项新机动或能力；需要找到导师或资料 |
| **康复** | 移除一层创伤或降低负担 1 点 |
| **社交** | 提升与某个 NPC 的羁绊，或结识新关系（我会掷一次决定结果） |
| **副业** | 赚取收入，金额由相关技能判定决定 |
| **制作** | 进行一次工艺活动（见第 4 节） |
| **研究** | 针对一个明确的问题推进调查，导引者必须给出实际进展 |
| **偿还** | 处理债务、人情或遗留问题 |
| **维护关系** | 防止关系衰减，或者主动修复一段恶化的关系 |
| **个人事务** | 一个有叙事意义但不涉及主要剧情的目标（例如：回家参加葬礼、寻找失散的亲人） |

> **"个人事务"是最被低估的选项。** 它给了 AI 主持人一个天然的机会去创造只属于某个角色的支线，这是让玩家感到被看见的最佳手段。

### 并行叙事 Vignette

每个间幕，导引者应当为**至少一位角色**演出一段 100–200 字的个人小场景，可以是：

- 训练过程中的一个失败与领悟；
- 与某个 NPC 的一次简短互动；
- 一个与主线无关的、揭示角色私生活的瞬间；
- 一个伏笔的暗示。

> 这些小场景片段不需要掷骰，但它们决定了这场战役在玩家记忆里是"一串任务"还是"一段人生"。

### 时间跳跃

跳过较长的时间时：

1. 导引者宣布跳过的时间长度；
2. 每位玩家简要描述这段时间自己做了什么（一句话即可）；
3. 导引者为这段时间发生的**世界变化**做一次概述（一到三个要点）；
4. 结算：维护费、关系衰减、负担恢复、势力的动静。

### 章节结构建议

```
一个章节 = 3–5 次会话
         = 一条主线 + 1–2 条个人支线
         = 一个明确的起承转合
         = 结束时：1 次升级 + 1 次大修整
```

## 九、非战斗团队协作

连携机制存在于战斗中，非战斗也需要等价物。

### 协助链 Assist Chain

当一个角色在某项任务上行动时，其他角色可以提供协助。规则如下：

1. 协助者必须**描述具体的帮助方式**（"我用手电帮他照亮"而不是"我帮他"）；
2. 一次任务最多接受 **2 次协助**；
3. 每次成功的协助提供 **+1 枚助势骰**（构建引擎：+1 枚骰）；
4. **协助也需要判定**（DF 由协助的具体性质决定）：成功才提供增益，但**失败不会连累主行动者**。

> 最后一点很重要：协助失败不惩罚主行动者，这让协助始终是正期望的选择，鼓励团队合作。

### 集体检定

当全队共同参与一项工作时（合力推门、集体潜入、一起说服一个人群），采用**集体检定**：

```
1. 每个人各自掷骰；
2. 统计成功的人数占比；
3. 占比 ≥ 2/3 → 团队级别的凯旋；≥ 1/2 → 成功；≥ 1/3 → 险成；低于 1/3 → 挫败。
```

集体检定让每个角色都有参与感，也让"队伍里谁也帮不上忙"的尴尬场景消失。

### 分工动作

在非战斗场景中，玩家可以执行以下组合动作，它们比各自为战更高效：

| 组合 | 参与者 | 效果 |
|---|---|---|
| **声东击西** | 2 人 | 一人制造骚动，另一人的潜行判定获得 +2 骰 |
| **前后夹击** | 2 人 | 在探索时覆盖两条路线，发现事物的概率翻倍，且可以互相策应 |
| **红白脸** | 2 人 | 在交涉中一人施压、一人安抚，对方立场额外削减 1d6 |
| **掩护撤离** | 全队 | 撤退时不丢下任何人，且追击者的判定 −1 骰 |
| **技术支援** | 1 技术支持 + 1 行动者 | 行动者每次尝试获得一次重掷机会 |
| **交叉验证** | 2 人（两名不同技能的知识角色） | 调查中的一条线索若两人都认可，则必定为真 |
| **集体伪装** | 全队 | 一次欺骗判定可以覆盖所有成员，但任一成员的行为异常都会导致整体暴露 |

### 情报共享机制

为了避免"只有 GM 和一个玩家知道某件事"的低效局面：

- **默认假设**：角色之间会分享重要情报。发现线索的玩家不必"表演转述"，其他角色**自动知晓**。
- **例外**：当某个角色有明确的保密动机时（隐瞒真相、私下来往），可以要求私下交流。这需要在叙事上给出理由，而其他玩家应当乐意配合这段演出。

> **这条规则让桌面效率提高一倍。** 热衷秘密的团可以关闭这条默认，改为“必须明确告知”；但对于由 AI 主持的团，强烈建议开启默认共享。
