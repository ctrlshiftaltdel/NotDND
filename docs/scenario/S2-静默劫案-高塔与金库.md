## 一、核心设定

### 一句话钩子

> 城里最值钱的东西都锁在柜里。**柜从来不是问题——问题是你带着它走下九阶的那条路。**

### 世界是什么

**云脊城**（The Yunji Spire）建在一道近乎垂直的巨型岩脊上。它不向外扩张，只向上与向下生长。

城市沿崖壁层层挑出，形成 **九阶**。冠台在海拔两千九百六十米处，井底在四十米处。**富人往上，机械往下。**
住在第几阶，就是你在这个城里是谁：阶籍写在通行证上，写在婚约上，写在讣告的第一行。

支撑这座城运转的不是法律，是 **柜**。

柜不是保险箱。柜是一间房、一层楼、一段被单独封起来的空间——由 **静默社** 设计、建造与维护，拥有自己的锁序、自己的哨械、自己的账目。全城在册的柜有二百一十七座，其中十二座是登记为「重柜」的高安保据点。人们不信彼此，只信柜。金衡行抵押的是柜里的东西，白壁行拍卖的是柜里的东西，守夜局守卫的也是柜里的东西。

于是城里有了第二种职业：**开柜的人**。

玩家是一支盗窃团伙。接活、踩点、动手、撤离、销赃。他们有雇主、有内应、有买家、有同行竞争者、有失主。
他们会在十个不同的柜里进进出出，每一次都面对同一道真正的考题——**不是怎么进去，是怎么出来，以及出来之后谁在等他们。**

而在所有柜之下，藏着一座不属于任何阶的柜：**元柜**。二十年前它被封，九枚权钥散入城中九座柜。
有人正在一枚一枚地，用别人的手，把它们捡回来。

### 十条设定信条

| # | 信条 | 它在本册如何落地 |
|---|---|---|
| 1 | **高度即等级。** | 阶籍决定通行、物价、住宿与法律援助。下阶人上不去，上阶人下不来。 |
| 2 | **柜比人可靠。** | 人们相信柜。因此"打开一个柜"在本城既是技术行为，也是渎神行为。 |
| 3 | **静默是商品。** | 安静可以被买、被制造、被消耗。见第 5 节「静默值」。 |
| 4 | **每一件赃物都有一个失主，每个失主都有一段记性。** | 每件赃物自带一条「失主线」，见第 11 节赃物表与第 12 节线索网。 |
| 5 | **雇主永远比你知道得多。** | 任何委托都有隐藏条款，用第 11 节《雇主隐藏动机表》掷出。 |
| 6 | **进去从来不是问题，出来才是。** | 每个据点的撤离段难度 ≥ 潜入段。这是本册的结构原则。 |
| 7 | **城是活的，而且已经超载了。** | 九阶的承重有上限，理事会知道，市民不知道。这是贯穿暗线。 |
| 8 | **锁匠不偷东西，他们只是记得门原来的样子。** | 静默社的职业道德：开过的柜必须恢复原状，否则视为宣战。 |
| 9 | **你出手的那一刻，就成了别人的踩点对象。** | 每个据点完成后，掷一次《同行竞争者反应表》。 |
| 10 | **没有干净的分账，只有还没被追到的那一份。** | 分账永远产生后续，见第 11 节《分账纠纷表》。 |

### 三段可直接朗读的导引者开场白

**开场一（战役起点，灰市，雨夜）**

> 灰市的雨是从上面漏下来的。五阶没有天，只有六阶的地板缝。你们坐在绳会账房的后间，桌上摆着一盏灯、三只杯子、和一个没开口的木匣。温苔把木匣往中间推了半寸，说：白壁行有个活。只偷一样东西，东西在四阶判牍阁的档案柜里，名字她不能说，说了你们就不接了。她笑了笑。她从不说不能说的是什么——她只说，价钱是你们去年一年加起来的三倍。窗外有人顺着检修井的钢索滑下去，速度很快，手上有钩爪。你们在等谁先开口。

**开场二（据点潜入，白壁听泉馆，凌晨两点）**

> 二阶的安静是有钱买来的那种安静：厚地毯、双层玻璃、连水管都包了麻。听泉馆的西翼亮着一盏灯，是老夫人失眠时留的。你们贴在檐下的阴影里，脚下是六十米的空。馆子的空调外机在滴水，滴在一块铜板上，一声、一声。三楼的窗是锁序的第三节，按图上说它该在第二声水滴之后开三十七秒。阿宓今晚在西翼当值，她在楼梯口留了一把没插进去的钥匙。现在，第一声水滴落下了。

**开场三（撤离段，铜环，警报之后）**

> 走廊尽头的红光灯开始转，慢得像不情愿。你们身后那扇柜门正在自己合拢，合拢的声音很轻——静默社造的东西连关门都讲体面。前面的防火闸在往下落，速度是每秒一掌宽。你们怀里那枚印章是热的，因为它刚才在一盏灯下烤了六分钟。四阶的守夜局在六个街区外，他们到这儿要四分半。而消防梯在闸的另一边。你们有四分半，和一个还没决定要不要跟你们走的人。

## 三、地理与区域（九阶与千梯）

> 十一个区域，自上而下排列。每个区域给出氛围、解锁条件、关键地点、常见遭遇、可获取资源与搞砸后的后果。

### 3.1 一阶 · 冠台（The Crown Terrace）

- **氛围**：这里没有街道，只有平台和风。海拔两千九百六十米，云从脚下过，所以叫冠台。理事会大厅的地板是整块岩脊磨平的，走上去有回声。所有人都压低声音，包括来抗议的人。
- **解锁条件**：阶籍 ≥ 一阶通行证（flag.tier1_pass）或 声望（理事会）≥ +2；否则只能经检修井（檐行者路线）。
- **关键地点**：
  - **理事会大厅**——九阶各派七席。可交互对象：席位下方的铜制投票匣（可开，DF 16）。
  - **冠台图书室**——藏有《崖测录》与历次沉降评估。可交互对象：借阅登记簿（可伪造）。
  - **天空港**——飞艇与货运吊臂。可交互对象：货运时刻板（每时段刷新）。
  - **元柜井口**——图书室下方的一口封死的竖井。可交互对象：井口的九孔锁盘（终局）。
  - **侍从长值房**——曲临的办公室。可交互对象：他的私人茶柜（内有副本钥匙）。
- **常见遭遇**：预算 6–10（高等级段）；典型组合 = 冠台侍卫（精锐）×2 + 哨械「垂听者」×1。
- **可获取**：一阶通行证（唯一）、沉降评估摘要、《崖测录》副本、元柜井口图。
- **若被玩家搞砸**：冠台进入「净阶」状态——全部吊篮停运 1d6 时段，检修井加装栅格，此后所有经千梯上行的路线 DF +3；声望（理事会）−3。

### 3.2 二阶 · 白壁（The Whitewall）

- **氛围**：一整排面朝崖外的白房子，墙是真的白，因为每月洗一次。这里是老钱，不喧哗，连狗都不叫。夜里两点之后，整阶只剩下空调外机的滴水声。
- **解锁条件**：flag.rep_baihang ≥ 0，或持白壁行邀请函；否则须经外墙（檐行者，潜行 DF 16）。
- **关键地点**：
  - **听泉馆**——宓老夫人的宅子，西翼有室内泉。可交互对象：泉水循环泵（可制造噪音掩护）。
  - **白壁行拍卖厅**——洗印与拍卖一体。可交互对象：拍品预展柜（摸清安防的最佳场所）。
  - **白壁行地库**——洗印模具与待洗物品。可交互对象：洗印台（本城唯一合法改来历的地方）。
  - **回声匣保管室**——恒温、独立供电。可交互对象：匣本身（V7）。
  - **老园丁小屋**——阿宓住的地方。可交互对象：她的换班表。
- **常见遭遇**：预算 5–9；典型组合 = 家卫（标准）×3 + 猎犬（杂兵，迅捷）×2。
- **可获取**：洗印服务（唯一）、高端赃物的行情、老夫人的私人情报、邀请函。
- **若被玩家搞砸**：白壁行对全城发出「拒收通告」，此后 1d4 周内所有赃物折价率 −20%；声望（白壁行）−3。

### 3.3 三阶 · 中庭（The Atrium）

- **氛围**：城市的客厅。剧场、医院、百货、婚丧嫁娶都在这里办。人多，眼杂，也最容易藏人。三阶的中庭大堂是六层挑空，抬头能看见四阶的地板缝里漏下来的水。
- **解锁条件**：—（开局可用）。
- **关键地点**：
  - **琉璃厅**——剧院兼预展场地。可交互对象：舞台上方的吊杆系统（可作为垂直通道）。
  - **中庭医院**——六阶以下的人来这里要排队。可交互对象：急诊登记表（追踪谁当晚来过）。
  - **旧柜餐厅**——把第一座公共柜的锁序铜板当墙面装饰。可交互对象：铜板（可拓印）。
  - **道具工坊**——游七的地盘。可交互对象：道具箱的清单（伪装道具来源）。
  - **中庭派出所**——守夜局在三阶的派出机构。可交互对象：值班表。
- **常见遭遇**：预算 3–7；典型组合 = 巡逻巡守（标准）×2 + 便衣（杂兵，隐伏）×1。
- **可获取**：伪装道具、人群掩护、医院床位（去创伤）、剧院的人脉。
- **若被玩家搞砸**：中庭大堂加装临时查验口，此后每次穿越三阶须通过一次欺骗 DF 14；声望（守夜局）−1。

### 3.4 四阶 · 铜环（The Copper Ring）

- **氛围**：铜是这里的颜色——屋顶、招牌、门把手，连法院的栏杆都是铜的，因为铜不生锈。写字楼、法院、守夜局总部都挤在这一阶。白天最吵，夜里最亮。
- **解锁条件**：—（开局可用，但守夜局总部需 flag.tier4_pass）。
- **关键地点**：
  - **判牍阁**——法院档案库。可交互对象：档案索引柜（V1 目标区）。
  - **守夜局总部**——《夜巡三条》铜牌挂在这里。可交互对象：值班室的巡逻调度板（最值钱的情报）。
  - **铜环证物房**——268 年设立。可交互对象：证物编号册（V6）。
  - **柜险查勘处**——金衡行在此办公。可交互对象：柜险单存根（廉价情报）。
  - **铜环当铺**——后墙有静默社章程石刻。可交互对象：石刻（可拓印，解锁静默社声望）。
- **常见遭遇**：预算 6–12；典型组合 = 巡守小队（标准）×3 + 哨械「记名录」×1 + 查勘员（杂兵）。
- **可获取**：巡逻调度表、柜险情报、法律文书伪造、证物房线索。
- **若被玩家搞砸**：四阶进入「铜环宵禁」，夜间所有通行须连过两次潜行 DF 15；声望（守夜局）−2。

### 3.5 五阶 · 灰市（The Grey Market）

- **氛围**：本册的母港。灰市的顶就是六阶的地板，所以永远不亮；所有的灯都是自己拉的线。这里什么都卖，包括别人的秘密。绳会的账房在最深处，门口挂着一串铜毫做的帘子。
- **解锁条件**：—（开局可用）。
- **关键地点**：
  - **绳会账房**——温苔的地盘，后间有木匣。可交互对象：暗账（可查谁在找什么）。
  - **檐下铁铺**——改造装备。可交互对象：工作台（工艺，可用）。
  - **修表铺**——门口摆着报废的初代哨械。可交互对象：哨械残骸（技术 DF 14 可拆出零件）。
  - **当铺后墙**——静默社章程石刻。可交互对象：拓印工具。
  - **哑巴酒馆**——不说话的酒馆，因为隔墙有耳。可交互对象：墙上的欠账板。
- **常见遭遇**：预算 2–6；典型组合 = 檐党收数人（杂兵）×4 或 醉汉（杂兵）×3（非致命）。
- **可获取**：全部非法服务、销赃渠道、装备改造、传闻、雇主。
- **若被玩家搞砸**：绳会宣布「断绳」——3d6 天内不接你们的货，不传话，不认人；声望（绳会）−3。

### 3.6 六阶 · 沉巷（The Sunken Lane）

- **氛围**：137 年被削掉两层的旧工人区。天花板低，管道外露，走道里永远有风。被封的旧两层就在脚下的检修井里，檐党说是「下面还有六阶」。
- **解锁条件**：—（开局可用）。
- **关键地点**：
  - **租屋长廊**——一间挨一间的隔断。可交互对象：隔断墙后的听音孔（情报）。
  - **被封旧层**——137 年削掉的两层。可交互对象：旧层的货运口（通往七阶的捷径）。
  - **沉巷小学堂**——孩子们白天上课。可交互对象：教室墙上的阶籍表（谁家搬走了）。
  - **檐党哨点**——收檐钱的地方。可交互对象：凿痕标记。
  - **公共澡堂**——唯一能洗掉痕迹又不被问的地方。可交互对象：换衣柜（临时藏物）。
- **常见遭遇**：预算 2–6；典型组合 = 檐党巡巷（杂兵）×4 + 檐党打手（标准）×1。
- **可获取**：藏身处（可发展据点）、下层人脉、通往七阶的捷径、廉价劳动力。
- **若被玩家搞砸**：檐党在沉巷发布「挂名」——你们的相貌被画在墙上，此后在六阶以下行动被认出的概率大增；声望（檐党）−3。

### 3.7 七阶 · 铁腹（The Ironbelly）

- **氛围**：整阶都在震。工场、货索站台、仓库，空气里有铁屑和机油味。铁腹工团在这里说了算，工牌比通行证好使。
- **解锁条件**：flag.rep_gongtuan ≥ −1 或 持工牌（可伪造，欺骗 DF 13）。
- **关键地点**：
  - **七号料库**——夜班三人，堆着贵重金属。可交互对象：料位卡（V4 目标区）。
  - **货索站台**——全城货运的咽喉。可交互对象：调度牌（可改动运输顺序）。
  - **旧锅炉房**——233 年罢工的号志旗藏在这里。可交互对象：锅炉检修口（通往八阶）。
  - **工团议事堂**——邵铁的办公室。可交互对象：工牌发放册。
  - **废件场**——报废哨械堆积。可交互对象：可拆零件（技术 DF 12）。
- **常见遭遇**：预算 5–10；典型组合 = 工团纠察（标准）×3 + 装卸机（精锐，巨型）×1。
- **可获取**：工牌、金属原料、运输调度权限、工团武力支援、通往八阶的检修口。
- **若被玩家搞砸**：工团封锁货索，此后所有经货索的运输路线关闭 1d4 周；声望（铁腹工团）−3。

### 3.8 八阶 · 涝底（The Sump）

- **氛围**：排水、废料、电厂。地面永远是湿的，脚下的水往低处走，最后落进井底。261 年出现的贯穿裂缝被填埋了，但填埋层下面还在渗。这里的灯是防水的，绿幽幽。
- **解锁条件**：flag.rep_gongtuan ≥ 0（需工团放行）或 经旧锅炉检修口（潜行 DF 15）。
- **关键地点**：
  - **排水枢纽**——八阶的心脏。可交互对象：主阀门轮盘（关掉它，全阶停水）。
  - **填埋裂缝**——261 年封锁的那道。可交互对象：填埋层后的旧泵房（V5 目标）。
  - **黑汛旧泵房**——73 年被淤泥封死。可交互对象：泵房里的老图纸（V5 赃物）。
  - **电厂主控**——全城三分之一电力。可交互对象：分时供电表（踩点核心情报）。
  - **渗水层**——往下就是井底。可交互对象：锈蚀的爬梯（危险的捷径）。
- **常见遭遇**：预算 6–12；典型组合 = 涝底值守（标准）×2 + 排污巡检机（精锐，装甲）×1 + 渗水爬虫群（杂兵）×4。
- **可获取**：供电表（决定所有电子安防的窗口）、老图纸、通往井底的路、断电能力。
- **若被玩家搞砸**：八阶泄洪一次，六阶以下被淹 1d3 时段，全城供电波动；声望（铁腹工团）−2，声望（理事会）−2，且获得 1 层【负担】（道德成本，由导引者提出）。

### 3.9 九阶 · 井底（The Shaft Bottom）

- **氛围**：没有阶籍的地方。矿渣堆、旧城木栈残骸、拾骨人的棚屋。往下四十米是水泥，往上两千九百米是城。这里的人不抬头。
- **解锁条件**：flag.entered_shaft_bottom（首次需经八阶渗水层或千梯四十级）。
- **关键地点**：
  - **木栈残骸**——城历前 60 年的檐。可交互对象：栈道尽头的岩壁凿痕（静默社标记）。
  - **拾骨人营地**——老钳的地盘。可交互对象：他的废件堆（V8 赃物在其中）。
  - **空版铅字坑**——219 年查抄的铅字被倒在这里。可交互对象：尚未熔化的铅字（可读出标题）。
  - **渗水口**——从八阶落下的水。可交互对象：水面下的旧仓门。
  - **崖测井**——往下四十米的水泥层下还有东西。可交互对象：井盖的九孔锁（终局伏笔）。
- **常见遭遇**：预算 7–14；典型组合 = 拾骨人（杂兵）×5 + 井底爬行者（标准，隐伏）×2 + 崖测井下物（首领，仅终局前）。
- **可获取**：造钥模（V8）、空版铅字（线索）、静默社标记、静默社声望、终局伏笔。
- **若被玩家搞砸**：拾骨人全体迁走，井底再无向导；此后在井底的追踪 DF +4；声望（静默社）−2。

### 3.10 千梯（The Ladders）

> 不是一阶，而是一套贯穿九阶的垂直系统。它是本册最重要的「道路」，也是最好的逃跑路线和最坏的伏击场。

- **氛围**：三条路并行——吊篮在崖外晃，货索在崖内爬，检修井在墙里藏。千梯上没有人管你从哪来，只有人管你交没交檐钱。
- **解锁条件**：—（开局可用吊篮）；货索需工牌；检修井需檐行者或檐党放行。
- **关键地点**：
  - **吊篮站台**（每阶一处）——客运。可交互对象：阶籍查验闸（可伪造）。
  - **货索井道**——货运。可交互对象：中途挂钩站（可藏身、可甩脱）。
  - **检修井**——墙内的钢爬梯与滑轮。可交互对象：檐党凿痕（路标）。
  - **四十级**——248 年被封的四十级。可交互对象：檐党的纪念凿刻。
  - **中途挂钩站 B7**——全城的货物都在这里换钩。可交互对象：换钩记录板。
- **常见遭遇**：预算 3–9；典型组合 = 檐党收数人（杂兵）×3 + 巡检哨械（标准）×1，或在四十级遇到「罗屏盗团」（标准 ×3）。
- **可获取**：最快的跨阶移动、甩脱追兵的场地、檐党人脉、运输情报。
- **若被玩家搞砸**：檐党封井，检修井全线加装栅格；此后跨阶移动一律走吊篮（须过查验），移动耗时 ×2 且风险池骰改为 d4。

### 3.11 界外 · 雾桥（The Fogshelf）

> 不属于任何阶。云脊城东侧一道伸出崖外的废弃装卸平台，雾大的时候看不见尽头。这里是「不进城的分账地点」。

- **氛围**：雾、铁锈、和一种没有回声的安静。所有声音都被雾吃掉，所以掮客喜欢在这里谈价。
- **解锁条件**：flag.know_fogshelf（由绳会或檐党告知）或 声望（绳会）≥ +1。
- **关键地点**：
  - **装卸平台尽头**——谈判点。可交互对象：一台还能动的旧吊臂。
  - **雾里的旧集装箱**——藏物。可交互对象：箱号（可作为约定暗号）。
  - **崖边裂隙**——往下就是雾。可交互对象：一条被绳子磨出的沟（说明有人常来）。
  - **废弃磅秤**——称货的地方。可交互对象：秤盘下的暗格。
- **常见遭遇**：预算 4–10；典型组合 = 对方带来的保镖（标准）×2，或埋伏（杂兵 ×4，隐伏）。
- **可获取**：不受阶籍约束的交易、分账、灭迹（把东西扔下崖）、私下会面。
- **若被玩家搞砸**：雾桥成为对方的伏击点并永久标记为「不可信」；此后在此地的交涉立场 +4；声望（绳会）−2。

### 4.2 具名 NPC（24 位）

**霍砚**（"副理"）｜白壁行副理，本册的雇主与暗线核心｜势力：白壁行［归属／表面中立］
- **外观与气质**：四十出头，衣着极整洁，说话前会先把手里的东西摆正。左袖口比右袖口长半寸。
- **驱动**：在两年内把九枚权钥凑齐，并决定是把《沉降名单》公开，还是让自己成为唯一能开元柜的人。
- **秘密**：他是守钥人计霜的儿子；元柜的九钥制度是他母亲定的，他手里已有第一枚（从未交给任何人）。
- **态度轴**：初始 +1。上升：按时交货、不留痕迹、替他保守动机。下降：追问他的动机、把赃物卖给第三方、伤害内应。
- **他知道的线索**：T-01（九钥存在）、T-04（每座柜与元柜的对应）、T-09（元柜里不是钱）。
- **若被杀死／背叛**：白壁行立刻对全城发布「拒收通告」，棺材铺的账会送到绳会；但他预先留了一封信给镜台报馆，信里点名了玩家——这封信会在 1d6 个会话后被刊登，届时守夜局会照着名单上门。故事继续，但玩家从此在被追猎中完成终局。

**温苔**（"绳头"）｜绳会总掮客，中间人｜势力：绳会［中立］
- **外观与气质**：五十岁上下，账房帘子后面坐着，手指常年沾着墨。她记账时不看人。
- **驱动**：让绳会成为城里唯一不可替代的中枢，并让自己活着退场。
- **秘密**：她的暗账里有一页记着「霍砚付了三次钱给同一个死人」。
- **态度轴**：初始 0。上升：准时付佣、不在她的地方动手。下降：在她账房里见血、绕过她私下交易。
- **他知道的线索**：T-02（谁在找什么）、T-06（回声匣是追踪器）、T-11（雾桥的用法）。
- **若被杀死／背叛**：绳会「断绳」；但她的暗账会流入灰市，任何人花标准 ×3 都能买到——其中包含玩家所有已销赃的记录。

**岑照**（"总巡查使"）｜守夜局总巡查使，追猎者｜势力：守夜局［敌对］
- **外观与气质**：走路很轻，说话很慢，从不提高音量。她记得每一个她见过的名字。
- **驱动**：在她退休之前，把《沉降名单》拿到手，用它换一个不会被崩塌吞掉的秩序。
- **秘密**：她 219 年参与过查抄镜台报馆，她保留了一块没交上去的铅字。
- **态度轴**：初始 −2。上升：主动交出赃物、提供他人情报、救过她的人。下降：在她面前杀人、在她辖区连续作案。
- **他知道的线索**：T-03（玩家团伙的手法特征）、T-07（九钥中有几枚已被移动）、T-12（霍砚在找钥匙）。
- **若被杀死／背叛**：守夜局换上一个更蠢也更狠的继任者，全城进入「铜环宵禁」常驻状态；但岑照的私人笔记本会被她的副手交给镜台报馆。

**尤梨**（"拍卖师"）｜白壁行首席拍卖师，买家接口｜势力：白壁行［归属］
- **外观与气质**：语速极快，落槌前一定停顿一秒。她记得每一位买家的出价上限。
- **驱动**：把白壁行做成艺术品的唯一话语权，并嫁进二阶。
- **秘密**：她私下替三阶一位买家做「代持」，那批代持物里有一枚权钥。

- **态度轴**：初始 −1。上升：把料还回去、帮她拿到证据。下降：偷工团的料、伤害工人。
- **他知道的线索**：T-04（填埋令）、T-11（旧锅炉）、T-15（工团里的内鬼）。
- **若被杀死／背叛**：邵铁不再信任任何人，工团与玩家的交集全部关闭；但她留下的证据会由贺九转交，玩家仍可取得（代价：必须替工团做一件事）。

**裴知**（"少东"）｜金衡行少东，失主与潜在买家｜势力：金衡行［归属］
- **外观与气质**：二十多岁，穿得比所有人都新。他说话像在出价，连问路都像在出价。
- **驱动**：在他父亲退位之前，做成一笔他父亲做不成的生意。
- **秘密**：他私下买了柜险，投保标的包括自己家的主柜。
- **态度轴**：初始 0。上升：给他独家、让他觉得自己精明。下降：让他觉得自己被耍了。
- **他知道的线索**：T-07（权钥的行情）、T-13（柜险的假账）、T-16（金衡行也想开柜）。
- **若被杀死／背叛**：金衡行全面收缩，所有柜险作废，玩家少一个情报渠道；他的投保单成为证据，指向他父亲 190 年的旧事。

**卜同**（"账房"）｜绳会账房，销赃的执行者｜势力：绳会［归属］
- **外观与气质**：记账用左手，吃饭也用左手。他从不抬头看进来的人。
- **驱动**：把每一笔账做平，一毫都不差。
- **秘密**：他偷偷抄了一份副账，藏在雾桥的磅秤暗格。
- **态度轴**：初始 0。上升：账目清楚、不欠绳会的钱。下降：赖账、在他面前动账本。
- **他知道的线索**：T-06（谁买了什么）、T-11（雾桥的暗格）、T-13（赃物的真实流向）。
- **若被杀死／背叛**：绳会的账乱 1d4 周，销赃折价率 −20%；他的副账被温苔找到，温苔会用它反制玩家一次。

**阿枝**（"学徒"）｜静默社学徒，技术支援｜势力：静默社［中立］
- **外观与气质**：十五岁，手上全是细小的割伤。她拆东西比装东西快。
- **驱动**：让计晚承认她能造柜。
- **秘密**：她偷偷仿制过一把锁序钥匙，能开三阶那座旧柜——那座柜现在是一家餐厅。
- **态度轴**：初始 +1。上升：给她真的锁序图纸看、让她动手。下降：让她参与暴力、把她的仿制品弄坏。
- **他知道的线索**：T-08（旧锁序的破法）、T-16（反钥的位置）、T-05（哨械的拆法）。
- **若被杀死／背叛**：静默社与玩家永久交恶，全城哨械维修记录向守夜局开放；若她活着到终局，她可以替玩家改装一次锁盘（关键选项）。

## 五、世界特则：静默值与预案点

> 本册的两个世界专属子系统。它们互相咬合：**预案点是你们提前买的余裕，静默值是你们当场欠的债**。
> 花掉预案点可以抵掉静默值；静默值升高会让预案点更贵；两者在结算时共同决定「这一票你们到底赚了多少」。

### 5.1 世界专属技能与态势（对内核的加法，见 `01` 第三节）

| 新增技能 | 属性 | 用于 |
|---|---|---|
| **锁序** Lockwork | 心智 / 灵巧 | 读懂、拆解、重排、伪造柜的开启程序；与哨械打交道 |
| **销赃** Trade-craft | 气场 / 心智 | 估价、议价、洗印流程、判断买家是否可靠 |
| **静默** Hush | 灵巧 / 洞察 | 消音、匿迹、判断一个动作会惊动多少东西（与静默值直接对接） |

**新增态势：潜势（Infiltration）**

| 态势 | 攻击 | 防护 | 移动 | 特殊 |
|---|---|---|---|---|
| **潜势** | −1 骰 | — | — | 潜行／巧手／静默／锁序判定 +1 骰；本回合你造成的静默值增量 −1（最低 0） |

> 潜势与守势可以同时声明吗？不能。但潜势与「移动」是天然搭配：移动后仍保持潜势，是本册最标准的盗窃节奏。

### 5.2 特则 A：静默值（Silence Track）

**定义**：一次「活」（一个据点的完整潜入）期间，全场共享的一根计量条，范围 **0–12**。
它不代表"有多大声音"，而代表**这座建筑对你们的怀疑累积到了什么程度**。

**起始值** = 据点安保层级的起始静默值（见第 12 节每个据点的条目，通常为 0–2）。

#### 阈值表

| 静默值 | 层级 | 场上发生了什么 |
|---|---|---|
| 0–2 | **静默** | 一切正常。巡逻按表走，哨械处于常态。 |
| 3–4 | **疑影** | 有人觉得不对。所有针对玩家的察觉／巡查判定 **DF +2**；巡逻队改为双人行动。 |
| 5–6 | **惊动** | 增援被叫来。1d4 时段后一支增援队到达（见该据点增援配置）；此后每过一个时段，静默值 **+1**（因为你们还没走）。 |
| 7–8 | **封锁** | 据点封锁。可通行的出口减半（导引者保留 1 条）；所有未开启的锁序 **临时升一级**（DF +3）；撤离段所有判定 **DF +2**。 |
| 9–10 | **通缉** | 全城通缉。跨阶移动须通过查验；声望（守夜局）**−2**；本次所有赃物销赃折价率 **−20%**。 |
| 11–12 | **净阶** | 该阶全面封锁 1d3 天。本次任务直接判为 **failed**（除非玩家仍有预案点可支付「撤退」，见下）。 |

#### 静默值增量表

| 事件 | 增量 | 备注 |
|---|---|---|
| 一次潜行判定「险成」 | +1 | |
| 一次潜行／巧手判定「挫败」 | +2 | |
| 一次潜行／巧手判定「灾难」 | +3 | 并掷一次《巡逻意外表》 |
| 破坏一扇门、墙、玻璃、柜体 | +2 | 凯旋的破坏（无声拆解）只 +0 |
| 使用爆破或强攻破门 | +4 | |
| 触发一台哨械 | +3 | 若当场拆掉（技术 DF 16），改为 +1 |
| 战斗开始（任何一次攻击命中） | +2 | 之后每回合 +1 |
| 杀死一名守卫 | +3 | 且留下痕迹，静默值下限锁定为 3（无法降到 3 以下） |
| 击昏／束缚一名守卫而未处理 | +2 | 由「收尾人」处理痕迹后 **−1** |
| 留下明显痕迹（血、工具、撬开的锁） | +1 | 每件可单独处理 |
| 有人目击你们但未被灭口 | +2 | 说服／威胁成功可降至 +1，道德成本由导引者提出 |
| 触发警报装置 | +4 | 若无「静默匠」在场，改为 +5 |
| 在非潜势下奔跑、撞倒重物、喊叫 | +1 | 每次，每时段最多 2 次 |
| 任务计时器越过一个时段而你们仍在据点内 | +0 | 但若静默值 ≥ 5，改为 +1（见阈值表惊动项） |

#### 降低静默值

| 手段 | 减量 | 条件 |
|---|---|---|
| 安静地度过一个时段（无人发现、无新事件） | −1 | 需要真正躲起来（潜行 DF 12 或在一个已确认安全的房间） |
| 处理痕迹（手艺／静默 DF 12） | −1 | 每件痕迹一次；处理尸体为 DF 14 |
| 灭迹一名击昏的守卫（把他放回岗位） | −2 | 且移除「下限锁定」 |
| 断电或干扰通讯（技术 DF 15） | 下一时段所有增量减半 | 持续 1 时段 |
| 花预案点「静默」 | −1d3 | 见 5.3 |
| 花预案点「抹平」 | 取消一次增量 | 见 5.3 |

> **重要裁决原则**：静默值**只增不减到负数**，最低 0。导引者必须在每个时段结束时**公开宣布当前静默值与层级**（见 `04` 第 15 节反模式 15：暗骰太多）。玩家应当始终能看到这根条。

### 5.3 特则 B：预案点（Prep Pool）

**定义**：在**踩点阶段**用时间、钱与人情换来的团队共享点数。它在潜入中可以被花掉，用来把一次失误抹平、或凭空变出一条你们"早就准备好"的路。

```
预案池上限 = 4 + 队伍人数          （3 人队 = 7；5 人队 = 9）
初始预案点 = 0
```

#### 踩点阶段：如何赚到预案点

一次「活」的踩点阶段通常占 1–3 个时段。每个时段每名角色可以做**一件踩点行动**；同一行动对同一据点只能做一次（除非换一种做法）。

| # | 踩点行动 | 判定 | 消耗 | 产出预案点 | 附带收益 |
|---|---|---|---|---|---|
| 1 | **蹲点观察** | 察觉／直觉 DF 13 | 1 时段 | +1（凯旋 +2） | 得知一条巡逻规律 |
| 2 | **调阅柜险单** | 人脉／数据 DF 12 | 1 时段 + 铜毫 ×5 | +1 | 得知一处安防弱点（下次锁序判定 +1 骰） |
| 3 | **收买内应** | 说服／人脉 DF 14 | 1 时段 + 银阶 ×1 | +2 | 解锁一条内应路线 |
| 4 | **实地勘察外墙** | 运动／杂技 DF 14 | 1 时段 + 风险池 1 枚 | +1 | 解锁檐行者路线（且该路线 DF −2） |
| 5 | **全员演习** | 集体检定（见 `03` 第九节） | 1 时段 | +2（成功）／+1（险成）／+0 | 潜入第一次集体潜行 +1 骰 |
| 6 | **伪造身份文件** | 手艺／欺骗 DF 13 | 1 时段 + 银阶 ×1 | +1 | 解锁伪装路线 |
| 7 | **拆解一台报废哨械** | 技术 DF 14 | 1 时段 + 废件 | +2 | 获得一件一次性干扰器 |
| 8 | **打听传闻** | 人脉 DF 12 | 1 时段 | +1 | 掷一次《踩点收获表》（第 11 节） |

**时间压力**：每花掉一个踩点时段，`clock.prep_deadline` 推进 1 格。期限归零时：
- 若玩家仍要动手 → 起始静默值 **+3**（仓促上阵），且预案点无法再增加；
- 若玩家放弃 → 任务进入 `expired`（可回头再接，但赃物可能已被别人取走）。

> **权衡的核心**：多踩一个点 = 多一点余裕，也少一点时间。这是本册每一次「活」的第一道决策。

#### 潜入阶段：如何花掉预案点

| 消耗 | 名称 | 效果 | 使用限制 |
|---|---|---|---|
| 1 | **改道** | 宣布此处本有一条你们早已准备好的替代路线。导引者**必须**给出一条（哪怕临时编一条合理的）。 | 每次潜入 2 次 |
| 1 | **取物** | 从背包里"恰好"取出一件准备好的小工具（一次性，由玩家命名，导引者裁定其合理性）。 | 每次潜入 3 次 |
| 1 | **时差** | 把一次巡逻遭遇解释为"你们算准了交接班"：该次判定改为自动成功，且不产生静默值。 | 每次潜入 1 次 |
| 2 | **抹平** | 把一次失败判定改为「险成」，或取消一次静默值增量（无论多大）。 | 无限制，但见下 |
| 2 | **身份** | 你们已经准备好一套身份文件：一次欺骗判定 **+2 骰**。 | 每次潜入 1 次 |
| 2 | **内应** | 一位内应在关键时刻出现，替你们完成一个动作（开一扇门、引开一人、按掉一次警报）。 | 需 flag.has_insider |
| 3 | **捷径** | 解锁一条未经踩点的通道（"这扇门本该锁死，但它今天没锁"）。导引者必须给出。 | 每次潜入 1 次 |
| 3 | **撤退** | 宣布你们留了一条后手撤离路线：撤离段的一次判定**自动成功**（凯旋）。 | 每次潜入 1 次 |
| 3 | **静默** | 花一个时段彻底收尾，静默值 **−1d3**。 | 需在无人注视的场景 |

**加价规则**：当静默值 ≥ 7（封锁及以上）时，所有预案点花费 **+1**（因为你们手忙脚乱）。这条是本册两个子系统最直接的咬合点。

#### 结算：预案点与静默值如何变成钱

一次「活」结束时，计算 **销赃加成**：

```
销赃加成 = （剩余预案点 × 4%）  −  （终值静默值 × 3%）     上限 +24% / 下限 −36%
```

并判定本次活的 **成色**：

| 条件 | 成色 | 后果 |
|---|---|---|
| 终值静默值 ≤ 2 且 剩余预案点 ≥ 5 | **无声** | 声望（绳会）+1、声望（檐党）+1；销赃加成再 +10%；导引者应当演出一段"没人知道你们来过"的收尾 |
| 终值静默值 ≤ 4 | **干净** | 销赃加成 +5% |
| 终值静默值 5–8 | **有痕** | 无加成；失主会追查（见第 11 节《失主反应表》） |
| 终值静默值 ≥ 9 | **惊城** | 销赃加成 −10%；声望（守夜局）−2；必掷《失主反应表》与《同行竞争者反应表》 |

### 5.4 两个子系统与核心规则的接口

| 核心规则 | 本册如何对接 |
|---|---|
| **专注** | 花 2 点专注可以临时让一次静默值增量 −1（角色"屏住呼吸"，需导引者认可）。 |
| **气势** | 「1 点 — 改写」在本册可把一次**静默值增量**改为 0（而不只是敌体结果）。这是本册气势最常见的用法。 |
| **决意** | 「1 点 — 背景牌」可调用一次**预案点**而不消耗它（每会话一次）。 |
| **负担** | 一次惊城级（静默值 ≥ 9）的活，全队各 +1 负担。 |
| **场地要素** | 每个潜入场景生成 2–4 个要素，其中**至少 1 个必须是"可被用来降低静默值"的**（通风口、帘幕、噪音源、配电箱）。 |
| **战斗** | 潜入中一旦进入战斗，静默值至少 +2，且**此后每回合 +1**。战斗在本册永远是「计划失败」的信号，不是目标。 |

### 6.4 工艺：改造与制作（本册风味）

本册的工艺叫 **「改活」**——把一件合法的东西改成干活用，或把一件赃物改成合法。

| 改造 | DF | 效果 |
|---|---|---|
| 消音处理 | 13 | 一件武器/工具的噪音静默值增量 −1（最低 0） |
| 减重 | 12 | 负载降一级（重→中→轻） |
| 伪装外观 | 14 | 使一件工具看起来像日常用品，被搜查时不被认出 |
| 伪造柜印 | 16 | 给物品打上一座柜的编号钢印（销赃必要步骤；伪造失败则该物永久带假印） |
| 拆装哨械零件 | 15 | 从报废哨械中取出可用件，制作一次性干扰器 |
| 复制锁序抄本 | 17 | 抄录一份锁序抄本（需要原件在手，且抄录者锁序熟练） |

### 6.5 销赃规则（本册核心经济规则）

**规则一：柜货不可直卖。** 任何带柜印（Coffer-mark）的物品，在绳会与灰市只能按标价的 **20%** 出手。

**规则二：洗印。** 白壁行可以合法改写一件物品的来历，手续费 = 标价的 **15%–40%**（由拍品资格声望与物品稀有度决定）。洗印后物品可按标价的 **60%–85%** 出手，但会留下白壁行的登记（可被追查）。

**规则三：折价率公式。**

```
最终售价 = 标价 × 折价率

折价率 = 0.30（基础）
       + 渠道修正（绳会 +0.10 / 白壁行洗印后 +0.30 / 私人买家 +0.15 / 雾桥 +0.20）
       + 静默修正（第 5 节销赃加成）
       + 声望修正（绳缘 +1 → +0.05，+2 → +0.10，+3 → +0.15；负值同幅下降）
       + 竞拍修正（在白壁行公开拍卖 +0.15，但物品被认领的风险 +50%）
       上限 0.85 ／ 下限 0.05
```

**规则四：被认领。** 每件赃物有一枚「被认领风险」值（见第 11 节赃物表）。活结束时掷 `d20 ≥ (20 − 风险值)` 则失主认领成功：物品被追回，且声望（对应势力）−1，玩家须退还已收款项（若已花掉，形成债务）。

**规则五：债务。** 适用 `03` 第五节债务规则。本册的债主通常是绳会或罗屏的债主，每章未偿还额 +20%。

## 八、手法体系

> 在本世界里，能力统称 **「手法」**。手法分四类：**身手**（身体）、**器巧**（工具与机关）、**门道**（人与信息）、**终局**（8 级以上的招牌）。
> 格式遵循 S0 模板 T2。共 **70 条**。

### 8.1 身手（20 条）

**《挂索》**｜类型：迅捷｜消耗：—｜AP：1｜标签：【移动】【攀附】
- **前提**：—
- **效果**：把钩爪固定到上方一个支点，并沿索上／下行一次移动距离。
- **数值**：运动 DF 10（墙面材质恶劣时 14）；成功后本回合你的移动视为垂直且不触发借机。
- **升级**：+1 级后 DF −2，且可在移动后仍保留 1 AP。
- **风味**：钩爪咬进岩缝的那一声，是檐行者听过最像家乡话的声音。

**《贴壁》**｜类型：被动｜消耗：—｜AP：—｜标签：【攀附】
- **前提**：檐行者 或 运动熟练
- **效果**：你可以在垂直表面移动而不减速，且在外墙上时获得轻度掩体。
- **数值**：外墙移动速度 = 正常移动 −1 米（而非减半）。
- **升级**：+1 级后外墙移动不再减速，且坠落伤害减半。
- **风味**：把身体压成墙上一道影子，风从你和外崖之间穿过去。

**《摆荡》**｜类型：全额｜消耗：专注 1｜AP：3｜标签：【移动】【突进】

- **数值**：跨度 = 移动 ×2；落点判定杂技 DF 12；失败则悬在半空，需 1 AP 自救。
- **升级**：+1 级后可在摆荡终点进行一次基础攻击。

**《落点》**｜类型：反应｜消耗：—｜AP：反应 1｜标签：【减伤】

- **数值**：坠落伤害减半且总是以脚着地；着地后不获得【失衡】。
- **升级**：+1 级后坠落伤害归零，且着地当回合获得【隐匿】机会。

**《熄步》**｜类型：被动｜消耗：—｜AP：—｜标签：【静默】

- **数值**：在潜势下额外再 +1 骰。
- **升级**：+1 级后你带领的一支队伍（≤4 人）移动同样不产生静默值。

- **数值**：静默 DF 12；凯旋则额外得知接下来 1d4 时段内该处是否会被巡逻经过。
- **升级**：+1 级后可同时判断三处位置。

### 8.2 器巧（22 条）

**《听锁》**｜类型：全额｜消耗：专注 1｜AP：3｜标签：【锁序】

## 十、游戏化结构

### 10.1 任务状态机（10 个据点各一台）

> 每台状态机独立可读。导引者只需维护 `flag` 与 `clock`，不需要记页码。

**任务 V0《绳会账房的后间木匣》**
```
状态： dormant → offered → active → (succeeded_clean | succeeded_dirty | failed | expired)
转移条件：
  dormant → offered   : 战役开始，且 队伍等级 >= 1
  offered → active    : 玩家接受温苔的委托
  active → succeeded_clean : flag.v0_box == true 且 clock.silence <= 2
  active → succeeded_dirty : flag.v0_box == true 且 clock.silence >= 3
  active → failed     : flag.v0_box == false 且 flag.ropeclan_cut == true
  active → expired    : flag.chapter >= 1 而未完成（温苔把活给了别人）
```

**任务 V1《铜环·判牍阁》**
```
状态： dormant → offered → active → (succeeded_clean | succeeded_dirty | failed | expired)
转移条件：
  dormant → offered   : flag.v0_done == true 且 flag.rep_ropeclan >= 0
  offered → active    : 玩家接受霍砚的委托
  active → succeeded_clean : flag.key_v1 == true 且 clock.silence <= 4
  active → succeeded_dirty : flag.key_v1 == true 且 clock.silence >= 5
  active → failed     : flag.insider_liwang_dead == true 且 flag.has_insider == false
                        或 clock.silence >= 11
  active → expired    : 判牍阁档案被转移（flag.chapter >= 3 而未接取）
```

**任务 V2《白壁·听泉馆》**
```
状态： dormant → offered → active → (succeeded_clean | succeeded_dirty | succeeded_mercy | failed)
转移条件：
  dormant → offered   : flag.key_v1 == true 且 flag.rep_baihang >= 0
  offered → active    : 玩家接受（霍砚坚持"只要那只鸟"）
  active → succeeded_clean  : flag.key_v2 == true 且 flag.madame_hurt == false
  active → succeeded_dirty  : flag.key_v2 == true 且 flag.madame_hurt == true
  active → succeeded_mercy  : flag.v2_truth_heard == true 且 玩家主动放弃取鸟
                              （老夫人自己交出——同样获得权钥，且 rep_baihang +1）
  active → failed     : flag.key_v2 == false 且 clock.silence >= 11
```

**任务 V3《中庭·琉璃厅》**
```
状态： dormant → offered → active → (succeeded_clean | succeeded_dirty | failed | expired)
转移条件：
  dormant → offered   : flag.key_v2 == true（霍砚：预展夜有一枚胸针）
  offered → active    : 玩家接受
  active → succeeded_clean : flag.key_v3 == true 且 clock.silence <= 4
  active → succeeded_dirty : flag.key_v3 == true 且 clock.silence >= 5
  active → failed     : flag.key_v3 == false 且 flag.rival_luo_first == true
  active → expired    : 预展夜结束（clock.prep_deadline == 0）
```

**任务 V4《铁腹·七号料库》**
```
状态： dormant → offered → active → (succeeded_clean | succeeded_dirty | succeeded_union | failed)
转移条件：
  dormant → offered   : flag.key_v3 == true 且 flag.rep_gongtuan >= -1
  offered → active    : 玩家接受，或 flag.rep_gongtuan >= 1 时改由邵铁委托（succeeded_union 路线）
  active → succeeded_clean  : flag.key_v4 == true 且 clock.silence <= 4
  active → succeeded_dirty  : flag.key_v4 == true 且 clock.silence >= 5
  active → succeeded_union  : flag.key_v4 == true 且 flag.union_allied == true
                              （工团主动交出量规，rep_gongtuan +2，但权钥被标记）
  active → failed     : flag.insider_hejiu_dead == true 或 clock.silence >= 11
```

**任务 V5《涝底·排水枢纽》**
```
状态： dormant → offered → active → (succeeded_clean | succeeded_flood | failed)
转移条件：
  dormant → offered   : flag.key_v4 == true 且 flag.rep_gongtuan >= 0
  offered → active    : 玩家接受
  active → succeeded_clean  : flag.key_v5 == true 且 flag.flood_happened == false
  active → succeeded_flood  : flag.key_v5 == true 且 flag.flood_happened == true
                              （拿到了图纸，但六阶以下被淹，全员 +1 负担，两层声望 −2）
  active → failed     : flag.key_v5 == false 且 clock.silence >= 11
```

**任务 V6《铜环·守夜局证物房》**
```
状态： dormant → offered → active → (succeeded_clean | succeeded_dirty | succeeded_trap | failed)
转移条件：
  dormant → offered   : flag.subsidence_known == true 且 flag.rep_watch <= 0
  offered → active    : 玩家接受（本册唯一"玩家主动提出"的活）
  active → succeeded_clean  : flag.key_v6 == true 且 flag.weizheng_exposed == false
  active → succeeded_dirty  : flag.key_v6 == true 且 flag.weizheng_exposed == true
  active → succeeded_trap   : flag.key_v6 == true 且 flag.weizheng_used == true
                              （玩家识破卫铮并反利用，岑照收到假情报；终局关键筹码）
  active → failed     : 被捕（clock.silence >= 11）→ 转为"越狱"支线，完成后可重接
```

**任务 V7《白壁·回声匣》**
```
状态： dormant → offered → active → (succeeded_clean | succeeded_loud | failed | cursed)
转移条件：
  dormant → offered   : flag.keys_collected >= 4（霍砚终于点名要这只匣）
  offered → active    : 玩家接受（若拒绝，霍砚撤回后续所有委托 → 暗线转为"追查霍砚"）
  active → succeeded_clean  : flag.key_v7 == true 且 flag.echo_box_silenced == true
  active → succeeded_loud   : flag.key_v7 == true 且 flag.echo_box_silenced == false
                              （此后 clock.silence 下限锁定 5，且每时段 +1）
  active → failed     : flag.key_v7 == false 且 clock.silence >= 11
  active → cursed     : 玩家在不知情时把匣子卖给了第三方 → flag.echo_sold == true
                        （第三方被追踪，买家找上门；岑照提前介入）
```

**任务 V8《井底·旧城遗址》**
```
状态： dormant → offered → active → (succeeded_clean | succeeded_dirty | succeeded_guide | failed)
转移条件：
  dormant → offered   : flag.entered_shaft_bottom == true 且 flag.keys_collected >= 5
  offered → active    : 玩家接受（或由老钳引导，succeeded_guide 路线）
  active → succeeded_clean  : flag.key_v8 == true 且 flag.laoqian_alive == true
  active → succeeded_dirty  : flag.key_v8 == true 且 flag.laoqian_alive == false
  active → succeeded_guide  : flag.key_v8 == true 且 flag.laoqian_allied == true
                              （额外获得崖测坐标，解锁终局第三种解法）
  active → failed     : flag.key_v8 == false 且 沉听者被惊动（clock.silence >= 11）
```

**任务 V9《冠台·元柜》**
```
状态： dormant → offered → active → (ending_open | ending_sell | ending_hold | ending_collapse)
转移条件：
  dormant → offered   : flag.keys_collected >= 8 且 flag.primecoffer_located == true
  offered → active    : 玩家决定进入（这是唯一没有雇主的活）
  active → ending_open     : flag.primecoffer_opened == true 且 flag.press_allied == true
  active → ending_sell     : flag.keys_sold == true（交给岑照／白壁行／金衡行）
  active → ending_hold     : flag.primecoffer_opened == true 且 flag.keys_kept == true
  active → ending_collapse : clock.silence >= 11 且强行开柜 → 结构信息泄露，全城动荡
```

### 12.2 贯穿暗线（三层）

**第一层（玩家在第 1–4 据点会隐约感到）：雇主知道得太多。**
霍砚每次都能准确说出赃物在哪个位置、哪条路能走通、哪个内应可以收买。他从不解释。
他的隐藏动机（掷表 8，或直接采用第 16 项）：**他在收集九枚权钥。**

**第二层（第 5–8 据点）：那些赃物不是赃物。**
九件看似毫不相干的东西——一枚印、一只鸟、一枚胸针、一把量规、一卷图纸、一件封存物、一只匣、一副模、一枚反钥——
在《元柜锁盘》面前会同时发亮。它们是 **权钥**：静默社为元柜造的九件验证物。
元柜里装的不是钱，是 **《九阶图》原本** 与 **《沉降名单》**：一份记录哪几阶会在未来三十年因超载崩塌、以及理事会决定优先疏散谁的名单。

**第三层（第 7–9 据点，与终局）：霍砚是守钥人的儿子，而他在利用你们踩雷。**
他知道每一座柜的安防会怎么反应——因为他要让**你们**去试。第七件（回声匣）是明的陷阱：它一旦被带出保管室就持续告密，
霍砚要的就是守夜局把所有注意力放在你们身上，好让他自己走进冠台。
而守夜局的岑照在追同一批钥匙，她想拿名单换秩序；镜台报馆的胡同舟想印出来；金衡行想让名单永远不出现。

> **暗线揭示的三个节点**（导引者必须确保玩家能碰到，用三线索法则保证三条途径）：
> 1. **T-16「九钥」**：① 裴无咎的备用锁序残片；② 计晚说的"关上而不是打开"；③ 拾骨人老钳床头那副模。
> 2. **T-09「元柜里不是钱」**：① 沉听者说的数字（沉降坐标）；② 曲临的元柜工程日志副本；③ 镜台报馆未印出的铅字标题。
> 3. **T-12「霍砚在雇两队」**：① 温苔暗账里"三次钱给同一个死人"；② 罗屏手里的图；③ 薄言说"匣子的信号不是发给守夜局的"。

### 12.4 十个据点详述

#### V0《绳会账房的后间木匣》
- **一句话**：温苔给了你们一个没开口的木匣，和一个不许问的问题。
- **推荐等级**：1｜**安保层级** 1｜**起始静默值** 0｜**阶**：五阶灰市
- **赃物**：木匣里是一份委托函与一张判牍阁的索引号（无标价，情报价值）。
- **守备配置**：温苔（不战斗）＋ 两名绳会收账人（杂兵）＋ 一道门扣（杂兵）。
- **三条进入路径**：① 正门走进去（温苔请你们来的）；② 后巷的卸货口（潜行 DF 10）；③ 屋檐与天窗（檐行者，运动 DF 12）。
- **机关与解锁**：木匣有一把两转锁（巧手 DF 10）。**不许破坏**——破坏了温苔会立刻知道。
- **三种方案**：

| 方案 | 预案点消耗 | 痕迹 | 后续 |
|---|---|---|---|
| 老实接活（不做任何多余的事） | 0 | 无 | rep_ropeclan +1，但酬劳最低 |
| 顺手看看她的暗账（数据 DF 13） | 1 | 若被发现，rep_ropeclan −2 | 得知"三次钱给同一个死人"（T-12 的第一条途径） |
| 把木匣掉包（巧手 DF 14） | 2 | 无（若成功） | 你们留了副本；霍砚后来会察觉 |

- **撤离路线**：① 原路走出正门（最安全）；② 后巷（可甩脱跟踪）。
- **搞砸后果**：温苔宣布「断绳」；五阶的活全部关闭，且她会把你们的相貌卖给第一个掏钱的人。

### 12.6 四个结局

**A · 开柜（需要 flag.press_allied == true）**
玩家把《九阶图》与《沉降名单》交给镜台报馆。报纸印出那一版的时候，全城同时读到了同一件事：这座城在沉，而且有人早就知道。
理事会垮台或改组；八阶与九阶的人开始往上走；玩家成为公众口中的"揭幕者"，同时在守夜局与金衡行的名单上排第一。
**余波**：一次全城追索（1–2 次会话），之后玩家可以选择离开云脊城，或留下重建某个檐口。

**B · 换手（flag.keys_sold == true）**
玩家把九钥（或名单）交给岑照／白壁行／金衡行中的任一方。他们拿到赦免、一笔足以离开这座城的钱、和一个新的身份。
名单被封存。沉降照旧。三十年内，某几阶会塌，而塌下去的还是同一批人。
**余波**：玩家富有但声名狼藉（或声名显赫但内心空洞）；导引者应当演出一次"很多年后"的短景——他们在一座更高的城里，听见有人说起云脊城塌了。

**C · 自持（flag.primecoffer_opened == true 且 flag.keys_kept == true）**
玩家自己拿着名单。他们成为新的守钥人：所有势力都想要他们手里的东西，也都不敢动他们。
玩家可以逐个去谈：用名单换工团的自由、换檐党的井、换报馆的版面、换霍砚和岑照互相制衡。
**余波**：这不是一个"结束"，而是一个**长期状态**。战役转入开放结局，玩家决定每一次把名单的哪一部分给谁。

**D · 崩塌（clock.silence >= 11 且强行开柜）**
强开的那一瞬间，九孔守柜机把结构数据广播给了全城。九阶同时知道了自己脚下的承重量。
结果不是解放，是恐慌：上阶封锁下阶，下阶冲击上阶，货索停运，千梯断裂。
**余波**：玩家在混乱中逃出冠台，带着（或没带着）名单。城市进入动荡期；下一季的战役从废墟里开始。

> **结局判定顺序**：先判 D（静默值）→ 再判 B（是否卖出）→ 再判 A（是否有报馆盟友）→ 否则 C。
